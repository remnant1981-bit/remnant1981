# R&D 사업비 가이드 — 수익화 방안 (v0.1, 2026-11-14)

> 수치는 모두 **검증 전 가설**. 실제 방문·사용 데이터를 3개월 모은 뒤 조정한다.

## 1. 전제
| 구분 | 내용 |
|---|---|
| 사용자 | 중소·중견기업 연구소·연구행정 담당, 창업기업 대표, 대학 산학협력단, 정부과제 컨설턴트 |
| 특징 | 틈새(B2B) 시장: 방문자 수는 적지만 **업무 목적이 분명하고 구매력 있음** → 일반 광고 단가보다 **직접 제휴·B2B**가 유리 |
| 원칙 | 핵심 기능(편성·점검·엑셀) **무료 유지**, 입력값은 브라우저 저장(개인정보 수집 최소) |

## 2. 수익원 후보
| # | 방식 | 내용 | 예상 규모(가설) | 난이도 | 선행 조건 |
|---|---|---|---|---|---|
| 1 | 디스플레이 광고 | 애드센스 2곳(이미 코드 준비) | 낮음(틈새 트래픽) | 낮음 | 전용 도메인·처리방침·승인 |
| 2 | **직접 제휴(스폰서) 광고** | 정부과제 컨설팅·세무회계(정산)·특허사무소·기업부설연구소 인정 대행 등 1~3곳 고정 노출(월정액) | 애드센스보다 높음 | 중간 | 방문 통계, 제휴 제안서 |
| 3 | **전문가 상담 연결(리드)** | "계획서·정산 검토 받기" 버튼 → 동의 후 파트너에 연결, 건당 수수료 | 중간 | 중간 | 동의·처리방침, 문의 폼, 파트너 계약 |
| 4 | **디지털 상품** | 편성·정산 실무 가이드북, 비목별 계상 체크리스트, 증빙 체크리스트, 계획서 양식 엑셀 고급판(크몽·스마트스토어) | 중간 | 낮음 | 사업자등록·통신판매업 |
| 5 | **기관 라이선스(B2B)** | TP·강소특구·창업보육센터·대학에 기관 로고·기본 기준 세팅한 전용 버전 제공(연 단위) | 높음(건당) | 높음 | 영업, 설치형/전용 배포 |
| 6 | 교육·세미나 | 사업비 편성·정산 실무 온라인 강의, 기관 위탁 교육 | 중간 | 중간 | 강의 자료(도구 화면 활용) |
| 7 | 유료 기능(장기) | 클라우드 저장·팀 공유·AI 검토 | 미정 | 높음 | 서버·결제·약관 |

## 3. 권장 순서
| 단계 | 기간 | 할 일 | 성과 지표 |
|---|---|---|---|
| 0. 기반 | ~1개월 | 전용 도메인 연결, 방문 통계(GA4), 개인정보처리방침·이용약관 페이지, 애드센스 신청, 검색 등록(구글·네이버) | 월 방문자, 엑셀 다운로드 수 |
| 1. 유입 | 1~3개월 | 블로그(티스토리 자동 발행 활용)로 "사업비 편성·기관부담금·간접비" 실무 글 연재 → 도구 링크 | 검색 유입, 재방문율 |
| 2. 초기 수익 | 2~4개월 | 디지털 상품 1~2종 출시(④), 제휴 1곳 섭외(②) | 상품 판매 수, 제휴 클릭 |
| 3. B2B | 4~6개월 | 기관 대상 전용 버전·교육 제안(⑤⑥), 상담 연결 시범(③) | 기관 계약 1건 |

## 4. 화면에 넣을 위치(기능 스위치로 단계 공개)
- 엑셀 다운로드 완료 안내 아래: "계획서·정산 검토가 필요하면" 제휴/상담 카드(②③)
- 점검 오류가 많을 때: 가이드북·체크리스트 안내(④)
- 하단: 기관용 문의(⑤⑥)
- 광고는 입력 흐름을 방해하지 않는 위치 유지(현재 2곳)

## 5. 확인 필요(리스크)
| 항목 | 내용 |
|---|---|
| 겸업 | 개인 사업으로 운영 시 소속 회사 겸업·자산 사용 규정 확인 |
| 사업자 | 상품 판매·제휴 수수료는 사업자등록, 판매는 통신판매업 신고 |
| 개인정보 | 상담 연결은 수집 항목 최소화·동의·제3자 제공 고지 필수 |
| 중립성 | 제휴 노출은 "광고/제휴" 표시, 점검 결과와 무관함 명시 |
| 법령 정확도 | 고시 개정 시 즉시 반영(신뢰가 핵심 자산) |
