# R&D 사업비 가이드 — 3단계 후보 A: 집행 현황판 설계안 (v0.1, 2026-11-13)

> 상태: **A1 구현 완료(2026-11-13)**, 기능 스위치 `features.execution`(기본 false)로 숨긴 채 배포. 결정: 부진·과속 ±25%p, 연차 기간 직접 입력. A2·A3 미구현.

## 1. 목적·범위
| 구분 | 내용 |
|---|---|
| 목적 | 편성(계획) 대비 **집행액·잔액·집행률**을 비목별로 한눈에 보고, 초과·부진·마감 일정을 미리 알림 |
| 사용자 | 과제 실무 담당(연구책임자·연구행정), PC 위주 |
| 포함 | 비목별 월 집행액 입력, 기관부담 현금 납부 기록, 현황표·경고, 엑셀 현황표, 백업 파일 |
| **제외** | 건별 증빙·거래처 관리, 이지바로·RCMS 등 시스템 연동, 서버 저장(→ 개인정보·권한 문제, 무료 정적 사이트 범위 밖) |

## 2. 화면 구성(PC 2단 유지)
- 상단 전환: **[편성] [집행]** (집행은 `features.execution` 켤 때만 표시)
- 좌측(입력)
  1. **연차 기간**: 시작일·종료일(협약 기준) → 기준일(오늘) 대비 **경과율** 자동 계산
  2. **협약 금액 확인**: 편성 금액을 기본값으로 불러오고, 협약 과정에서 조정된 비목만 수정(편성 데이터는 그대로 유지)
  3. **월별 집행 입력**: 비목(행) × 월(열) 그리드. 현금만 입력(현물은 편성액 그대로 인정 표시)
  4. **기관부담 현금 납부**: 납부일·금액 목록
- 우측(고정 패널)
  - 총 집행률 · 경과율 · 잔액 · 경고 건수, 집행률/경과율 막대
  - 경고 목록(근거 조문 표시), 엑셀 현황표 다운로드, 백업 저장/불러오기

### 현황표(비목별)
| 비목 | 협약(현금) | 집행 누계 | 잔액 | 집행률 | 상태 |
|---|---|---|---|---|---|
| 인건비 | 35,000 | 26,250 | 8,750 | 75.0% | 정상 |
| 연구재료비 | 120,000 | 31,200 | 88,800 | 26.0% | ⚠ 부진 |
| 연구수당 | 9,000 | 9,500 | −500 | 105.6% | ✖ 초과 |

## 3. 점검 규칙(A단계: 안내 수준, 자동 판정 아님)
| 구분 | 규칙 | 표시 |
|---|---|---|
| 초과 집행 | 비목 잔액 < 0 | ✖ "비목 간 변경(전문기관 승인 대상일 수 있음) 확인" |
| 집행 부진 | 집행률 < 경과율 − 25%p | ⚠ 부진(기준값 화면에서 조정) |
| 과속 집행 | 집행률 > 경과율 + 25%p (인건비 제외) | ⚠ 과속 |
| 연구수당 | 집행 누계 ≤ 협약액, 1인 70% 한도 안내 | ✖/안내(사용 기준 제26조) |
| 기관부담 현금 | 납부 누계 < 최소 현금, 기한 = 연차 종료 3개월 전(협약에 별도 기한 있으면 그 날짜) | D-day 표시(사용 기준 제60조②) |
| 장비 구입 | 과제 종료 2개월 전까지 구입 완료 | D-day(사용 기준 제23조) |
| 연차 종료 | 종료 30일 전부터 잔액·미집행 안내(이월·반납은 사업별 상이) | 안내 |

- 경고는 편성 화면과 동일하게 "오류·주의만 기본 표시, 통과는 접기"
- 비목 간 변경 **승인 기준 비율은 사업별로 달라** A단계에선 자동 판정하지 않음(공고문 기준 입력은 B단계)

## 4. 데이터·저장
```
project.v = 3
insts[i].data[y].exec = {
  start: 'YYYY-MM-DD', end: 'YYYY-MM-DD',        // 연차 기간
  agreed: { [비목]: { cash, inkind } } | null,     // 협약 조정분(없으면 편성값)
  monthly: { [비목]: [12개월 현금 집행액] },         // 천원
  orgCashPaid: [{ date, amount }]
}
```
- 브라우저 저장(localStorage) + **백업 파일(JSON) 내보내기·불러오기** 필수(장기 데이터, 브라우저 삭제 시 분실 위험)
- v2 → v3 자동 변환(exec 없음 = 빈 값). 편성 데이터 변경 없음
- 금액만 저장. 거래처·증빙·개인 식별정보 저장 안 함

## 5. 엑셀 출력(집행 현황표)
① 비목별 현황(협약·집행·잔액·집행률, 수식) ② 월별 집행 추이 ③ 기관부담 현금 납부 내역 ④ 경고·기준일

## 6. 단계 구분
| 단계 | 내용 | 스위치 |
|---|---|---|
| A1 | 연차 기간·월별 직접 입력·현황표·경고·엑셀·백업 | `execution` |
| A2 | 시스템 집행내역 **붙여넣기**(탭 구분 → 비목 매핑 미리보기 → 반영) | `executionPaste` |
| A3 | 월별 추이 차트 | `executionChart` |

## 7. 결정 필요
1. 부진·과속 기준(기본 ±25%p) 적정 여부
2. A2용 이지바로·RCMS 집행내역 내보내기 **샘플 파일**(열 이름·비목 표기 확인용, 금액 외 정보는 가려서)
3. 연차 기간 기본값: 협약일 기준 12개월 vs 직접 입력

## 8. 테스트 계획
