# 메종도로시 주문 페이지

내포 센텀시티 여성복 매장 **메종도로시**의 인스타그램 프로필 링크용 페이지입니다.
신상 목록 → 사이즈·컬러 선택 → 장바구니 → 주문서(택배/매장 픽업) → 입금 안내까지 한 페이지에서 처리합니다.

- 주소: `https://remnant1981-bit.github.io/remnant1981/maison-dorothy/`
- 빌드 없음 (정적 HTML/CSS/JS), `main` 병합 시 `.github/workflows/pages.yml`이 자동 게시
- 로컬 확인: 저장소 루트에서 `python3 -m http.server 8000` → `http://localhost:8000/maison-dorothy/`
- 테스트: `node --test "tests/maison-dorothy/*.test.js"`

## 파일
| 파일 | 역할 |
|---|---|
| `config.js` | **매장 정보·상품 목록·택배비·주문 접수 주소** — 운영 중 고치는 파일은 이것뿐 |
| `images/` | 상품 사진 640×800(4:5), `t/` 썸네일, 매장 사진, 공유 미리보기 `og.jpg` — 인스타 게시물에서 가져와 잘라 압축함 |
| `logic.js` | 장바구니·금액·주문서 검사 (테스트 대상) |
| `app.js`, `index.html`, `style.css` | 화면 |
| `policy.html` | 개인정보처리방침·교환 환불 안내 |
| `products-sheet.csv` | 지금 상품을 구글 시트로 옮길 때 쓰는 파일 (게시 안 됨) |
| `admin/` | 관리자 앱 (Apps Script 별도 프로젝트, 게시 안 됨) |
| `order-apps-script.gs` | 주문을 구글 시트에 쌓고 메일 알림 보내는 스크립트 (사장님 구글 계정에 설치, 게시 안 됨) |

## 오픈 전 체크리스트
1. `config.js` → `store`: 전화번호, 카톡채널 주소, 밴드 주소, 입금 계좌, 사업자 정보(통신판매업 신고번호 포함)
2. `config.js` → `products`: 가격 입력 (비우면 "가격 문의"로 주문 받음), 품절은 `soldOut: true`, 새 상품은 사진을 `images/` 에 넣고 항목 추가
3. 구글 시트 + `order-apps-script.gs` 설치 → 웹앱 URL 을 `orderEndpoint` 에 입력
4. `preview: false` 로 변경, `index.html` 의 `<meta name="robots" content="noindex">` 삭제
5. 테스트 주문 1건 → 시트·메일 도착 확인 → 인스타 프로필 링크에 주소 등록

## 구매 전환을 위해 넣은 것
- 첫 화면에 실제 매장 사진, 바로 아래 "신상 보기" / "사이즈 물어보기"
- **내 사이즈 필터(66·77·88·99)**: 추천 사이즈를 아는 옷만 거름, 고른 사이즈는 상품 상세에 자동 선택
- 상품 상세: 사진 여러 장, 인스타 원문 코디 팁, "함께 입으면 예뻐요"(같이 입은 상품 추천), 인스타 원문 링크
- 가격 미정 상품도 담아서 주문서 전송 가능 → 사장님이 가격·재고 확인 후 안내
- 단골 후기("개미지옥") + 프리마켓 사진으로 신뢰, 매장 찾는 길(골목 랜드마크) 안내
- 카톡·밴드 링크 공유 시 매장 사진 미리보기(og.jpg)
- 인스타식 스토리, 하단 탭(홈·신상·찜·쇼핑백·매장), 찜·최근 본 옷(휴대폰에 저장)
- **뒤로가기로 창 닫기**: 상품·쇼핑백·스토리를 열고 휴대폰 뒤로가기를 눌러도 페이지를 떠나지 않음
- **상품 공유 링크**: 주소 끝 `#p-상품id`(예: `#p-p04`)로 들어오면 그 옷이 바로 열림 → 인스타 게시물·DM에 붙여 쓰기
- 지금 영업 중 표시(config.js `store.open`), 주소 복사, 무료배송까지 남은 금액(가격 입력 시), 전화번호 자동 하이픈, 우편번호 검색
- 이미지: 상품 640×800, 스토리용 180px 썸네일(`images/t/`), 매장 사진 800/1200 두 크기

## 관리자 앱 (`admin/`) — 휴대폰으로 주문·상품·매장 정보 관리
구글 계정으로 로그인해야만 열리는 별도 앱. 데이터는 운영 시트에 저장되고, 손님 페이지는 시트를 읽어 반영합니다.

| 화면 | 할 수 있는 것 |
|---|---|
| 오늘 | 오늘 주문 수, 입금 확인할 주문, 보낼 택배, 픽업 대기, 판매 중·품절 수 |
| 주문 | 상태별 보기·검색, 입금액 입력(가격 문의 주문), 입금 확인 → 발송·픽업 완료, 송장번호, 취소·되돌리기, 전화·문자, 안내 문자 복사 |
| 상품 | 휴대폰 사진첩에서 사진 올리기(자동 축소 → 드라이브), 새 상품·수정·삭제, 보이기·품절 스위치, 순서 바꾸기 |
| 매장 | 공지 한 줄, 영업 요일·시간, 전화, 카톡채널, 밴드, 입금 계좌 |

### 설치 순서 (지금은 훈이님 구글 계정으로 운영)
1. **운영 시트 + 공개 스크립트**: `order-apps-script.gs` 맨 위 안내 1~6 (시트 준비하기 → 웹 앱 배포: 실행 "나", 액세스 "모든 사용자")
2. `config.js` 의 `orderEndpoint`·`productsUrl` 에 공개 웹앱 URL 입력
3. **관리자 앱**: `admin/Code.gs` 맨 위 안내 1~5 (별도 프로젝트, 웹 앱 배포: 실행 "나", 액세스 **"나만"**)
4. 관리자 앱 주소를 휴대폰에서 열고 "홈 화면에 추가"

### 매장 대표에게 넘길 때
운영 시트 소유권 이전 → 두 스크립트를 대표 계정에서 다시 배포 → 새 공개 웹앱 URL을 `config.js` 에 반영. 주문 알림 메일은 `NOTIFY_EMAIL`.

### 보안
- 공개 스크립트(모든 사용자)는 주문 접수와 "상품"·"설정" 탭 읽기만 함. 손님 정보가 있는 "주문" 탭은 공개되지 않음
- 관리 기능은 "나만" 배포된 관리자 앱에만 있고, 모든 기능이 관리자 본인인지 한 번 더 확인
- 손님 입력이 시트에서 수식으로 실행되지 않도록 막음(`=`, `+`, `-`, `@` 로 시작하는 값)
- 테스트: `tests/maison-dorothy/gas.test.js` 가 두 스크립트를 가짜 시트 위에서 시험

## 시트 꾸미기 (메뉴 "메종도로시 → 보기 좋게 꾸미기")
- 값은 바꾸지 않고 모양만: 머리줄 색, 줄무늬, 칸 너비, 금액 `#,##0원`, 접수시각 `yyyy-mm-dd hh:mm`, 긴 글 줄바꿈, 앞쪽 칸 고정
- 주문 상태별 색(입금대기 주황·입금확인 파랑·완료 초록·취소 회색 취소선), 상태는 목록에서만 고르기
- 상품: 숨김 줄 회색, 품절 줄 붉은색, 가격 빈칸 주황, 노출·품절은 Y/N 목록
- **현황** 탭: 오늘 주문, 입금 확인할 주문, 보낼 택배, 픽업 대기, 이번 달 입금액, 판매 중·품절·가격 미입력 수 (수식, 공개 안 됨)
- 상품을 가져오거나 칸을 손본 뒤 다시 누르면 서식이 맞춰짐

## 사장님이 휴대폰으로 상품 관리 (구글 시트)
코드를 고치지 않고 구글 시트 "상품" 탭만 고치면 페이지에 반영됩니다.
1. 주문 접수용 구글 시트에 `order-apps-script.gs` 설치 (파일 맨 위 안내 1~5)
2. 시트 메뉴 **메종도로시 → 상품표 만들기**, 또는 `products-sheet.csv`(지금 상품 11개)를 가져와 탭 이름을 "상품"으로
3. `config.js` 의 `productsUrl` 에 웹앱 URL(주문 접수와 같은 주소) 입력
| 칸 | 쓰는 법 |
|---|---|
| 노출 | N 이면 숨김 |
| 아이디 | 영문·숫자, 한 번 정하면 바꾸지 않기 (찜·공유 링크 연결) |
| 가격 | 숫자 (비우면 "가격 문의") |
| 배지 | NEW 또는 원하는 짧은 말 |
| 사진·추가사진 | 구글 드라이브 사진 공유 링크("링크가 있는 모든 사용자"), 또는 images 폴더 파일명 |
| 컬러·사이즈·함께입기 | 쉼표로 구분 (사이즈를 비우면 손님이 평소 사이즈 66~99 중 선택) |
| 추천사이즈 | 66~88 처럼 |
| 품절 | Y 면 품절 표시 |
- 반영 시점: 새 손님은 바로, 이미 왔던 손님은 다시 열 때 (저장해 둔 상품표로 먼저 보여주고 뒤에서 새로 받아 갱신)
- 시트를 못 읽으면(2.5초 초과) `config.js` 상품으로 보여줌
- 시트의 글자는 글자로만 표시되고, 사진 칸에는 https 주소·드라이브 링크·파일명만 허용(보안)

## 개인정보처리방침·교환 환불 (`policy.html`)
- 하단 링크와 주문서 동의 문구에서 연결. 책임자·연락처·시행일은 `config.js` 의 `store.policy`
- 법률 검토를 거친 문서가 아니므로 오픈 전 내용 확인 필요 (특히 위탁 택배사 이름, 보유 기간)

## 주문 접수 방식
- `orderEndpoint` 있음: 주문이 구글 시트 "주문" 탭에 쌓이고 메일 알림. 전송 실패 시 손님에게 카톡 복사 안내
- `orderEndpoint` 없음: 손님이 주문 내용을 복사해 카톡채널로 보냄
- 결제는 계좌이체만. 카드결제는 PG 계약이 필요하므로 스마트스토어 연계 등으로 별도 검토

## 사진 출처
`images/` 의 사진은 메종도로시 인스타그램 게시물에서 가져왔습니다. 모델 착용 사진 중 도매처 제공 이미지가 있다면 쇼핑몰 사용이 허용된 사진인지 사장님이 확인해 주세요.

## 개인정보
주문서에서 성함·연락처·주소를 받으며 수집 동의 체크가 필수입니다. 저장소에는 주문 정보가 남지 않고, 사장님 구글 시트에만 저장됩니다. 계좌·연락처 외의 비밀번호·토큰은 이 저장소(공개)에 넣지 마세요.
