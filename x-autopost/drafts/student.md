# 수험생·대학생 대상 앱 트윗 초안 (5순위)

- 대상 앱 유형: 학습(인강·단어·문제풀이), 알바 구하기, 중고거래, 대학 생활(시간표·커뮤니티)
- 애드픽 캠페인 상세를 보고 `{ }` 빈칸만 채워 쓰면 됨. 혜택·조건은 **상세 문구 그대로** 적을 것
- `[광고]` 표시와 홍보 링크는 게시할 때 자동으로 붙음 → 본문만 고르면 됨
- 빈칸(`{…}`)이 남은 글은 게시기가 자동으로 막음
- 길이 확인: 긴 앱 이름·혜택(예: 「신규 가입 후 첫 지원 시 편의점 상품권 3,000원」)을 넣어도 최대 163/280

## 초안 5종 (접근 방식별)
| # | 방식 | 본문 | 예상 길이 |
|---|---|---|---|
| 1 | **상황형 (권장)** | {시즌}에 {용도}<br>{앱이름} {혜택}<br>{대상} | 약 165 |
| 2 | 혜택 요약 | {앱이름} {대상} 혜택<br>{혜택}<br>#대학생 (수험생 대상이면 #수능끝) | 약 135 |
| 3 | 조건 공개형 | {앱이름} {혜택}<br>조건: {조건}<br>대상: {대상} | 약 155 |
| 4 | 질문형 | {용도} 앱 찾는 분?<br>{앱이름} 가입하면 {혜택} | 약 135 |
| 5 | 짧은 한 줄 | {앱이름} {혜택} ({마감일}까지) | 약 110 |

- 1번 권장 이유: 이 주제는 "지금 할 일"과 엮을 때 반응이 좋음 → `{시즌}` + `{용도}` 조합

### `{시즌}` × `{용도}` 조합 예시
| `{시즌}` | 알바 앱 | 학습 앱 | 중고거래 앱 |
|---|---|---|---|
| 수능 끝나고 | 첫 알바 찾기 | — | 문제집·참고서 정리 |
| 겨울방학 | 단기 알바 찾기 | 자격증·어학 준비 | 안 쓰는 물건 정리 |
| 개강 전 (2월) | 학기 중 알바 찾기 | 전공 선행 | 전공책 사고팔기 |
| 기말고사 (12월 초) | — | 시험 대비 | — |

### 게시 예시 (가상의 앱으로 채운 모습)
```
[광고] 수능 끝나고 겨울방학에 동네 단기 알바 찾기
캠퍼스잡 알바 매칭 신규 가입 후 첫 지원 시 편의점 상품권 3,000원
만 18세 이상 신규 가입자
https://adpick.co.kr/?ac=…
```

## 이 주제에서 특히 주의 (미성년자 포함 대상)
| 항목 | 내용 |
|---|---|
| 나이 조건 | 수험생 상당수가 만 18세 이하 → 상세의 **가입 가능 나이**를 `{대상}`에 반드시 적음. 만 14세 미만은 법정대리인 동의 필요 |
| 유료 구독 학습앱 | 미성년자 대상 자동결제 홍보는 피함 (민법상 미성년자 계약 취소 가능 → 캠페인 무효·분쟁) |
| 알바 앱 | "고수익 알바", "하루 ○만 원" 금지 (게시기 자동 차단 대상 + 청소년 유해 광고 오인) |
| 수능 날짜 | 수능 당일·전날 게시는 피함 (수험생 대상 광고 반감). 날짜는 교육부 공고로 확인 |
| 성적·합격 표현 | "성적 ○등급 상승", "합격 보장" 금지 (근거 없는 효과 표시) |

## 운영 순서
| 시점 | 쓸 초안 |
|---|---|
| 수능 다음 주~ | 1 상황형 (수능 끝나고) |
| 12월 중순~ | 1 상황형 (겨울방학) ↔ 4 질문형 |
| 조건이 까다로운 캠페인 | 3 조건 공개형 먼저 |
| 중간중간 채움용 | 2 혜택 요약, 5 짧은 한 줄 |
→ 1~4순위와 번갈아 하루 3건 안에서 배분됨

## campaigns.csv 입력 양식 (AI 자동 초안용)
```
name,url,benefit,target,deadline,notes,active
{앱이름} 가입,{애드픽 홍보 링크},{혜택 — 상세 문구 그대로},{대상 — 가입 가능 나이 포함},{마감일 YYYY-MM-DD},"용도: {용도} / 조건: {조건} / 시즌: {시즌} / 고수익·합격 보장 표현 금지",y
```
