# 유튜브 쇼츠 대본 — 1~5순위

## 공통 규칙
| 항목 | 내용 |
|---|---|
| 길이 | 목표 **35~45초** (내레이션 약 200~250자, 초당 5~6음절 기준) |
| 첫 2초 | 문제 상황 한 문장 + 큰 자막 (스크롤 멈추게) |
| 광고 표시 | ① 업로드 시 **고급 설정 → '유료 프로모션 포함' 체크** (유튜브 정책) ② 영상 **처음부터 끝까지 화면 상단 '광고' 자막** ③ 설명란 첫 줄 `[광고]` — 공정위 지침: 동영상은 시작 부분 + 반복 표시 |
| 링크 | 쇼츠 설명란·댓글 링크는 클릭 안 됨 → **채널 프로필 링크**에 애드픽 홍보 링크, 영상에서는 "프로필 링크" 안내 |
| 화면 소스 | 게임 영상·웹툰 원고·OTT 화면 사용 금지(저작권) → 자막 애니메이션, 아이콘, **본인 휴대폰 설정 화면 녹화**만 사용. 게임사 공식 영상은 캠페인 상세에 사용 허용이 있을 때만 |
| 목소리 | 직접 녹음 또는 TTS (TTS면 설명란에 표기 불필요, 단 지어낸 체험 문구 금지) |
| 빈칸 | `{ }`는 애드픽 캠페인 상세 문구 그대로 |

## 1. 게임 사전예약 — "사전예약 보상 못 받는 이유 3가지"
| 시간 | 화면·자막 | 내레이션 |
|---|---|---|
| 0~3초 | 큰 자막: **사전예약 했는데 보상이 없다?** | 사전예약까지 했는데 보상이 안 들어왔다면, 이유는 대부분 세 가지예요. |
| 3~12초 | ① 계정 아이콘 2개 ≠ 표시 | 첫째, 예약한 계정이랑 로그인한 계정이 달라요. 구글 계정 여러 개면 어떤 걸로 예약했는지 꼭 메모하세요. |
| 12~20초 | ② 달력·모래시계 아이콘 | 둘째, 기한이 지났어요. 쿠폰 입력 기간이랑 우편함 보관 기간이 따로 있는 경우가 많아요. |
| 20~27초 | ③ 캐릭터 1개에 선물 상자 | 셋째, 보상이 첫 캐릭터에만 들어가는 게임도 있어요. 서버 고르기 전에 출시 공지부터 보세요. |
| 27~38초 | 캠페인 카드: {게임명} / {보상} / 출시 {출시일} | 지금 {게임명} 사전예약하면 {보상}을 받을 수 있어요. 출시는 {출시일}이에요. |
| 38~42초 | "프로필 링크 ↑" + 저장 아이콘 | 사전예약 링크는 프로필에 있어요. 출시 날 보려면 저장해 두세요. |

- **제목**: 사전예약 보상 못 받는 이유 3가지 #Shorts
- **설명란**: `[광고] 애드픽 캠페인 참여 영상입니다. {게임명} 사전예약 링크는 채널 프로필에 있습니다. 보상·일정은 게임사 공지 기준.`
- **해시태그**: #사전예약 #모바일게임 #{게임명}

## 2. 앱테크 — "앱테크 깔기 전에 이것부터"
| 시간 | 화면·자막 | 내레이션 |
|---|---|---|
| 0~3초 | 큰 자막: **포인트 모았는데 출금이 안 된다?** | 앱테크 포인트 열심히 모았는데 출금이 안 된 적 있으세요? |
| 3~11초 | 지갑 아이콘 + "최소 출금 금액" | 앱 깔기 전에 최소 출금 금액부터 보세요. 얼마부터 출금되는지, 현금인지 기프티콘인지요. |
| 11~18초 | 모래시계 + "유효기간" | 그리고 포인트 유효기간. 출금 기준 닿기 전에 소멸되면 헛수고예요. |
| 18~26초 | 휴대폰 권한 팝업 녹화 + ✕ | 만보기 앱이 연락처 권한을 달라고 하면 거부하세요. 기능에 필요한 권한만 주면 돼요. |
| 26~31초 | 🚫 "돈 먼저 넣으면 더 번다" | 돈 먼저 넣으라는 앱은 리워드 앱이 아니라 사기예요. |
| 31~40초 | 캠페인 카드: {앱이름} / {가입보상} / 출금 {출금조건} | {앱이름}은 신규 가입하면 {가입보상}, 출금 조건은 {출금조건}이에요. |
| 40~43초 | "프로필 링크 ↑" | 조건 맞으면 프로필 링크에서 시작하세요. |

- **제목**: 앱테크 시작 전 꼭 볼 2가지 #Shorts
- **설명란**: `[광고] 애드픽 캠페인 참여 영상입니다. {앱이름} 링크는 채널 프로필에 있습니다. 적립액은 사용 방식에 따라 다릅니다.`
- **해시태그**: #앱테크 #짠테크 #리워드앱

## 3. 쇼핑 첫 구매 — "첫 구매 쿠폰 적용 불가 안 뜨게"
| 시간 | 화면·자막 | 내레이션 |
|---|---|---|
| 0~3초 | 결제 화면 + 빨간 자막 **적용 불가** | 첫 구매 쿠폰, 결제할 때 적용 불가 뜬 적 있죠? |
| 3~10초 | ① "○○원 이상" | 첫째, 최소 주문 금액. 원래 사려던 물건으로 맞추세요. |
| 10~17초 | ② 특가 태그에 ✕ | 둘째, 특가 상품이나 일부 브랜드는 쿠폰이 안 먹히는 경우가 많아요. |
| 17~24초 | ③ 달력 | 셋째, 유효기간. 세일 날 쓰려고 아끼다가 만료되는 경우가 제일 많아요. |
| 24~30초 | "행사 할인 + 쿠폰 = ?" | 블프 같은 행사 땐 행사 할인이랑 쿠폰이 중복 안 될 수도 있어요. |
| 30~39초 | 캠페인 카드: {쇼핑몰} / {첫구매혜택} / {최소주문} | 지금 {쇼핑몰}은 첫 구매면 {첫구매혜택}이에요. 조건은 {최소주문}. |
| 39~42초 | "프로필 링크 ↑" | 링크는 프로필에 있어요. |

- **제목**: 첫 구매 쿠폰 '적용 불가' 안 뜨게 하는 법 #Shorts
- **설명란**: `[광고] 애드픽 캠페인 참여 영상입니다. {쇼핑몰} 링크는 채널 프로필에 있습니다. 혜택 조건은 쇼핑몰 안내 기준.`
- **해시태그**: #쇼핑꿀팁 #첫구매혜택 #연말세일

## 4. 웹툰·OTT 무료체험 — "무료체험 자동결제 피하는 법"
| 시간 | 화면·자막 | 내레이션 |
|---|---|---|
| 0~3초 | 카드 명세서 + **구독료 결제됨** | 무료체험만 하려다 구독료 나간 적 있으세요? |
| 3~9초 | 달력 알림 설정 녹화 | 신청한 날 바로, 끝나는 날 2일 전에 알림을 걸어 두세요. |
| 9~20초 | 휴대폰 화면 녹화: 플레이 스토어 › 결제 및 정기 결제 / 아이폰 설정 › 구독 | 해지 위치는 결제한 곳마다 달라요. 안드로이드는 플레이 스토어 정기 결제, 아이폰은 설정의 구독 메뉴예요. |
| 20~27초 | 해지 화면 "○월 ○일까지 이용 가능" 강조 | 해지해도 종료일까지 볼 수 있다고 나오면, 가입하자마자 해지하는 게 제일 안전해요. |
| 27~31초 | 앱 삭제 아이콘 + ⚠️ | 앱을 지워도 구독은 안 없어져요. |
| 31~41초 | 캠페인 카드: {서비스} / {무료혜택} / ※ {전환조건} | 지금 {서비스}는 {무료혜택}. 체험이 끝나면 {전환조건}이니까 종료일 꼭 챙기세요. |
| 41~44초 | "프로필 링크 ↑" | 링크는 프로필에 있어요. |

- **제목**: 무료체험 자동결제 안 당하는 법 #Shorts
- **설명란**: `[광고] 애드픽 캠페인 참여 영상입니다. {서비스} 링크는 채널 프로필에 있습니다. ※ {전환조건}`
- **해시태그**: #무료체험 #구독해지 #웹툰 (OTT면 #OTT)
- 화면 녹화는 **본인 휴대폰 설정 화면**만 (결제 정보·이메일은 모자이크)

## 5. 수험생·대학생 — "수능 끝나고 첫 알바 전에 이것만"
| 시간 | 화면·자막 | 내레이션 |
|---|---|---|
| 0~3초 | 큰 자막: **수능 끝! 첫 알바 전에 이것만** | 수능 끝나고 첫 알바 구한다면, 지원 전에 이것만 확인하세요. |
| 3~12초 | "만 18세 미만?" + 동의서 아이콘 | 생일 전이면 만 열일곱 살일 수 있어요. 만 18세 미만이면 부모님 동의서랑 가족관계증명서가 필요해요. |
| 12~18초 | 계약서 아이콘 | 근로계약서는 첫날 서면으로 받고 사진으로도 남겨 두세요. |
| 18~23초 | 큰 숫자 **10,320원** | 2026년 최저시급은 만 삼백이십 원이에요. |
| 23~32초 | 🚫 통장 / 현금 봉투 / 입금 | 통장만 빌려 달라, 현금만 전달해 달라는 알바는 보이스피싱이에요. 본인이 처벌받을 수 있어요. |
| 32~40초 | 캠페인 카드: {앱이름} / {혜택} / 대상 {대상} | 알바 찾을 땐 {앱이름}도 있어요. {혜택}. 대상은 {대상}이에요. |
| 40~43초 | "프로필 링크 ↑" + 저장 | 링크는 프로필에, 체크리스트는 저장해 두세요. |

- **제목**: 수능 끝나고 첫 알바 전에 꼭 확인할 것 #Shorts
- **설명란**: `[광고] 애드픽 캠페인 참여 영상입니다. {앱이름} 링크는 채널 프로필에 있습니다. 법 기준: 근로기준법(2026년 11월 기준), 최신 기준은 고용노동부 확인.`
- **해시태그**: #수능끝 #첫알바 #최저시급
- 2027-01-01 이후 최저시급 금액 수정 필요
