# 쇼핑 앱 첫 구매 혜택 트윗 초안 (3순위)

- 애드픽 캠페인 상세를 보고 `{ }` 빈칸만 채워 쓰면 됨. 할인액·적용 조건은 **상세 문구 그대로** 적을 것
- `[광고]` 표시와 홍보 링크는 게시할 때 자동으로 붙음 → 본문만 고르면 됨
- 빈칸(`{…}`)이 남은 글은 게시기가 자동으로 막음
- 길이 확인: 긴 쇼핑몰명·혜택(예: 「첫 구매 10,000원 할인 쿠폰+무료배송」)을 넣어도 최대 148/280

## 초안 5종 (접근 방식별)
| # | 방식 | 본문 | 예상 길이 |
|---|---|---|---|
| 1 | 혜택 요약 | {쇼핑몰} {대상} 혜택<br>{첫구매혜택}<br>#첫구매 | 약 115 |
| 2 | **조건 공개형 (권장)** | {쇼핑몰} {첫구매혜택}<br>적용 조건: {최소주문}<br>{마감일}까지 | 약 130 |
| 3 | 시즌형 | {행사명} 장보기 전에<br>{쇼핑몰} 첫 구매면 {첫구매혜택}<br>기간: {기간} | 약 150 |
| 4 | 질문형 | {쇼핑몰} 아직 안 써본 분?<br>가입 후 첫 구매 시 {첫구매혜택}<br>#첫구매 | 약 120 |
| 5 | 짧은 한 줄 | {쇼핑몰} 첫 구매 {첫구매혜택} ({최소주문}) | 약 120 |

- 2번 권장 이유: 쿠폰은 "최소 주문 금액·적용 카테고리" 때문에 막히는 경우가 많음 → 조건을 같이 적어야 클릭 후 이탈이 줄어듦

### 게시 예시 (가상의 쇼핑몰로 채운 모습)
```
[광고] 마켓스퀘어 프리미엄 첫 구매 10,000원 할인 쿠폰+무료배송
적용 조건: 20,000원 이상 결제 시
12월 1일까지
https://adpick.co.kr/?ac=…
```

## 11~12월 시즌 활용 (3번 시즌형)
| 행사 | 시기 (2026) | 비고 |
|---|---|---|
| 블랙프라이데이 | 11/27(금) 전후 1주 | 쇼핑몰별 행사 기간 다름 → 상세 확인 |
| 사이버먼데이 | 11/30(월) | |
| 연말 세일·크리스마스 선물 | 12월 1~3주 | "선물 준비 전에"로 문구 변경 |
| 연초 신학기·설 준비 | 1월 | 다음 시즌 |
- 쇼핑몰 자체 행사가 아니면 `{행사명}`에 "블프"를 쓰지 말고 "연말 장보기 전에"처럼 일반 표현 사용 (행사 연관 오인 방지)

## 운영 순서
| 시점 | 쓸 초안 |
|---|---|
| 첫 게시 | 2 조건 공개형 |
| 행사 주간 | 3 시즌형 |
| 이후 번갈아 | 1 혜택 요약 ↔ 4 질문형 |
| 중간중간 채움용 | 5 짧은 한 줄 |
→ 게임·앱테크와 번갈아 하루 3건 안에서 배분됨

## 피할 표현
| 피할 것 | 이유 |
|---|---|
| "최저가", "역대급 할인", "최대 ○○% 할인" | 근거 없는 최상급·최대치 강조 → 표시광고법 위반 소지 (게시기가 "최저가 보장" 자동 차단) |
| "선착순 마감 임박" | 상세에 수량 제한이 없으면 허위 → 자동 차단 |
| 정가 대비 할인율 계산해 넣기 | 기준 가격이 달라지면 허위 광고 |
| 특정 상품 가격 언급 | 가격 변동 → 게시 시점에 틀릴 수 있음 |

## campaigns.csv 입력 양식 (AI 자동 초안용)
```
name,url,benefit,target,deadline,notes,active
{쇼핑몰} 첫 구매,{애드픽 홍보 링크},{첫구매혜택 — 상세 문구 그대로},{대상},{마감일 YYYY-MM-DD},"적용 조건: {최소주문} / 행사: {행사명} {기간} / 최저가·할인율 표현 금지",y
```
