# 인스타그램 글 초안 — 1~5순위 (카드뉴스 + 캡션 + 스토리)

## 공통 규칙
| 항목 | 내용 |
|---|---|
| 형식 | **카드뉴스(캐러셀) 6~7장** + 캡션 + 스토리 1장 (정보형이 저장·공유가 잘 됨) |
| 링크 | 캡션 링크는 클릭 안 됨 → **프로필 링크** 또는 **스토리 링크 스티커**에 애드픽 홍보 링크 |
| 광고 표시 | ① 1번 카드 상단 `광고` 표기 ② 캡션 **첫 줄** `[광고]` ③ 스토리 상단 `광고` — 공정위 지침: 해시태그 사이에 묻히지 않게 첫 부분에 표시 |
| 해시태그 | 캡션 맨 끝 3~5개 (인스타그램 공식 권장 범위) |
| 카드 문구 | 장당 제목 1줄 + 본문 2~4줄 (휴대폰 화면 기준 큰 글씨) |
| 사진·이미지 | 게임·작품 이미지 사용 금지(저작권) → 텍스트·아이콘 중심 디자인 |
| 빈칸 | `{ }`는 애드픽 캠페인 상세 문구 그대로 |

## 1. 게임 사전예약

### 카드뉴스
| 장 | 제목 | 본문 |
|---|---|---|
| 1 | 사전예약 보상, 못 받는 이유 3가지 | (상단 작게) 광고<br>예약해 놓고 출시 날 보상이 없다면? |
| 2 | ① 계정이 달라요 | 사전등록한 구글 계정 ≠ 로그인한 계정<br>→ 예약 계정을 메모해 두세요 |
| 3 | ② 기한이 지났어요 | 쿠폰 입력 기간, 우편함 보관 기간이 따로<br>→ 출시일에 달력 알림 |
| 4 | ③ 캐릭터 단위 보상이에요 | 첫 캐릭터·특정 서버에만 지급되는 게임도<br>→ 출시 공지 먼저 읽기 |
| 5 | 이런 DM은 무시 | "보상 대리 수령해 드려요"<br>= 계정 도용 위험 |
| 6 | 지금 사전예약 중 | {게임명}<br>보상: {보상}<br>출시 {출시일} · 마감 {마감일} |
| 7 | 저장해 두고 출시 날 확인 📌 | 링크는 프로필에 |

### 캡션
```
[광고] 애드픽 캠페인 참여 게시물입니다.

사전예약해 놓고 보상 못 받는 이유, 대부분 3가지예요 🎮
① 예약 계정과 로그인 계정이 다름
② 쿠폰·우편함 기한 지남
③ 캐릭터 단위 보상인 줄 모름

지금 사전예약 중인 {게임명}은
예약 보상 {보상}, {출시일} 출시 예정이에요.
사전예약 링크는 프로필에 있어요.

#사전예약 #신작게임 #모바일게임 #{게임명}
```

### 스토리
```
광고
{게임명} 사전예약
보상: {보상}
{마감일}까지
[링크 스티커: 사전예약 하기 → {애드픽 홍보 링크}]
```

## 2. 앱테크

### 카드뉴스
| 장 | 제목 | 본문 |
|---|---|---|
| 1 | 앱테크 시작 전 꼭 볼 2가지 | (상단 작게) 광고<br>출금 조건 · 포인트 유효기간 |
| 2 | 최소 출금 금액 | 얼마부터 출금되는지<br>현금인지 기프티콘인지 |
| 3 | 포인트 유효기간 | 출금 기준 닿기 전에 소멸되면 헛수고<br>미접속 소멸 조건도 체크 |
| 4 | 앱 권한 체크 | 만보기 앱이 연락처를 달라고 하면?<br>→ 거부 |
| 5 | 내 숫자로 판단 | 일주일만 '쓴 시간 / 모은 포인트' 기록 |
| 6 | 이건 사기 🚫 | "돈 먼저 넣으면 더 번다"<br>정상 리워드 앱은 입금 요구 안 함 |
| 7 | 이번 달 가입 혜택 | {앱이름}<br>가입 보상 {가입보상}<br>출금 조건 {출금조건} |

### 캡션
```
[광고] 애드픽 캠페인 참여 게시물입니다.

앱테크 앱 깔기 전에 출금 조건부터 보세요 💸
✔ 최소 출금 금액
✔ 포인트 유효기간
✔ 앱 권한 (기능에 필요한 것만)

{앱이름}은 신규 가입 시 {가입보상},
출금 조건은 {출금조건}이에요.
조건 확인하고 맞으면 프로필 링크에서 시작하세요.

#앱테크 #리워드앱 #짠테크 #포인트적립
```

### 스토리
```
광고
{앱이름} 가입 보상 {가입보상}
출금 조건: {출금조건}
[링크 스티커: 가입하기 → {애드픽 홍보 링크}]
```

## 3. 쇼핑 첫 구매

### 카드뉴스
| 장 | 제목 | 본문 |
|---|---|---|
| 1 | 첫 구매 쿠폰 '적용 불가' 안 뜨게 | (상단 작게) 광고<br>결제 전 3가지 체크 |
| 2 | ① 최소 주문 금액 | ○○원 이상 구매 조건<br>원래 살 물건으로 맞추기 |
| 3 | ② 적용 제외 상품 | 특가·일부 브랜드는 빠지는 경우 많음 |
| 4 | ③ 유효기간 | 발급 후 며칠 안에만<br>행사일보다 만료가 먼저인지 확인 |
| 5 | 블프·연말 세일 주의 | 행사 할인 + 쿠폰<br>중복 안 되는 경우 있음 |
| 6 | 비교는 최종 결제 금액으로 | 배송비·카드 할인 포함 금액 |
| 7 | 지금 첫 구매 혜택 | {쇼핑몰}<br>{첫구매혜택}<br>조건 {최소주문} · {마감일}까지 |

```
[광고] 애드픽 캠페인 참여 게시물입니다.

✔ 최소 주문 금액
✔ 적용 제외 상품
✔ 유효기간

{쇼핑몰} 첫 구매 혜택: {첫구매혜택}
적용 조건: {최소주문} / {마감일}까지
링크는 프로필에 있어요.

#첫구매혜택 #쇼핑꿀팁 #연말세일 #쿠폰
```

## 4. 웹툰·OTT 무료체험

### 카드뉴스
| 장 | 제목 | 본문 |
|---|---|---|
| 1 | 무료체험 자동결제 안 당하는 법 | (상단 작게) 광고<br>신청한 날 5분이면 끝 |
| 2 | ① 종료일 달력에 | 끝나기 2일 전 알림 |
| 3 | ② 결제한 곳 확인 | 구글 플레이 / 앱스토어 / 웹<br>해지 위치가 다 달라요 |
| 4 | 해지 위치 | 플레이 스토어 › 결제 및 정기 결제<br>아이폰 설정 › 내 이름 › 구독<br>웹 › 멤버십 관리 |
| 5 | ③ 바로 해지해도 될까? | "○월 ○일까지 이용 가능"이 뜨면<br>→ 가입 직후 해지가 가장 안전 |
| 6 | 앱 삭제 ≠ 구독 해지 ⚠️ | 앱 지워도 결제는 계속돼요 |
| 7 | 지금 무료체험 | {서비스}<br>{무료혜택}<br>※ {전환조건} |

### 캡션
```
[광고] 애드픽 캠페인 참여 게시물입니다.

무료체험 신청한 날, 이것만 해 두면 자동결제 걱정 없어요 📺
✔ 종료일 달력에 (2일 전 알림)
✔ 결제한 곳 확인 (해지 위치가 다름)
✔ 지금 해지해도 끝까지 볼 수 있는지 확인

{서비스} {무료혜택}
※ {전환조건}
링크는 프로필에 있어요.

#무료체험 #웹툰추천 #OTT #구독관리
```

### 스토리
```
광고
{서비스} {무료혜택}
※ {전환조건}
[링크 스티커: 체험 신청 → {애드픽 홍보 링크}]
```
