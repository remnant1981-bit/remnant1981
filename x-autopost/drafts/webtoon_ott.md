# 웹툰·웹소설·OTT 무료체험 트윗 초안 (4순위)

- 애드픽 캠페인 상세를 보고 `{ }` 빈칸만 채워 쓰면 됨. 무료 혜택·자동결제 조건은 **상세 문구 그대로** 적을 것
- `[광고]` 표시와 홍보 링크는 게시할 때 자동으로 붙음 → 본문만 고르면 됨
- 빈칸(`{…}`)이 남은 글은 게시기가 자동으로 막음
- 길이 확인: 긴 서비스명·혜택(예: 「신규 가입 시 쿠키 30개+14일 무료 이용권」)과 자동결제 문구를 넣어도 최대 144/280

## 초안 5종 (접근 방식별)
| # | 방식 | 본문 | 예상 길이 |
|---|---|---|---|
| 1 | 혜택 요약 | {서비스} {대상} 혜택<br>{무료혜택}<br>#웹툰 (OTT면 #OTT) | 약 115 |
| 2 | **조건 공개형 (필수급)** | {서비스} {무료혜택}<br>※ {전환조건} | 약 145 |
| 3 | 작품형 | {대표작} 정주행할 분?<br>{서비스} {무료혜택} | 약 120 |
| 4 | 시즌형 | {시즌} 정주행 준비<br>{서비스} {무료혜택}<br>{마감일}까지 | 약 125 |
| 5 | 짧은 한 줄 | {서비스} {무료혜택} ({마감일}까지) | 약 105 |

- **2번이 사실상 필수**: 무료체험 → 유료 자동 전환 구독은 소비자 불만·신고가 가장 많은 유형 (2025년 전자상거래법 개정으로 사업자의 유료 전환 사전 고지 의무화) → 자동결제가 있는 캠페인이면 **첫 게시를 2번으로**, 다른 초안에도 가능하면 `※ 체험 후 자동결제` 한 줄 추가
- 자동결제가 없는 혜택(쿠키·코인 지급만)이면 `{전환조건}` 자리에 "추가 결제 없음"처럼 상세 기준으로 적음

### 게시 예시 (가상의 서비스로 채운 모습)
```
[광고] 스토리온 웹툰 플러스 신규 가입 시 쿠키 30개+14일 무료 이용권
※ 체험 종료 후 월 9,900원 자동결제 (해지 시 미청구)
https://adpick.co.kr/?ac=…
```

## 3번 작품형 주의
- `{대표작}`은 **캠페인 상세나 해당 서비스에 실제로 있는 작품**만 적음 (독점 종료·서비스 지역 제한으로 없는 경우 있음)
- 작품 이미지·캐릭터 그림은 첨부하지 않음 (저작권) — 텍스트로 작품명만 언급
- 줄거리·결말 언급 금지 (스포일러 신고 대상)

## 시즌 활용 (4번 시즌형)
| `{시즌}` | 시기 |
|---|---|
| 수능 끝난 수험생 | 11월 하순 |
| 겨울방학 | 12월 하순~2월 |
| 연말 연휴 | 12/24~1/1 |
| 설 연휴 | 2027-02 초 (날짜는 게시 전 확인) |

## 운영 순서
| 시점 | 쓸 초안 |
|---|---|
| 첫 게시 | 2 조건 공개형 |
| 방학·연휴 앞 | 4 시즌형 |
| 이후 번갈아 | 1 혜택 요약 ↔ 3 작품형 |
| 중간중간 채움용 | 5 짧은 한 줄 |
→ 1~3순위와 번갈아 하루 3건 안에서 배분됨

## 피할 표현
| 피할 것 | 이유 |
|---|---|
| "완전 무료", "평생 무료" | 자동결제가 있으면 허위 ("평생"은 게시기 자동 차단) |
| 자동결제 조건 생략 | 소비자 기만 소지, 클릭 후 신고·이탈 |
| "○○ 작품 독점", "여기서만" | 독점 여부는 바뀜 → 상세에 있을 때만 |
| 불법 공유 사이트와 비교 ("○○○ 대신") | 플랫폼·애드픽 규정 위반 가능 |
