# 게임 사전예약 트윗 초안 (1순위)

- 애드픽 캠페인 상세를 보고 `{ }` 빈칸만 채워 쓰면 됨. 보상·일정은 **상세 문구 그대로** 적을 것 (지어내면 표시광고법 위반 소지)
- `[광고]` 표시와 홍보 링크는 게시할 때 자동으로 붙음 → 본문만 고르면 됨
- 빈칸(`{…}`)이 남은 글은 게시기가 자동으로 막음
- 길이 확인: 긴 게임명·보상(예: 「5,000 다이아+전설 장비 상자」)을 넣어도 최대 140/280

## 초안 5종 (접근 방식별)
| # | 방식 | 본문 | 예상 길이 |
|---|---|---|---|
| 1 | 혜택 요약 | {게임명} 사전예약 진행 중<br>예약만 해도 {보상} 지급<br>#사전예약 | 약 120 |
| 2 | 질문형 | {장르} 새로 할 거 찾는 분?<br>{게임명} 사전예약하면 {보상}<br>{출시일} 출시 예정 | 약 140 |
| 3 | 마감 안내 | {게임명} 사전예약 {마감일} 마감<br>예약 보상: {보상}<br>#사전예약 | 약 120 |
| 4 | 출시 임박 | {게임명} {출시일} 출시<br>지금 사전예약하면 {보상}<br>{플랫폼} 지원 | 약 130 |
| 5 | 짧은 한 줄 | {게임명} 사전예약 보상 {보상}, {출시일} 출시 전까지 | 약 115 |

### 게시 예시 (가상의 게임으로 채운 모습)
```
[광고] 엘리시온 크로니클 사전예약 진행 중
예약만 해도 5,000 다이아+전설 장비 상자 지급
#사전예약
https://adpick.co.kr/?ac=…
```

## 운영 순서
| 시점 | 쓸 초안 |
|---|---|
| 사전예약 시작 ~ 중반 | 1 혜택 요약 → 2 질문형 |
| 마감 3일 전 | 3 마감 안내 |
| 출시 1~2일 전 | 4 출시 임박 |
| 중간중간 채움용 | 5 짧은 한 줄 |
→ 같은 캠페인은 하루 1건 (게시기 기본 설정), 같은 문구는 다시 안 올라감

## 피할 표현
- "무조건", "100% 지급", "역대급", "최고 보상" (과장)
- "저도 해봤는데" 같은 지어낸 체험
- 상세에 없는 보상 금액·확률·순위

## campaigns.csv 입력 양식 (AI 자동 초안용)
```
name,url,benefit,target,deadline,notes,active
{게임명} 사전예약,{애드픽 홍보 링크},{보상 — 상세 문구 그대로},{플랫폼·대상},{마감일 YYYY-MM-DD},"장르: {장르} / 출시일: {출시일}",y
```
