# 핀터레스트 핀 초안 — 1~5순위

## 운영 방식: 핀 → 내 블로그 글 → 애드픽 링크
| 항목 | 내용 |
|---|---|
| 핀 링크 | 애드픽 링크를 핀에 직접 걸지 않고 **티스토리 글 주소**로 연결 (`tistory-autopost/drafts/adpick/` 글). 핀터레스트는 리디렉션·추적 링크를 스팸으로 판단하는 경우가 있어 블로그 경유가 안전 |
| 광고 표시 | 연결되는 블로그 글에 수수료 고지 있음 + 핀 설명 끝에 "제휴 링크가 포함된 글로 연결됩니다" |
| 성격 | 핀터레스트는 **이미지 검색 엔진** → 제목·설명에 검색어(키워드)를 자연스럽게 |
| 이미지 | 세로 2:3 (1000×1500), 큰 제목 + 체크리스트형 인포그래픽. 게임·작품 이미지 사용 금지(저작권) |
| 글자 수 | 제목 최대 100자, 설명 최대 500자 |
| 새 핀 | 같은 글이라도 **이미지 문구를 바꾼 핀 2개**를 며칠 간격으로 (아래 A·B) |
| 국내 이용층 | 20~30대 비중 높음, 생활·정리·체크리스트 콘텐츠 반응 좋음 → 3·4·2·5 순으로 우선 |

## 보드 구성
| 보드 이름 | 들어갈 핀 |
|---|---|
| 생활비 아끼는 체크리스트 | 쇼핑 쿠폰, 구독 정리, 앱테크 |
| 대학생·사회초년생 가이드 | 첫 알바, 근로계약 |
| 모바일 게임 소식 | 게임 사전예약 |
