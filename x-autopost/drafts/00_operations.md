# 애드픽 홍보 통합 운영표 (12개 채널)

## 1. 채널 우선순위 — 한 번에 다 하지 말고 단계적으로
| 단계 | 채널 | 노력 | 자동화 | 위험 | 비고 |
|---|---|---|---|---|---|
| **1단계 (1주차~)** | X | 낮음 | ✅ 자동/반자동 (`x_poster.py`) | 낮음 | 대기열에 넣으면 끝 |
| | 티스토리 | 중간 | ✅ 자동 발행 (`tistory-autopost`) | 낮음 | 다른 채널의 연결 거점 |
| **2단계 (3주차~)** | 네이버 블로그 | 중간 | 수동 복붙 | 낮음 | 티스토리와 **다른 글** 사용 (유사문서 방지) |
| | 스레드 | 낮음 | 수동 | 낮음 | 연결글 3~4개 |
| **3단계 (5주차~)** | 인스타그램 | 높음 (카드 제작) | 수동 | 낮음 | Canva 카드뉴스 필요 |
| | 핀터레스트 | 중간 | 수동 | 낮음 | 티스토리 글 주소 필요 |
| | 페이스북 | 낮음 | 수동 (인스타 연동 가능) | 낮음 | 페이지에서만 |
| **4단계 (선택)** | 유튜브 쇼츠 | 높음 (영상) | 수동 | 중간 | '유료 프로모션' 체크 필수 |
| | 틱톡 | 높음 (영상) | 수동 | 중간 | 브랜디드 콘텐츠·CML 음원, 링크는 팔로워 1,000명부터 |
| **내 커뮤니티** | 카카오 오픈채팅 | 중간 (운영) | 수동 | **높음** | 내 방에서만, (광고)·08~21시 |
| | 네이버 밴드 | 중간 (운영) | 수동 | **높음** | 내 밴드에서만, 40~60대 맞춤 |
| **비권장** | 링크드인 | — | — | 본업 평판 | 사이드 프로젝트 회고(A)만 |

→ **처음 2주는 X + 티스토리만**. 애드픽 리포트에서 채널별 유입이 보이면 다음 단계 추가

## 2. 캠페인 정보 카드 — 한 번 채우면 모든 채널 빈칸에 사용
```
캠페인명      : {캠페인명}
홍보 링크     : {애드픽 홍보 링크}
혜택(원문)    : {캠페인 상세 문구 그대로}
대상·나이     : {대상 — 가입 가능 나이 포함}
조건          : {최소주문 / 출금조건 / 적용 제외 등}
자동결제      : {전환조건 — 없으면 "없음"}
일정          : 마감 {마감일} / 출시 {출시일}
홍보 허용 매체 : {캠페인 상세의 허용·금지 채널}
금지 문구     : {캠페인 상세의 금지 표현}
```
- **홍보 허용 매체를 먼저 확인** → 금지된 채널은 아래 전개표에서 제외
- 이 카드를 전달하면 Claude가 해당 주제의 모든 채널 초안 빈칸을 한 번에 채움
