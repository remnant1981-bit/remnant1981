# 링크드인 글 초안

## 먼저: 링크드인은 애드픽 홍보와 잘 안 맞음
| 항목 | 내용 |
|---|---|
| 채널 성격 | 직무·경력 중심 네트워크. 게임·쇼핑·앱테크 제휴 링크는 **커뮤니티 정책상 '관련 없는 홍보성 콘텐츠'**로 신고·노출 제한될 수 있음 |
| 평판 | 링크드인 프로필 = 실명·소속(책임연구원) 노출 → 제휴 홍보 글이 **본업 평판에 영향** |
| 겸업 규정 | 회사 취업규칙의 **겸업·부업 신고 규정**을 먼저 확인 (애드픽 수익은 부업 소득) |
| 결론 | 1~4순위 주제는 **링크드인 사용 안 함** 권장. 아래 3개 초안만 선택적으로 사용 |

| 초안 | 내용 | 애드픽 링크 |
|---|---|---|
| A | 사이드 프로젝트 회고 — 이번에 만든 SNS 자동 게시 도구 | **없음** (기술·업무 자동화 경험 공유) |
| B | 첫 근로계약 체크리스트 (대학생·신입·채용 담당자 대상) | 선택 — 넣으면 댓글에, `[광고]` 표시 |
| C | 직장인 구독 정리법 | 선택 — 넣으면 댓글에, `[광고]` 표시 |

## A. 사이드 프로젝트 회고 (권장)
> 실제로 만든 내용만 적음. 수익·조회수 같은 결과 수치는 **실제 데이터가 생긴 뒤에만** 추가

```
퇴근 후 사이드 프로젝트로 'SNS 게시 자동화 도구'를 만들었습니다.

블로그·X(트위터)에 정보성 글을 꾸준히 올리고 싶었는데, 매번 문구를 쓰고 규칙을 지키는 일이 반복 작업이었습니다.
그래서 반복되는 부분을 코드로 옮겼습니다.

🔧 구성
· 글 초안: Claude API로 초안 생성 → 대기열 파일로 저장 (사람이 검토·수정)
· 게시: GitHub Actions 정기 실행, X API 또는 휴대폰 알림으로 작성 화면 전달
· 언어/도구: Python, GitHub Actions

✅ 신경 쓴 부분 — '자동화할수록 규칙은 코드로'
· 광고 표시: 제휴 링크가 있는 글은 첫머리에 [광고]를 자동 삽입 (공정위 추천·보증 심사지침)
· 과장 표현 차단: "무조건", "100%" 등이 들어간 초안은 게시 전 자동 제외
· 게시 빈도 제한: 간격·하루 최대 건수·야간 금지를 설정값으로 관리
· 빈칸 검사: 템플릿 빈칸이 남은 글은 게시 차단
· 테스트 코드로 위 규칙을 매번 검증

💡 배운 점
연구 과제 문서 작업에서도 느꼈지만, 반복 작업 자동화의 핵심은 '빨리 만드는 것'보다 '틀리면 멈추는 장치'를 먼저 넣는 것이었습니다.

#업무자동화 #Python #GitHubActions #사이드프로젝트
```

## C. 직장인 구독 정리법
```
매달 나가는 구독료, 한 번에 찾는 4곳입니다.

1️⃣ 구글 플레이 › 결제 및 정기 결제
2️⃣ 아이폰 설정 › 내 이름 › 구독
3️⃣ 카드 명세서 — 매달 같은 금액 반복 항목 (웹에서 카드 등록한 구독은 여기서만 보임)
4️⃣ 어카운트인포(계좌정보 통합관리) — 계좌 자동이체

무료체험을 시작할 땐
· 종료일 2일 전 알림
· 결제 경로 기록
· 해지해도 종료일까지 이용 가능하면 바로 해지

앱을 삭제해도 구독은 해지되지 않습니다.

#재테크 #구독관리 #직장인
```
**(선택) 첫 댓글**
```
[광고] 지금 무료체험 되는 서비스: {서비스} — {무료혜택} (※ {전환조건})
{애드픽 홍보 링크}
애드픽 캠페인 참여 링크로, 가입 시 수수료를 받습니다.
```
