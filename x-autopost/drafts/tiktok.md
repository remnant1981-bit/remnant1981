# 틱톡 대본 — 1~5순위

## 쇼츠와 다른 점 (같은 영상 재사용 X → 형식 변경)
| 항목 | 유튜브 쇼츠 | 틱톡 |
|---|---|---|
| 길이 | 35~45초 | **20~30초** (내레이션 약 120~170자) |
| 형식 | 팁 3~4개 설명 | **한 화면 한 문장** + 빠른 컷, 화면 텍스트 중심 |
| 시작 | 문제 상황 | "○○ 하는 사람 이거 봐" 대상 지목형 / 댓글 답장형 |
| 링크 | 채널 프로필 | 프로필 링크 — **개인 계정은 팔로워 1,000명 이상**부터, 비즈니스 계정은 조건 다름 → 없으면 "검색창에 ○○" 안내 대신 **링크 있는 다른 채널(인스타·블로그) 안내** |

## 공통 규칙
| 항목 | 내용 |
|---|---|
| 광고 표시 | ① 게시 설정 **'콘텐츠 공개(Content disclosure)' → '브랜디드 콘텐츠'** 켜기 (틱톡 정책, '유료 파트너십' 라벨 표시) ② 화면 상단 '광고' 텍스트 처음~끝 ③ 캡션 첫 줄 `[광고]` |
| 음악 | 브랜디드 콘텐츠를 켜면 **상업용 음원 라이브러리(CML)** 음원만 사용 가능 → 인기 음원 대신 CML에서 선택 |
| 화면 소스 | 게임 영상·웹툰·OTT 화면 금지(저작권) → 텍스트, 아이콘, 본인 휴대폰 설정 녹화(결제 정보 모자이크) |
| 미성년자 | 틱톡은 브랜디드 콘텐츠 노출·대상에 나이 제한 정책이 있음 → **만 18세 이상 대상 캠페인만** 홍보 (5번 주제 주의) |
| 빈칸 | `{ }`는 애드픽 캠페인 상세 문구 그대로 |

## 1. 게임 사전예약 — 대상 지목형
| 시간 | 화면 텍스트 | 내레이션 |
|---|---|---|
| 0~2초 | **사전예약 해 둔 사람 이거 봐** | 사전예약 해 둔 사람, 이거 봐. |
| 2~7초 | 예약 계정 = 로그인 계정 ✅ | 출시 날 꼭 예약한 그 계정으로 로그인해야 돼요. |
| 7~12초 | 쿠폰·우편함 기한 ⏳ | 쿠폰이랑 우편함 보상은 기한 있어요. |
| 12~17초 | 서버 고르기 전 공지 📢 | 첫 캐릭터에만 주는 게임도 있으니까 공지 먼저. |
| 17~25초 | {게임명} 사전예약 중<br>{보상}<br>출시 {출시일} | 지금 {게임명} 예약하면 {보상}, {출시일} 출시예요. |
| 25~28초 | 링크 → 프로필 | 링크는 프로필에. |

- **캡션**: `[광고] 애드픽 캠페인 참여 영상. {게임명} 사전예약 보상 {보상} / {마감일}까지 #사전예약 #모바일게임 #게임추천`

## 2. 앱테크 — 댓글 답장형
> 영상 시작에 댓글 스티커: "앱테크 출금 안 되는 거 왜 그래요?" (본인 계정에 실제로 달린 댓글이 있을 때만 사용, 없으면 화면 텍스트로 대체)

| 시간 | 화면 텍스트 | 내레이션 |
|---|---|---|
| 0~3초 | **앱테크 출금 안 되는 이유** | 앱테크 출금이 안 되는 건 보통 이거 때문이에요. |
| 3~8초 | 최소 출금 금액 💳 | 최소 출금 금액, 안 보고 시작해서. |
| 8~13초 | 포인트 유효기간 ⏳ | 그리고 기준 닿기 전에 포인트가 소멸돼서. |
| 13~17초 | 🚫 입금 요구 = 사기 | 돈 먼저 넣으라는 앱은 그냥 사기예요. |
| 17~25초 | {앱이름}<br>가입 {가입보상}<br>출금 {출금조건} | {앱이름}은 가입하면 {가입보상}, 출금은 {출금조건}이에요. |
| 25~28초 | 조건 보고 시작 👉 프로필 | 조건 보고 맞으면 프로필 링크로. |

- **캡션**: `[광고] 애드픽 캠페인 참여 영상. 앱테크는 출금 조건부터 보기 #앱테크 #짠테크 #리워드앱`

## 3. 쇼핑 첫 구매 — 3초 체크리스트형
| 시간 | 화면 텍스트 | 내레이션 |
|---|---|---|
| 0~2초 | **첫 구매 쿠폰 쓰기 전 3초 체크** | 첫 구매 쿠폰 쓰기 전에 3초만. |
| 2~6초 | ☑️ 최소 주문 금액 | 최소 주문 금액. |
| 6~10초 | ☑️ 특가 상품 제외? | 특가 상품 빠지는지. |
| 10~14초 | ☑️ 유효기간 | 유효기간. |
| 14~18초 | 블프 할인 + 쿠폰 = 중복❓ | 블프 땐 행사 할인이랑 중복 안 될 수도 있어요. |
| 18~26초 | {쇼핑몰} 첫 구매<br>{첫구매혜택}<br>{최소주문} | {쇼핑몰} 첫 구매면 {첫구매혜택}, 조건은 {최소주문}이에요. |
| 26~28초 | 링크 → 프로필 | 링크는 프로필에. |

- **캡션**: `[광고] 애드픽 캠페인 참여 영상. {쇼핑몰} 첫 구매 {첫구매혜택} / {마감일}까지 #쇼핑꿀팁 #첫구매 #블프`

## 4. 웹툰·OTT 무료체험 — 화면 녹화 따라하기형
| 시간 | 화면 텍스트 | 내레이션 |
|---|---|---|
| 0~2초 | **무료체험 신청하고 바로 이거 해** | 무료체험 신청했으면 바로 이거 하세요. |
| 2~8초 | (녹화) 캘린더 알림 설정 | 끝나는 날 이틀 전에 알림. |
| 8~16초 | (녹화) 플레이 스토어 › 정기 결제 / 아이폰 설정 › 구독 | 해지는 결제한 곳에서. 안드로이드는 플레이 스토어, 아이폰은 설정 구독. |
| 16~20초 | 앱 삭제 ≠ 해지 ⚠️ | 앱 지워도 결제는 계속돼요. |
| 20~28초 | {서비스} {무료혜택}<br>※ {전환조건} | {서비스} {무료혜택}, 끝나면 {전환조건}이에요. |
| 28~30초 | 링크 → 프로필 | 링크는 프로필에. |

- **캡션**: `[광고] 애드픽 캠페인 참여 영상. ※ {전환조건} — 종료일 알림 필수 #무료체험 #구독해지 #웹툰추천`

## 5. 수험생·대학생 (알바 앱) — 경고형
> 틱톡 나이 정책 때문에 **만 18세 이상 대상 알바 앱 캠페인일 때만** 사용. 고3 중 만 17세가 많으므로 화면에 대상 나이를 크게 표시

| 시간 | 화면 텍스트 | 내레이션 |
|---|---|---|
| 0~2초 | **수능 끝나고 이런 알바 오면 거절** | 수능 끝나고 이런 알바 연락 오면 거절하세요. |
| 2~7초 | 🚫 통장·체크카드 빌려주기 | 통장만 빌려주면 일당 준다? 대포통장이에요. |
| 7~12초 | 🚫 현금·서류 전달 | 현금만 전달해 달라? 보이스피싱 수거책이에요. |
| 12~16초 | 🚫 교육비 선입금 | 교육비 먼저 내라? 연락 끊겨요. |
| 16~20초 | ✅ 계약서 + 최저시급 10,320원 | 정상 알바는 계약서 쓰고 시급 만 삼백이십 원 이상. |
| 20~27초 | {앱이름}<br>{혜택}<br>대상 {대상} | 알바 찾을 땐 {앱이름}, {혜택}. 대상은 {대상}이에요. |
| 27~29초 | 링크 → 프로필 | 링크는 프로필에. |

- **캡션**: `[광고] 애드픽 캠페인 참여 영상. 대상: {대상} / 2026년 최저시급 10,320원 기준 #첫알바 #알바사기 #수능끝`
