# 네이버 밴드 글 초안 — 1~5순위

## 먼저 확인
| 항목 | 내용 |
|---|---|
| **남의 밴드 홍보 금지** | 가입한 다른 밴드에 리더 허락 없이 홍보 링크를 올리면 밴드 운영정책상 스팸 → 강제 탈퇴·신고 시 이용 제한. 애드픽 '무단 홍보' 유입은 수익 취소 가능 |
| **내 밴드 운영** | 직접 만든 '생활 혜택 정보 밴드'에 스스로 가입한 멤버에게만 게시 |
| **(광고) 표시** | 새 글은 멤버에게 알림이 가므로 광고성 정보 전송으로 볼 수 있음 → 오픈채팅과 같이 **첫머리 (광고), 운영자 이름, 수신 거부 방법** 표시 (정보통신망법 제50조) |
| **시간** | 08:00~21:00에만 게시. 밴드 **예약 글쓰기** 기능이 보이면 낮 시간으로 예약 |
| 독자 | 밴드는 40~60대 비중이 높음 → **큰 글씨로 읽기 쉽게, 짧은 문단, 용어 풀어쓰기**. 주제도 연령에 맞게 각도 조정 (아래 표) |
| 빈칸 | `{ }`는 애드픽 캠페인 상세 문구 그대로 |

### 주제별 밴드 적합도
| 순위 | 주제 | 밴드 적합도 | 조정 방향 |
|---|---|---|---|
| 1 | 게임 사전예약 | 낮음 | 퍼즐·카드 등 **중장년층이 하는 장르 캠페인일 때만** 사용 |
| 2 | 앱테크 | **높음** | 걷기·출석형 위주 |
| 3 | 쇼핑 첫 구매 | **높음** | 장보기·생필품 |
| 4 | 웹툰·OTT | 중간 | OTT(드라마·영화) 위주, 자동결제 해지법 강조 |
| 5 | 수험생·대학생 | 중간 | **수험생 '부모' 시점** — 자녀 첫 알바 서류 챙기기 |

## 0. 내 밴드 만들기

**밴드 이름**
```
생활 혜택 정보 모음
```

**밴드 소개**
```
걷기 앱, 장보기 쿠폰, OTT 무료체험 등 생활 혜택 정보를 쉽게 정리해 올립니다.
일부 글에는 제휴(애드픽) 링크가 있으며, 링크로 가입·설치하시면 운영자가 수수료를 받을 수 있습니다.
광고 글은 (광고)로 표시하고 낮 시간(08~21시)에만 올립니다.
```

**공지 (상단 고정)**
```
📌 우리 밴드 안내

1. (광고) 표시 글에는 제휴 링크가 있습니다. 링크로 가입·설치하시면 운영자가 수수료를 받습니다.
2. 광고 글은 하루 1개 이하, 낮 시간에만 올립니다.
3. 알림을 받고 싶지 않으시면 '밴드 설정 → 알림 설정'에서 끄시거나 밴드를 탈퇴하시면 됩니다.
4. 궁금한 점은 댓글로 남겨 주세요. 캠페인 내용은 공식 안내 기준으로 답변드립니다.

운영자: {운영자 이름}
```

**게시판(카테고리)**: `생활 정보` / `혜택 소식(광고)` / `질문·답변`

## 2. 앱테크 (걷기·출석형) — 밴드 우선 주제

**정보글 (생활 정보 게시판, 광고 아님)**
```
🚶 걷기 앱, 깔기 전에 이것만 확인하세요

요즘 걸으면 포인트 주는 앱이 많지요.
시작하기 전에 세 가지만 보시면 손해 볼 일이 줄어듭니다.

① 얼마부터 돈으로 바꿀 수 있는지
   (현금으로 받는지, 기프티콘으로만 바꾸는지)

② 포인트가 언제 사라지는지
   (몇 달 지나면 없어지는 앱이 많습니다)

③ 앱이 달라는 권한
   걷기 앱이 '연락처'나 '통화 기록'을 달라고 하면 '허용 안 함'을 누르세요.

⚠️ "돈을 먼저 넣으면 더 많이 준다"는 앱은 사기입니다.

#생활정보 #걷기앱 #앱테크
```

**홍보글 (혜택 소식 게시판, 정보글 다음 날)**
```
(광고) {운영자 이름}

📲 {앱이름} 새로 가입하시면 {가입보상}

· 포인트 모으는 방법: {적립방법}
· 돈으로 바꾸는 조건: {출금조건}
· 대상: {대상}

어제 올린 '세 가지 확인'을 이 앱에도 해 보시고 시작하세요.

👉 {애드픽 홍보 링크}

알림을 원치 않으시면 밴드 설정 → 알림 설정에서 끄실 수 있습니다.
#혜택소식 #앱테크
```

## 4. OTT 무료체험 (드라마·영화)

**정보글**
```
📺 무료체험 했다가 돈 나가는 일, 이렇게 막으세요

① 신청한 날, 체험 끝나는 날을 달력에 적어 두세요
② 해지하는 곳은 결제한 곳입니다
   · 갤럭시 등 안드로이드: 플레이 스토어 → 오른쪽 위 동그라미(프로필) → 결제 및 정기 결제
   · 아이폰: 설정 → 맨 위 내 이름 → 구독
③ 앱을 지워도 결제는 계속됩니다. 꼭 '해지'를 누르세요

자녀분께 한 번 같이 봐 달라고 하셔도 좋습니다.

#생활정보 #구독해지 #OTT
```

**홍보글**
```
(광고) {운영자 이름}

📺 {서비스} 무료로 먼저 보기

· 무료 혜택: {무료혜택}
· ※ 체험이 끝나면: {전환조건}
· 기간: {마감일}까지

신청하시면 위 정보글대로 끝나는 날을 꼭 적어 두세요.

👉 {애드픽 홍보 링크}

## 5. 수험생 부모 시점 — 자녀 첫 알바

**정보글**
```

① 만 18세 미만이면 서류 2개가 필요합니다
   · 친권자(부모) 동의서 — 고용노동부 누리집 양식 또는 사업장 양식
   · 가족관계증명서 — 정부24, 무인민원발급기, 주민센터에서 발급

② 근로계약서를 첫날 서면으로 받았는지 확인해 주세요

③ 2026년 최저시급은 10,320원입니다

④ 이런 연락은 범죄입니다
   · "통장·체크카드만 빌려주면 일당"
   · "현금이나 서류만 전달해 주면 된다"
   · "교육비·유니폼비 먼저 입금"
   자녀에게 꼭 미리 알려 주세요.

상담: 고용노동부 1350
