# 페이스북 글 초안 — 1~5순위

## 먼저 확인
| 항목 | 내용 |
|---|---|
| 어디에 올리나 | **페이스북 페이지** 또는 **프로페셔널 모드 프로필**에 게시. 일반 개인 프로필을 주로 영리 목적으로 쓰는 것은 메타 이용약관 취지에 맞지 않음 |
| 그룹 | 남의 그룹에 홍보 링크 무단 게시 금지 (그룹 규칙 위반·스팸 신고 → 게시 제한). 그룹 규칙이 '정보 공유 허용'이면 **링크 없는 정보글만** |
| 광고 표시 | 본문 **첫 줄 `[광고]`** + 끝에 수수료 고지. 메타 '유료 파트너십' 라벨은 광고주 페이지를 태그해야 해서 애드픽 캠페인에선 대부분 못 씀 → 텍스트 표시가 기본 |
| 링크 | 본문 링크 클릭 가능(미리보기 카드). 링크 글은 도달이 낮다는 운영자 경험담이 많음 → 본문 짧게 + 링크 1개, 또는 **첫 댓글에 링크** 방식 선택 |
| 독자 | 국내 페이스북은 30~50대 비중이 높음 → 생활 혜택(쇼핑·OTT·앱테크) 위주 |
| 해시태그 | 1~3개 |
| 빈칸 | `{ }`는 애드픽 캠페인 상세 문구 그대로 |

---

## 페이지 설정
**페이지 이름**: `생활 혜택 정리`
**소개**
```
쿠폰, 무료체험, 앱테크 등 생활 혜택을 조건까지 정리해 올립니다.
일부 게시물에는 제휴(애드픽) 링크가 포함되며, 링크로 가입·구매 시 수수료를 받을 수 있습니다.
```

## 1. 게임 사전예약
**페이지 게시물**
```
[광고]
🎮 {게임명} 사전예약 진행 중 — 예약 보상 {보상}

출시 예정 {출시일}, 예약은 {마감일}까지예요.

보상 놓치지 않으려면
✔ 예약한 계정으로 출시 날 로그인
✔ 쿠폰·우편함 보상은 기한 확인
✔ 서버 고르기 전 출시 공지 확인

👉 사전예약: {애드픽 홍보 링크}

이 게시물은 애드픽 캠페인 참여로 작성되었으며, 링크로 예약 시 수수료를 받습니다.
#사전예약 #모바일게임
```

## 2. 앱테크
**페이지 게시물**
```
[광고]
💸 {앱이름} 신규 가입 시 {가입보상}

· 적립: {적립방법}
· 출금 조건: {출금조건}
· 대상: {대상}

앱테크는 시작 전에 이 세 가지만 보세요.
① 최소 출금 금액 ② 포인트 유효기간 ③ 앱 권한(필요한 것만)
돈을 먼저 넣으라는 앱은 사기입니다.

👉 {애드픽 홍보 링크}

이 게시물은 애드픽 캠페인 참여로 작성되었으며, 링크로 가입 시 수수료를 받습니다.
#앱테크 #짠테크
```

**그룹 공유용 정보글 (링크 없음, 허용된 그룹만)**
```
앱테크 처음 하시는 분들 참고하세요 🙂
① 최소 출금 금액 (현금인지 기프티콘인지)
② 포인트 유효기간
③ 앱 권한 — 기능에 필요한 것만 허용
"입금하면 더 준다"는 앱은 사기예요.
```

## 3. 쇼핑 첫 구매
**페이지 게시물**
```
[광고]
🛒 {쇼핑몰} 첫 구매 {첫구매혜택}
조건: {최소주문} / {마감일}까지

블프·연말 세일에 첫 구매 쿠폰 쓰실 거라면
✔ 특가 상품은 쿠폰 제외인 경우가 많아요
✔ 행사 할인과 중복 안 될 수 있어요
✔ 비교는 배송비 포함 최종 금액으로

👉 {애드픽 홍보 링크}

이 게시물은 애드픽 캠페인 참여로 작성되었으며, 링크로 가입·구매 시 수수료를 받습니다.
#연말세일 #쇼핑꿀팁
```

**그룹 공유용 정보글**
```
연말 세일 전 첫 구매 쿠폰 체크 🛒
· 최소 주문 금액
· 특가 상품 적용 제외 여부
· 유효기간
· 행사 할인과 중복 여부
배송비 포함 최종 금액으로 비교하세요.
```

## 4. 웹툰·OTT 무료체험
**페이지 게시물**
```
[광고]
📺 {서비스} {무료혜택}
※ {전환조건}

무료체험 신청한 날 이것만 해 두세요.
① 종료일 2일 전 달력 알림
② 해지 위치 확인
   안드로이드: 플레이 스토어 › 결제 및 정기 결제
   아이폰: 설정 › 내 이름 › 구독
③ 앱 삭제 ≠ 구독 해지

👉 {애드픽 홍보 링크}

이 게시물은 애드픽 캠페인 참여로 작성되었으며, 링크로 가입 시 수수료를 받습니다.
#무료체험 #OTT
```

**그룹 공유용 정보글**
```
무료체험 자동결제 막는 법 📺
① 신청한 날 종료일 달력에
② 결제한 곳에서 해지 (플레이 스토어 정기 결제 / 아이폰 설정 구독)
③ 앱 지워도 결제는 계속돼요
```

## 5. 수험생·대학생 (부모·대학생 대상)
**페이지 게시물**
```
[광고]
✍️ 수능 끝나고 첫 알바, 지원 전에 확인할 것

· 만 18세 미만 → 친권자 동의서 + 가족관계증명서
· 근로계약서는 첫날 서면으로
· 2026년 최저시급 10,320원
· 통장·카드 대여, 현금 전달, 교육비 선입금 요구 = 범죄·사기

알바 찾을 때 {앱이름}: {혜택} (대상 {대상})
👉 {애드픽 홍보 링크}

이 게시물은 애드픽 캠페인 참여로 작성되었으며, 링크로 가입 시 수수료를 받습니다.
#수능 #첫알바
```

**그룹 공유용 정보글 (학부모·대학 그룹)**
```
수능 끝난 자녀 첫 알바 전 체크 ✍️
· 만 18세 미만: 친권자 동의서 + 가족관계증명서
· 근로계약서 서면 작성
· 최저시급 10,320원 (2026년)
· "통장만 빌려주면 일당" = 대포통장 범죄
상담: 고용노동부 1350
```

## 운영 팁
| 항목 | 내용 |
|---|---|
| 빈도 | 페이지 하루 1개, 광고 글은 주 3~4개 이하 |
| 시간 | 점심(12~13시)·저녁(20~21시) |
| 링크 위치 실험 | 2주는 본문 링크, 2주는 첫 댓글 링크 → 페이지 인사이트 '도달'로 비교 후 결정 |
| 그룹 | 정보글만, 링크 요청 댓글이 오면 페이지 게시물로 안내 |
| 인스타 연동 | 같은 메타 계정이면 인스타 카드뉴스를 페이지에 동시 게시 가능 (`instagram.md`) |
