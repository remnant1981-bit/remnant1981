# 카카오톡 오픈채팅 글 초안 — 1~5순위

## ⚠️ 먼저 확인 (계정·법 위험이 가장 큰 채널)
| 항목 | 내용 |
|---|---|
| **남의 방 홍보 금지** | 다른 사람이 운영하는 오픈채팅방에 방장 허락 없이 홍보 링크를 올리면 카카오 운영정책상 스팸 → 신고 시 **오픈채팅 이용 제한**. 애드픽 캠페인에서도 '무단 홍보' 유입은 수익이 취소될 수 있음 |
| **내 방 운영 권장** | 직접 만든 '혜택 정보 공유방'에 스스로 들어온 사람에게만 게시 (아래 방 설정 참고) |
| **(광고) 표시** | 정보통신망법 제50조: 영리 목적 광고성 정보는 **첫머리에 (광고)**, 보내는 사람 이름, 수신 거부 방법 표시 |
| **야간 금지** | 밤 9시~아침 8시 광고성 정보 전송은 별도 동의 필요 (정보통신망법 제50조) → **08:00~21:00에만** 게시 |
| 빈도 | 하루 2~3개 이하. 정보글 2 : 홍보글 1 비율 |
| 빈칸 | `{ }`는 애드픽 캠페인 상세 문구 그대로 |

## 0. 내 방 만들기 (그룹 오픈채팅)

**방 이름**
```
앱테크·혜택 정보 모음 (제휴 링크 포함)
```

**방 소개**
```
게임 사전예약, 앱테크, 첫 구매 쿠폰, 무료체험 정보를 정리해서 올려요.
일부 글에는 제휴(애드픽) 링크가 포함되며, 링크로 가입·설치 시 운영자가 수수료를 받을 수 있어요.
광고 글은 (광고)로 표시하고, 08~21시에만 올려요.
```

**공지 (고정)**
```
📌 방 규칙
1. (광고) 표시 글에는 제휴 링크가 있어요. 링크로 가입·설치 시 운영자가 수수료를 받아요.
2. 광고 글은 하루 최대 1~2개, 08~21시에만 올려요.
3. 받고 싶지 않으면 채팅방 알림 끄기 또는 나가기로 언제든 수신 거부할 수 있어요.
4. 참여자 홍보·도배는 금지예요.
운영자: {운영자 닉네임}
```

· 근로계약서는 첫날 서면으로
· 2026년 최저시급 10,320원
