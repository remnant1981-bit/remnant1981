# 앱테크(리워드 앱 가입) 트윗 초안 (2순위)

- 애드픽 캠페인 상세를 보고 `{ }` 빈칸만 채워 쓰면 됨. 보상·출금 조건은 **상세 문구 그대로** 적을 것
- `[광고]` 표시와 홍보 링크는 게시할 때 자동으로 붙음 → 본문만 고르면 됨
- 빈칸(`{…}`)이 남은 글은 게시기가 자동으로 막음
- 길이 확인: 긴 앱 이름·보상(예: 「3,000포인트+출석 7일 보너스」)을 넣어도 최대 149/280

## 초안 5종 (접근 방식별)
| # | 방식 | 본문 | 예상 길이 |
|---|---|---|---|
| 1 | 혜택 요약 | {앱이름} 신규 가입 시 {가입보상}<br>적립: {적립방법}<br>#앱테크 | 약 125 |
| 2 | **조건 공개형 (권장)** | {앱이름} 가입 보상 {가입보상}<br>출금 조건: {출금조건}<br>조건 먼저 보고 판단하세요 | 약 150 |
| 3 | 질문형 | {적립방법}으로 포인트 모으는 앱 찾는 분?<br>{앱이름} 가입하면 {가입보상}<br>#앱테크 | 약 135 |
| 4 | 대상 안내 | {대상} 대상<br>{앱이름} 가입 보상 {가입보상} ({마감일}까지) | 약 130 |
| 5 | 짧은 한 줄 | {앱이름} 신규 가입 {가입보상}, {적립방법}으로 적립 | 약 120 |

- 2번 권장 이유: 앱테크는 "출금이 안 된다"는 불만이 많은 분야 → 출금 조건을 먼저 밝히면 신뢰도↑, 가입 후 이탈·신고↓

### 게시 예시 (가상의 앱으로 채운 모습)
```
[광고] 포인트워크 플러스 가입 보상 3,000포인트+출석 7일 보너스
출금 조건: 5,000포인트부터 현금 출금
조건 먼저 보고 판단하세요
https://adpick.co.kr/?ac=…
```

## 운영 순서
| 시점 | 쓸 초안 |
|---|---|
| 첫 게시 | 2 조건 공개형 |
| 이후 번갈아 | 1 혜택 요약 ↔ 3 질문형 |
| 마감 1주 전 | 4 대상 안내 (마감일 포함) |
| 중간중간 채움용 | 5 짧은 한 줄 |
→ 같은 캠페인은 하루 1건 (게시기 기본 설정), 게임 사전예약과 번갈아 올라감

## 피할 표현 (앱테크는 특히 주의)
| 피할 것 | 이유 |
|---|---|
| "월 ○○만 원 수익", "부업으로 월세 벌기" | 수익 보장·과장 → 표시광고법 위반 소지, X 스팸 신고 대상 |
| "누구나 쉽게 돈 버는", "무조건 출금" | 게시기가 자동 차단하는 과장 표현 |
| "저도 하루 ○원 벌어요" | 지어낸 체험 |
| 상세에 없는 하루 적립액·소요 시간 | 실제와 다르면 허위 광고 |
| 친구 추천 코드 함께 적기 | 애드픽 링크와 별개 보상 → 캠페인 규정 위반 가능 |

## campaigns.csv 입력 양식 (AI 자동 초안용)
```
name,url,benefit,target,deadline,notes,active
{앱이름} 가입,{애드픽 홍보 링크},{가입보상 — 상세 문구 그대로},{대상},{마감일 YYYY-MM-DD},"적립 방법: {적립방법} / 출금 조건: {출금조건} / 수익 금액 표현 금지",y
```
