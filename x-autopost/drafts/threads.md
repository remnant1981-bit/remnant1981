# 스레드(Threads) 글 초안 — 1~5순위

## 공통 규칙
| 항목 | 내용 |
|---|---|
| 글자 수 | 게시물 1개 최대 500자 → 아래 초안 모두 150자 이내 (빈칸 채워도 여유) |
| 광고 표시 | 캠페인 링크가 들어가는 **연결글의 첫 게시물 첫 줄**에 `[광고]` (공정위 추천·보증 심사지침: 첫 부분 표시) |
| 링크 위치 | 본문엔 링크 없이 → **마지막 연결글(답글)에 링크** (스레드는 링크 글 노출이 약하다는 운영자 경험담이 많음 — 공식 확인된 기준은 아님) |
| 주제 태그 | 스레드는 게시물당 주제 태그 1개 → 각 초안 끝 `#태그` 1개만 |
| 문체 | 해요체, 짧은 줄 바꿈. 지어낸 체험("써 봤는데") 금지 |
| 빈칸 | `{ }`는 애드픽 캠페인 상세 문구 그대로 채움 |

각 주제마다 **A. 정보형 연결글(3~4개)** + **B. 단독 짧은 글** 2종.
- A: 블로그 초안(`tistory-autopost/drafts/adpick/`) 내용을 줄인 것 → 저장·공유가 잘 되는 형식
- B: A를 올린 뒤 며칠 간격으로 다시 알릴 때

## 1. 게임 사전예약

### A. 정보형 연결글
**①**
```
[광고]
게임 사전예약해 놓고 보상 못 받는 이유, 대부분 이 3개예요 🎮

1. 예약한 계정이랑 로그인한 계정이 다름
2. 쿠폰 입력 기한 지남
3. 보상이 첫 캐릭터에만 들어가는 줄 모름

하나씩 정리해 볼게요 👇
```
**②**
```
① 계정
구글 계정 여러 개면 어떤 계정으로 사전등록했는지 메모해 두세요.
출시 날 처음 로그인할 때 꼭 같은 계정으로.

② 기한
쿠폰은 입력 기간, 우편함 보상은 보관 기간이 따로 있는 경우가 많아요.
출시일 + 기한을 바로 달력에.
```
**③**
```
③ 서버·캐릭터
보상이 계정 단위인지 캐릭터 단위인지 출시 공지에 나와요.
서버 고르기 전에 공지 먼저 읽기.

+ "보상 대리 수령해 줄게요" 같은 DM은 계정 도용이니 무시하세요.
```
**④ (링크 답글)**
```
지금 사전예약 중인 게임 👇
{게임명} — {보상}
출시 {출시일} / 예약 마감 {마감일}
{애드픽 홍보 링크}

#게임
```

### B. 단독 짧은 글
```
[광고]
{게임명} 사전예약 {마감일}까지예요.
예약 보상: {보상}
출시는 {출시일}.

예약한 계정 메모해 두는 거 잊지 마세요 🎮
링크는 답글에 👇

#게임
```

## 2. 앱테크

### A. 정보형 연결글
**①**
```
[광고]
앱테크 앱 깔기 전에 이거 2개만 먼저 보세요 💸

1. 최소 출금 금액
2. 포인트 유효기간

이거 안 보고 시작하면
출금 기준 닿기 전에 포인트가 소멸되는 경우가 있어요.
```
**②**
```
그 외 체크할 것

✔ 운영사 정보 — 앱마켓 하단 개발자 정보에 회사명·연락처 있는지
✔ 권한 — 만보기 앱이 연락처 달라고 하면 거부
✔ 데이터 — 영상 광고형은 처음엔 와이파이에서
✔ 탈퇴 — 대부분 남은 포인트 소멸, 출금 먼저
```
**③**
```
그리고 제일 중요한 거.
일주일만 '쓴 시간 / 모은 포인트' 적어 보세요.
남들 후기 말고 내 숫자로 판단하는 게 정확해요.

"돈 먼저 넣으면 더 번다"는 앱은 리워드 앱이 아니라 사기예요.
```
**④ (링크 답글)**
```
이번 달 가입 혜택 있는 앱 👇
{앱이름} — {가입보상}
출금 조건: {출금조건}
{애드픽 홍보 링크}

#앱테크
```

### B. 단독 짧은 글
```
[광고]
{앱이름} 신규 가입하면 {가입보상}.
출금 조건은 {출금조건}이에요.

조건 먼저 보고 맞으면 시작해 보세요.
링크는 답글에 👇

#앱테크
```

## 3. 쇼핑 첫 구매

### A. 정보형 연결글
**①**
```
[광고]
첫 구매 쿠폰, 결제 화면에서 '적용 불가' 뜬 적 있죠? 🛒

블프·연말 세일 전에 3개만 확인하세요.
1. 최소 주문 금액
2. 적용 제외 상품 (특가·일부 브랜드)
3. 유효기간 (발급 후 며칠)
```
**②**
```
놓치기 쉬운 것

✔ 행사 할인이랑 쿠폰이 중복 안 되는 경우 있음
✔ 주문 취소하면 첫 구매 쿠폰 복원 안 되는 곳 있음
  → 사이즈 애매한 옷보다 확실히 살 물건에
✔ 다른 곳이랑은 배송비 포함 '최종 결제 금액'으로 비교
```
**③ (링크 답글)**
```
지금 첫 구매 혜택 있는 곳 👇
{쇼핑몰} — {첫구매혜택}
적용 조건: {최소주문} / {마감일}까지
{애드픽 홍보 링크}

#쇼핑
```

### B. 단독 짧은 글
```
[광고]
{쇼핑몰} 첫 구매면 {첫구매혜택}.
조건: {최소주문}, {마감일}까지.

원래 사려던 물건 있으면 이때 쓰는 게 이득이에요.
링크는 답글에 👇

#쇼핑
```

## 4. 웹툰·OTT 무료체험

### A. 정보형 연결글
**①**
```
[광고]
무료체험 신청한 날, 5분만 쓰면 자동결제 안 당해요 📺

1. 체험 끝나는 날 달력에 (2일 전 알림)
2. 어디서 결제했는지 확인
3. 지금 해지해도 끝날 때까지 볼 수 있는지 확인
```
**②**
```
해지 위치가 결제한 곳마다 달라요.

· 구글 플레이 결제 → 플레이 스토어 > 프로필 > 결제 및 정기 결제
· 아이폰 결제 → 설정 > 내 이름 > 구독
· 웹에서 카드 등록 → 그 서비스 웹사이트 멤버십 관리

앱 지워도 구독은 안 없어져요 ⚠️
```
**③**
```
해지 화면에 "○월 ○일까지 이용 가능"이 뜨면
가입하자마자 해지해 두는 게 제일 안전해요.

웹툰 쿠키·코인도 유효기간 있는 경우 많으니
볼 작품 미리 정해 두기.
```
**④ (링크 답글)**
```
지금 무료체험 되는 곳 👇
{서비스} — {무료혜택}
※ {전환조건}
{애드픽 홍보 링크}

#웹툰
```
(OTT 캠페인이면 태그 `#OTT`)

### B. 단독 짧은 글
```
[광고]
{시즌} 정주행 준비 중이면
{서비스} {무료혜택}.

※ {전환조건}
종료일 달력에 넣고 시작하세요.
링크는 답글에 👇

#웹툰
```

## 5. 수험생·대학생 (알바 앱 기준)

### A. 정보형 연결글
**①**
```
[광고]
수능 끝나고 첫 알바 구하는 분들,
지원 전에 이것부터 확인하세요 ✍️

1. 내 만 나이 (생일 전이면 만 17세일 수 있음)
2. 근로계약서는 첫날 서면으로
3. 2026년 최저시급 10,320원
```
**②**
```
만 18세 미만이면

· 부모님 동의서 + 가족관계증명서 사업장에 제출
· 하루 7시간, 주 35시간 기본
· 밤 10시~아침 6시 근무는 본인 동의 + 고용노동부 인가 필요

마감 알바 권유받으면 이거 먼저 확인.
```
**③**
```
이런 알바는 무조건 거르세요 🚫

· "통장·체크카드만 빌려주면 일당" → 대포통장, 본인이 처벌받음
· "현금·서류만 받아서 전달" → 보이스피싱 수거책
· 교육비·유니폼비 먼저 입금 → 연락 두절

임금 밀리면 고용노동부 1350.
```
**④ (링크 답글)**
```
알바 찾을 때 쓸 수 있는 앱 👇
{앱이름} — {혜택}
대상: {대상}
{애드픽 홍보 링크}

#알바
```

### B. 단독 짧은 글
```
[광고]
{시즌}에 {용도} 찾는 중이면
{앱이름} {혜택}.
대상: {대상}

지원 전에 근로계약서·최저시급(10,320원)은 꼭 확인하세요.
링크는 답글에 👇

#알바
```
