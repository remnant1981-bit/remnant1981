## 구성
- 본문은 캠페인과 무관하게 읽어도 쓸모 있는 **정보 글** (검색 유입용), 끝부분 `📌 캠페인 박스`에만 애드픽 링크
- 맨 위·맨 아래 수수료 고지 문구 포함 (voice.md 고지 규칙)
- 문체: voice.md (합니다체, 방법 N가지, 핵심 정리, 실천 한 줄)
- 제목 점수(quality.py) 95~100, 본문 문체 검사 통과

## 발행 방법
1. 애드픽 캠페인 상세를 보고 `📌` 박스의 `{ }` 빈칸을 **상세 문구 그대로** 채움
2. 맞는 캠페인이 없으면 박스와 맨 위·아래 고지 문구를 지우고 일반 정보 글로 발행
3. 파일을 `tistory-autopost/posts/`로 옮김 → 자동 발행 (기본 `visibility: private` — 확인 후 공개로 변경)
   - 예약하려면 front matter에 `publish_at: 2026-11-25 09:00` 추가

⚠️ 이 폴더(`drafts/`)는 자동 발행 대상이 아님. `posts/`로 옮기는 순간 발행되므로 **빈칸을 다 채운 뒤** 옮길 것
