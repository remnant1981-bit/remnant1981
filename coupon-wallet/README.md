# 쿠폰 지갑 (개인용 PWA)

쿠폰 만료 / 적립 진행(프리퀀시·별·스탬프)을 한곳에서 관리하는 개인용 앱. 빌드 도구·서버 없음 (정적 파일).

## 기능
- 쿠폰: 브랜드·혜택·가치·만료일·번호·바코드 이미지, 사용 완료 처리(절약 금액 기록), 상태/브랜드 필터
- 적립: 현재/목표/마감일/보상, +1/−1, **남은 기간 대비 필요 페이스** 및 달성 불가 경고
- 홈: 사용 가능 쿠폰 수, 이번 달 절약/놓친 금액, 7일 내 만료, 진행 중 적립
- 알림: 앱을 열 때 만료 3일 이내 쿠폰·마감 7일 이내 적립을 알림으로 표시 (앱이 꺼진 상태의 자동 알림은 아님)
- 백업: JSON 내보내기/불러오기 (데이터는 기기 브라우저 localStorage에만 저장)

## 실행
```bash
cd coupon-wallet
python3 -m http.server 8000   # http://localhost:8000
```

## 폰(Android)에 설치
PWA 설치·알림은 HTTPS 필요. 정적 호스팅(GitHub Pages, Netlify, Cloudflare Pages 등)에 `coupon-wallet/` 폴더를 올린 뒤
Chrome에서 접속 → 메뉴 → "홈 화면에 추가".
