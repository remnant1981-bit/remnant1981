# 쿠폰 지갑 (개인용 PWA)

쿠폰 만료 / 적립 진행(프리퀀시·별·스탬프)을 한곳에서 관리하는 개인용 앱. 빌드 도구·서버 없음 (정적 파일).

## 기능
- **쿠폰**: 브랜드·혜택·가치·만료일·번호·바코드 이미지, 검색, 상태/브랜드 필터, 사용 완료(절약 금액 기록)
  - 바코드 상세 화면은 **화면 꺼짐 방지**(결제 중 유지)
  - 삭제·사용 완료는 **실행 취소** 가능
- **적립**: 현재/목표/마감일/보상, ±1(연타 가능), **남은 기간 대비 필요 페이스**, 달성 불가 경고, 진행 중/완료·마감 지남 구분
- **홈**: 사용 가능 쿠폰 수, 이번 달 절약/놓친 금액, 누적 절약, 사용률, 7일 내 만료, 진행 중 적립
- **알림**: 앱을 열 때·앱으로 돌아올 때, 그리고 (지원 기기에서) 백그라운드 점검 시 만료 3일 이내 쿠폰·마감 7일 이내 적립을 하루 1회 알림
- **백업**: JSON 내보내기 / 불러오기(병합, 형식 검증), 마지막 백업 일자 표시
- **편의**: 폰 뒤로가기로 팝업 닫기, 아이콘 길게 누르기 바로가기(쿠폰 추가·적립), 오프라인 동작, 다크 모드

## 데이터 저장
- 브라우저 **IndexedDB**(이 기기 전용, 서버로 전송 없음). v1.0의 localStorage 데이터는 첫 실행 때 자동 이전됨
- 저장은 트랜잭션 단위(전부 성공 또는 전부 취소). 저장 실패 시 입력 내용을 유지하고 안내함
- 영구 저장(persist)을 요청해 브라우저의 임의 삭제 위험을 낮춤. 그래도 **기기 변경·브라우저 데이터 삭제 시 사라지므로 주기적 백업 필요**

## 실행
```bash
cd coupon-wallet
python3 -m http.server 8000   # http://localhost:8000
```

## 폰(Android)에 설치
배포 주소: https://remnant1981-bit.github.io/remnant1981/ (GitHub Pages, `main`에 `coupon-wallet/` 변경이 병합되면 자동 배포).
Android Chrome에서 위 주소 접속 → 메뉴(⋮) → "홈 화면에 추가" 또는 "앱 설치". 설치 후 앱에서 설정(⋯) → "알림 허용".
설정 화면 하단의 버전(예: 1.1.0)으로 업데이트 적용 여부를 확인할 수 있음.

## 구조
| 파일 | 역할 |
|---|---|
| `logic.js` | 순수 로직(날짜·상태·페이스·통계·입력 검증). 화면/서비스워커/테스트 공유 |
| `store.js` | IndexedDB 저장소 + 알림 점검(화면·서비스워커 공용) |
| `app.js` | 화면·이벤트 |
| `sw.js` | 오프라인 캐시(네트워크 우선, 3초 타임아웃), 백그라운드 점검(`periodicsync`), 알림 클릭 |

## 테스트
```bash
node --test "tests/coupon-wallet/*.test.js"   # 단위(로직) — 의존성 없음
node tests/coupon-wallet/e2e.js               # E2E(실제 Chromium) — playwright 필요
```
CI(`.github/workflows/coupon-wallet-ci.yml`)가 PR마다 두 가지를 실행함.

## 한계
