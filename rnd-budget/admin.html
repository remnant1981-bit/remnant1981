관리자 화면

← 사이트로 돌아가기 · 설정을 바꿔도 이 화면만으로는 실사이트가 바뀌지 않습니다. 만든 설정 파일을 배포해야 반영됩니다.

로그인

비밀번호가 맞지 않습니다.

1. 관리자 비밀번호

비밀번호를 정하면 암호화 값(해시)을 만들어 줍니다. 그 값만 설정 파일에 들어가고, 비밀번호 원문은 어디에도 저장·전송되지 않습니다. 저장소가 공개되어 있으므로 12자 이상, 다른 곳에서 쓰지 않는 문장형 비밀번호를 쓰세요.

2. 기능 스위치

‘운영’은 지금 실사이트 설정, ‘미리보기’는 이 브라우저에서만 켜고 꺼 보는 값입니다. 실사이트에 반영하려면 ‘운영에 반영’을 체크하고 아래에서 설정 파일을 만드세요.

기능운영미리보기(이 브라우저)운영에 반영
미리보기로 사이트 열기

3. 운영 설정

여기 값은 모두 공개 정보입니다(사이트 소스에서 누구나 볼 수 있음). 비밀번호·API 키·토큰은 넣지 마세요.

반영 방법
  1. 내려받은 config.js로 저장소의 rnd-budget/config.js를 바꿉니다(브랜치 → PR → 병합).
  2. 병합 후 1~2분 뒤 실사이트에 반영됩니다.
  3. 이 화면을 새로 고쳐 ‘운영’ 값이 바뀌었는지 확인합니다.
