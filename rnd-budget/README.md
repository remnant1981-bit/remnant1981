# R&D 사업비 편성 가이드 (무료 웹 도구, 광고 수익)

정부 R&D 과제 사업비를 **법령 기준으로** 편성·점검하는 정적 웹 도구. 빌드·서버·회원가입 없음. GitHub Pages `/rnd-budget/`로 게시.
주소(배포 후): https://remnant1981-bit.github.io/remnant1981/rnd-budget/

## 적용 법령(기준일 2026-11-13)
- 국가연구개발혁신법 시행령 제19조·별표 1(2024.12.31. 개정)
- 국가연구개발사업 연구개발비 사용 기준(과기정통부고시 제2026-38호, 2026.5.6. 시행)

| 기관 유형 | 정부지원 상한 | 기관부담 중 현금 | 간접비율 |
|---|---|---|---|
| 중소기업 | 75% | 10% | 10%(영리, 제114조④) |
| 중견기업(평균매출액등 3천억 원 미만) | 70% | 10%(별표 1 비고 2) | 10% |
| 중견기업(3천억 원 이상) | 70% | 13% | 10% |
| 대기업·공기업 | 50% | 15% | 10% |
| 대학 | 기관부담 의무 없음 | – | 고시비율 없으면 5%(제114조②) |
| 비영리기관(대학 외) | 기관부담 의무 없음 | – | 고시비율 없으면 17%(제114조③) |
| 공고문 기준 직접 입력 | 입력 | 입력 | 입력 |

공통 점검: 연구수당 ≤ 수정인건비(현물 포함 인건비 + 학생인건비)의 20%(제26조①), 위탁연구개발비 ≤ (직접비 − 위탁)의 40%(제27조①), 영리기관 연구자 총 참여율 ≤ 100%(제65조⑦), 기존 인력 인건비 현물 원칙·신규 채용 현금(제64조②), 간접비 = (직접비 − 현물 − 위탁) × 비율 현금(제2조9호), 영리기관 학생인건비 비목 제외(제7조), 장비 3천만 원 이상 안내(제23조).

법령 유형을 고르면 정부지원·현금·연구수당 비율은 **고정**, 간접비율은 기관 고시비율 범위 안에서만 낮출 수 있음. 공고문이 다르면 '공고문 기준 직접 입력'.

## 법령 재확인 필요(운영)
- 「연구개발비 사용 기준」 일부개정안 행정예고(과기정통부 공고 제2026-1017호, 2026.10.15.) — 확정·시행 시 수치 재확인
- 확인 시점 law.go.kr 점검 중(11/13~14) → 캐시·기관 배포본으로 대조함. 점검 후 원문 재대조 권장
- 법령 변경 시 `logic.js`의 `RULESETS`·`LIMITS`·`BASIS_DATE`와 화면 가이드 문구를 함께 수정

## 기능
**예시로 체험하기**(정상 편성 예시·오류 점검 예시, 화면 상단) / 기관 유형 선택 → 최소 총사업비·기관부담금·최소 현금·현물 가능액 / 참여연구원 인건비(구분: 기존 인력 현물·신규 채용 현금·기존 인력 현금) / 비목 편성·남은 편성액 / 점검(근거 조문 표시) / 엑셀(.xlsx, 수식·적용 기준 포함)·인쇄·안 저장(최대 20개) — **전부 무료**. 단계별 작성 가이드·FAQ 포함.
