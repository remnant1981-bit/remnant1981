# R&D 사업비 편성 가이드 (무료 웹 도구, 광고 수익)

정부 R&D 과제 사업비를 **법령 기준으로** 편성·점검하는 정적 웹 도구. 빌드·서버·회원가입 없음. GitHub Pages `/rnd-budget/`로 게시.
주소(배포 후): https://remnant1981-bit.github.io/remnant1981/rnd-budget/

## 적용 법령(기준일 2026-11-13)
- 국가연구개발혁신법 시행령 제19조·별표 1(2024.12.31. 개정)
- 국가연구개발사업 연구개발비 사용 기준(과기정통부고시 제2026-38호, 2026.5.6. 시행)

| 기관 유형 | 정부지원 상한 | 기관부담 중 현금 | 간접비율 |
|---|---|---|---|
| 중소기업 | 75% | 10% | 10%(영리, 제114조④) |
| 중견기업(평균매출액등 3천억 원 미만) | 70% | 10%(별표 1 비고 2) | 10% |
| 중견기업(3천억 원 이상) | 70% | 13% | 10% |
| 대기업·공기업 | 50% | 15% | 10% |
| 대학 | 기관부담 의무 없음 | – | 고시비율 없으면 5%(제114조②) |
| 비영리기관(대학 외) | 기관부담 의무 없음 | – | 고시비율 없으면 17%(제114조③) |
| 공고문 기준 직접 입력 | 입력 | 입력 | 입력 |

공통 점검: 연구수당 ≤ 수정인건비(현물 포함 인건비 + 학생인건비)의 20%(제26조①), 위탁연구개발비 ≤ (직접비 − 위탁)의 40%(제27조①), 영리기관 연구자 총 참여율 ≤ 100%(제65조⑦), 기존 인력 인건비 현물 원칙·신규 채용 현금(제64조②), 간접비 = (직접비 − 현물 − 위탁) × 비율 현금(제2조9호), 영리기관 학생인건비 비목 제외(제7조), 장비 3천만 원 이상 안내(제23조).

법령 유형을 고르면 정부지원·현금·연구수당 비율은 **고정**, 간접비율은 기관 고시비율 범위 안에서만 낮출 수 있음. 공고문이 다르면 '공고문 기준 직접 입력'.

## 법령 재확인 필요(운영)
- 「연구개발비 사용 기준」 일부개정안 행정예고(과기정통부 공고 제2026-1017호, 2026.10.15.) — 확정·시행 시 수치 재확인
- 확인 시점 law.go.kr 점검 중(11/13~14) → 캐시·기관 배포본으로 대조함. 점검 후 원문 재대조 권장
- 법령 변경 시 `logic.js`의 `RULESETS`·`LIMITS`·`BASIS_DATE`와 화면 가이드 문구를 함께 수정

## 단계적 공개(기능 스위치)
`config.js`의 `features`로 화면 노출을 켜고 끔(끈 기능도 코드·저장 데이터는 유지).

| 스위치 | 현재 | 내용 |
|---|---|---|
| `examples` | 켬 | 예시로 체험하기 |
| `project` | **끔(2단계 예정)** | 연차별·공동기관별 편성, 편집 탭, 총괄표. 끄면 첫 기관·1차년도만 편집·엑셀 |
| `scenarios` | 끔 | 여러 안 저장·불러오기 |
| `faq` | 끔 | 자주 묻는 질문 |
| `steps` | 끔 | 상단 단계 메뉴 |
| `legalHeader` | 끔 | 상단 적용 법령 문구(하단 안내에는 항상 표시) |
| `helper` | **켬(2026-11-14 공개)** | 처음 편성 도우미: 질문 4단계 → 법령 기준 맞춘 초안 자동 작성(연구재료비로 최소 총사업비·현금 맞춤, 연구수당 인건비 10%·연구활동비 5% 기본), 오류별 '고치기' 버튼·'한 번에 고치기', 비목 ⓘ 설명 |
| `noticeImport` | **켬(2026-11-14 베타 공개)** | 공고문(HWP·HWPX·PDF·TXT)에서 적용 기준 가져오기: 브라우저 안에서만 읽음(외부 전송 없음), 규칙 기반 추출(정부지원연구개발비 연간·총액, 기간, 기관 유형별 정부지원·현금 비율, 간접비, 위탁·연구수당 한도) → 근거 문장 표시 → 확인한 항목만 '공고문 기준 직접 입력'으로 적용, 출처 표시. HWP 5.0 직접 해석(암호·배포용 문서는 PDF로 저장 안내), PDF는 `vendor/pdfjs`(pdf.js 4.10.38, Apache-2.0)를 필요할 때만 로드 |
| `execution` | **켬(2026-11-14 공개)** | 집행 현황판: [편성]/[집행] 전환, 연차 기간·경과율, 비목별 협약·집행·잔액·집행률(부진·과속 ±25%p), 월별 집행 입력, 기관부담 현금 납부·기한, 일정 D-day, 집행 현황 엑셀, 백업(JSON) 저장·불러오기 |

화면: PC(1100px 이상)는 좌측 입력 / 우측 고정 패널(편성 요약·점검·엑셀) 2단, 모바일은 1단. 점검은 오류·주의만 기본 표시하고 통과·계산 내역은 접어 둠.

## 기능
- **과제 구성**: 연구개발기간 1~5년(연차), 주관·공동연구개발기관 최대 10곳(기관별 유형·법령 기준 개별 적용), 편집 탭(기관 × 연차), 이전 연차 복사, 총괄표(칸 클릭 → 해당 기관·연차 편집, 오류 표시)
- **계획서 양식 엑셀**: ① 연구개발비 총괄표(연차·기관별 정부지원/기관부담 현금·현물, 소계·총합계 수식) ② 기관별 연구개발비 사용계획(연차별 + 전체 연차 합계, 비목별 정부지원/기관부담 현금·현물 — 현금은 정부지원·기관 현금으로 비례 배분, 조정 가능) ③ 참여연구원 인건비 명세 ④ 적용 기준·근거
- 저장 형식 v2(과제 단위). 이전 버전 저장값(단일 기관·연차)은 자동 변환
**예시로 체험하기**(정상 편성 예시·오류 점검 예시, 화면 상단) / 기관 유형 선택 → 최소 총사업비·기관부담금·최소 현금·현물 가능액 / 참여연구원 인건비(구분: 기존 인력 현물·신규 채용 현금·기존 인력 현금) / 비목 편성·남은 편성액 / 점검(근거 조문 표시) / 엑셀(.xlsx, 수식·적용 기준 포함)·인쇄·안 저장(최대 20개) — **전부 무료**. 단계별 작성 가이드·FAQ 포함.
