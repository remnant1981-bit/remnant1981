# R&D 사업비 계산기 (수익형 웹 도구)

정부 R&D 과제 사업비 편성을 계산·점검하는 정적 웹 도구. 빌드·서버 없음, GitHub Pages `/rnd-budget/` 경로로 게시.
주소(배포 후): https://remnant1981-bit.github.io/remnant1981/rnd-budget/

## 기능
| 구분 | 내용 |
|---|---|
| 무료 | 정부출연금 → 최소 총사업비·기관부담금·최소 현금·최대 현물, 기관 유형(중소 75/10%, 중견 70/13%, 대기업 50/15%, 직접 입력), 참여연구원 인건비(연봉÷12×개월×참여율, 현금/현물), 비목별 편성, 간접비 자동 계산((직접비−현물−위탁)×비율), 점검(총사업비 부족·정부출연금 현금 편성·기관 현금 비율·연구수당 한도·참여율 100% 초과), 인쇄·PDF, 입력 자동 저장(브라우저) |
| Pro 이용권 | 엑셀(.xlsx) 편성표 내보내기(합계·비율 수식, 2개 시트), 시나리오 저장·불러오기(최대 20개), 광고 숨김 |
| 광고 | 애드센스 승인 후 `config.js` 입력 시에만 표시(Pro 사용자 제외) |

비율 기본값은 일반 기준이며 화면에서 수정 가능. 공고문·사업별 운영요령·기관 간접비 고시 비율이 우선(화면·엑셀에 고지).

## 수익 구조
1. **Pro 이용권 판매**: 외부 스토어(스마트스토어·크몽·Gumroad 등)에서 판매 → 주문번호로 이용권 코드 발급 → 구매자가 화면에 코드 등록
2. **광고**: 무료 사용자 대상 애드센스 1개 영역

### 이용권 코드 방식
- ECDSA P-256 서명 코드(`내용.서명`). 내용 = 주문번호·만료일. 브라우저가 공개키로 검증 → 서버 불필요
- 개인키는 운영자 PC에만 있으므로 코드 위조 불가(만료일 변조 시 서명 불일치). 정적 사이트 특성상 화면 코드를 직접 고치는 우회는 막을 수 없음 → 저가 이용권 모델 전제
- 개인정보(이메일 등)는 코드에 넣지 않음

## 판매 개시 절차
1. 키 생성(최초 1회, 운영자 PC): `node scripts/rnd-budget/license.mjs keygen`
   → 개인키 `~/.rnd-budget/private.jwk` 저장(권한 600), 공개키 출력
2. `rnd-budget/config.js`에 `licensePublicKey`(공개키), `storeUrl`(판매 페이지), `priceText`, `contact` 입력 → PR·병합 → 자동 배포
3. 판매 시: `node scripts/rnd-budget/license.mjs issue <주문번호> [이용일수=365]` → 출력 코드를 구매자에게 전달
4. (선택) 애드센스 승인 후 `adsenseClient`·`adsenseSlot` 입력

주의: 개인키를 저장소·메일·메신저에 올리지 말 것. 분실·유출 시 `keygen --force`로 재생성 후 새 공개키 배포(기존 코드 무효 → 구매자 재발급 필요).

## 테스트
- 단위: `node --test "tests/rnd-budget/*.test.js"` (계산·점검·이용권 서명/위조/만료·XLSX 구조/CRC/수식)
- E2E: `node tests/rnd-budget/e2e.js` (Playwright, 모바일 390px, 판매 전/후 설정, 엑셀 다운로드, 시나리오)
- CI: `.github/workflows/rnd-budget-ci.yml`
