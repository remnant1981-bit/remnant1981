## 왜 새로 썼나
- 같은 글을 티스토리·네이버에 동시에 올리면 네이버가 **유사문서**로 판단해 한쪽 노출이 떨어질 수 있음 → 주제는 같고 접근 방식·구성이 다른 글
- 네이버 AI 브리핑·검색은 질문-답(Q&A), 단계별 절차 구성이 잘 인용됨 → FAQ·순서형 위주

## 붙여넣기 방법 (스마트에디터 ONE)
| 표기 | 에디터에서 |
|---|---|
| `[제목]` | 제목 칸 |
| `■ 소제목` | 본문 '소제목' 서식 (또는 굵게 + 큰 글씨) |
| `(인용구)` 아래 문단 | 인용구 컴포넌트 (따옴표·라인 스타일) |
| `[이미지 제안]` | 본인 휴대폰 화면을 직접 캡처해 넣는 자리 (넣지 않으면 줄 삭제). 결제 정보·이메일은 모자이크 |
| `▶ … : {애드픽 홍보 링크}` | 링크 텍스트로 넣거나 '링크' 컴포넌트(미리보기 카드) |
| `[태그]` | 하단 태그 입력 칸 (`#` 빼고 입력) |

## 발행 전 체크
1. 캠페인 박스 `{ }` 빈칸을 애드픽 상세 문구 그대로 채우기 (맞는 캠페인 없으면 박스·고지 문구 삭제 → 일반 정보 글)
2. 수수료 고지 문구가 **본문 맨 위·맨 아래**에 있는지 (공정위 추천·보증 심사지침: 첫 부분 표시)
3. 글 하나에 제휴 링크는 1개 — 링크가 많으면 상업성 글로 판단될 수 있음
4. 하루 1편 이하, 같은 주제 티스토리 글과는 며칠 간격
5. 2027-01-01 이후 05번 최저시급 금액 수정
