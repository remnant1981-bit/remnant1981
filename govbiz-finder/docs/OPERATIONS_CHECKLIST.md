# 운영 전 체크리스트 / 알려진 제한
## 배포 전 필수(미완료 = 미체크)
- [ ] 비밀키 3종·SITE_URL 설정, HTTPS, 프록시 IP 헤더 신뢰 설정
- [ ] 실제 공고 원천 약관·API 확인 후 어댑터 구현(`docs/DATA_SOURCES.md`)
- [ ] 국세청 API 키 발급·필드 재확인·실호출 테스트
- [ ] 기업 관계 확인 방식 확정(현재 관리자 수동 승인), 계정 복구 설계
- [ ] 개인정보 처리방침·동의 문구·보유기간 작성(법무 검토)
- [ ] 알림 스케줄러(`npm run collect` 주기 실행)·이메일 공급자
- [ ] 백업 주기 설정 및 복구 리허설(`npm run db:backup -- <파일>` / `db:restore -- <파일>`; 자동 테스트 `tests/ops.test.ts`)
- [ ] 관리자 계정 비밀번호 교체(시드 계정 `admin@example.test`는 운영에서 삭제/교체)
## 검증 상태
- 자동: lint·typecheck·단위/통합/보안 테스트·axe 접근성·Playwright 스모크·CI
- 샘플 기업 4종(가상) 판정 검증: `tests/ops.test.ts`. 실제 기업 대상 사용자 검증은 미실시(실데이터 사용 시 명시적 동의·최소 수집 필요)
## 알려진 제한
- 실 공고 없음(테스트 데이터), 관리자 잠금 해제 UI 없음, 추천 이력 저장이 서버 렌더 중 수행됨
- 첨부파일 업로드 기능 없음(수집 링크만), 사용자 제보 기능 없음, 공고문 AI 구조화 없음
- rate limit은 DB 기반 고정 윈도우(소규모 전제)
