# 개발 단계 및 운영 계획

## Phase 0 — 저장소·환경 파악
- 기존 파일과 런타임 확인
- 개발 명령어·환경변수 확인
- 문서와 실제 코드의 차이 기록
완료: 실행 방법과 작업 계획 문서화

## Phase 1 — 앱 골격/UI
- Next.js/TypeScript 기반 구성(기존 프로젝트가 있으면 보존)
- 공통 레이아웃·반응형 내비게이션
- 홈·검색·상세 화면의 기본 골격
완료: lint/typecheck/build 통과

## Phase 2 — DB/도메인
- 스키마·마이그레이션·시드
- 공고·기업·사용자 도메인 모델
완료: 마이그레이션 및 기본 CRUD 테스트 통과

## Phase 3 — 공고 수집
- 원천 어댑터 인터페이스
- 공식 API 1순위 소스부터 연계
- mock 데이터 및 관리자 수동 등록
- 중복 제거·수집 로그
완료: 한 개 이상 실제 허용 원천 또는 mock adapter로 end-to-end 수집 테스트

## Phase 4 — 검색/상세
- 검색창·필터·정렬·페이지네이션
- 상세 화면·원문 링크·출처
완료: 검색 시나리오 테스트

## Phase 5 — 기업정보
- 국세청 API adapter
- 상태조회·응답 매핑
- 선택 기업정보 입력
완료: API mock/실연계 경로 모두 테스트

## Phase 6 — 인증/권한
- 회원가입·로그인·기업 관계 확인 상태
- 인증 전후 권한 분리
- 기업별 데이터 접근통제
완료: 권한 격리 테스트 통과

## Phase 7 — 추천
- 규칙 기반 적합성 엔진
- 충족/미충족/확인 필요
- 판단 근거
완료: 경계조건 단위 테스트

## Phase 8 — 내보내기
- XLSX·CSV·PDF·인쇄
완료: 생성 파일 열기 및 데이터 검증

## Phase 9 — 이력/알림
- 북마크·검색/열람 이력
- 앱 내 알림
- 이메일 adapter는 환경설정 후 활성화
완료: 사용자별 데이터 격리 확인

## Phase 10 — 관리자/운영
- 공고 관리·수집 모니터링
- 감사 로그
- SEO·운영 문서
완료: 관리자 권한 테스트

## Phase 11 — 통합 검증
- 전체 회귀 테스트
- 보안 테스트
- 샘플 기업 3~5개로 사용자 검증(실제 개인정보 사용 시 명시적 동의 및 최소 수집)
- 피드백 정리 및 우선순위화
완료: 알려진 제한·운영 체크리스트 작성

## 배포 원칙
운영 배포, 도메인 연결, 실제 API 키 등록, 이메일 발송 활성화, 유료 서비스 사용은 사용자의 명시적 승인 후 수행한다.
