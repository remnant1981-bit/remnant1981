# PDF·엑셀·CSV 내보내기 명세

## 1. 공통
- 현재 검색어·필터·정렬 조건을 그대로 반영한다.
- 내보내기 시점과 데이터 최종 확인 시각을 표시한다.
- 원문 링크를 포함한다.
- 사용자 권한을 서버에서 확인한다. 기업별 정보는 인증된 해당 기업 사용자만 포함한다.

## 2. XLSX
실무 관리용 기본 포맷. 권장 열:
- 분야
- 사업명
- 지원기관
- 지역
- 지원 대상
- 지원금액/지원내용
- 접수 시작일
- 접수 마감일
- 접수 상태
- 기업 적합성
- 확인 필요 항목
- 공식 원문 링크
- 최종 확인일
- 사용자 메모(개인별 데이터로 저장할 경우 권한 분리)

기본 기능:
- 헤더 고정
- 자동 필터
- 날짜/금액 형식
- 열 너비 조정
- 분야별 시트 분리 또는 단일 시트 필터 제공
- 수식 주입 방지(사용자 입력값을 안전하게 문자열 처리)

## 3. CSV
UTF-8(필요 시 BOM)로 생성하고 필드 이스케이프를 적용한다.

## 4. PDF
보고·내부 결재·공유용:
- 작성일
- 기업 기본정보(등록된 항목만)
- 검색 조건
- 분야별 결과 요약
- 검토 공고 목록
- 자격 평가 및 근거
- 접수기간·신청 방법
- 공식 링크
- 데이터 기준 시각과 한계 안내

## 5. 인쇄
공고 상세와 검색 결과에 인쇄용 스타일을 제공한다.
