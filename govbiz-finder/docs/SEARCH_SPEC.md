# 통합 검색 명세

## 1. 검색 대상
공개 상태의 활성 공고. 기업별 비공개 데이터는 검색 인덱스나 공개 API에 섞지 않는다.

## 2. 검색 필드
사업명, 지원기관, 분야, 기술 키워드, 지원 대상, 지역, 공고 본문에서 추출한 키워드.

## 3. 필터
- 분야
- 지역: 전국, 시·도, 시·군·구
- 지원기관
- 사업 유형
- 접수 상태
- 지원 대상/기업 규모(정보가 구조화된 경우)
- 접수 기간
- 기업 적합성(인증된 기업 프로필이 있을 때)

## 4. 분야 분류
- 재정·금융: 정책자금, 융자, 이차보전, 보증
- R&D: 국가연구개발, 기술개발
- 기술·사업화
- 설비·시설
- 수출·해외진출
- 마케팅·판로
- 인력·고용
- 인증·지식재산
- 창업·벤처
- 지역특화
복수 분야 태깅을 허용한다.

## 5. 정렬
- 기업 적합도순(기업정보가 있을 때)
- 최신순
- 마감 임박순
- 접수 시작일순
- 관련도순

## 6. 검색 결과
페이지네이션을 적용하고 검색 조건을 URL query string으로 표현해 공유·새로고침 시 상태를 유지한다. 내보내기도 현재 필터 조건을 동일하게 사용한다.

## 7. 지역 우선 노출
기업 소재지가 입력된 경우 해당 지역의 공고를 구분해 노출한다. 전국 공고를 누락하지 않는다. 소재지 미입력 시 전국 검색을 기본으로 한다.

## 8. 정확성
검색 결과에 원문 링크, 출처, 최종 확인 시각을 표시한다. 공고 상태를 확인할 수 없으면 `상태 확인 필요`로 표시한다.
