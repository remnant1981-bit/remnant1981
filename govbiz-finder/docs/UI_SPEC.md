# UI/UX 명세

## 1. 디자인 방향
- 신뢰감 있고 공공서비스에 적합한 단정한 화면
- 핵심 동작은 검색과 결과 확인에 집중
- 과도한 대시보드·복잡한 입력 폼 지양
- 데스크톱 우선 설계하되 모바일에서도 검색·상세·다운로드 사용 가능

## 2. 주요 화면
1. 홈/통합 검색
2. 검색 결과
3. 공고 상세
4. 로그인/회원가입
5. 기업 프로필 및 기업정보 조회
6. 맞춤 추천
7. 관심 공고·검색/열람 이력
8. 관리자 공고 관리
9. 관리자 데이터 수집 현황

## 3. 홈
- 서비스 핵심 메시지
- 통합 검색창
- 주요 분야 바로가기
- 전국/지역 선택
- 접수 중·마감 임박·신규 공고 섹션
- 데이터 수집 범위 및 최종 갱신 시각
- 비회원 검색 가능 안내

## 4. 검색 결과 카드
필수 표시:
- 사업명
- 지원기관
- 분야 및 지역
- 지원 대상 요약
- 지원금액 또는 지원내용(확인된 경우)
- 접수 시작일·마감일
- 접수 상태
- 맞춤 적합도(기업정보가 있을 때만)
- 출처 및 최종 확인 시각

## 5. 공고 상세
섹션:
- 사업 개요
- 지원 대상·신청 자격
- 지원 내용·한도
- 신청 기간 및 상태
- 제출 서류
- 신청 방법
- 문의처
- 첨부파일
- 공식 원문 바로가기
- 기업 적합성 분석(기업정보가 등록된 경우)
- 근거 문장과 확인 필요 항목

## 6. 기업정보 입력 UI
- 사업자등록번호 입력 후 조회 버튼
- 조회 결과: 사업자 상태, 과세 유형 등 API가 실제 제공하는 값만 표시
- 기업명·대표자명·소재지·업종·설립일·매출구간·종업원 수·연구소·벤처인증·수출 여부 등은 선택 입력
- 미입력 항목은 빈 값으로 유지하고 `확인 필요`로 처리
- 입력하지 않아도 기본 검색과 공고 열람 가능
- 기업 프로필 저장·수정·삭제의 목적과 범위를 안내

## 7. 상태 표현
- 접수 예정
- 접수 중
- 마감
- 상시 접수(원문에서 확인된 경우)
- 상태 확인 필요
- 기업 적합성: 충족 / 미충족 / 확인 필요

## 8. 오류 및 빈 상태
- 수집 지연, 원문 접속 실패, API 제한 등 원인을 구분해 표시
- 검색 결과 없음과 데이터 수집 오류를 구분
- 인증 미완료 시 공개 검색은 유지하고 기업 저장정보 접근만 제한
- 로딩·오류·빈 화면 상태를 모두 설계
