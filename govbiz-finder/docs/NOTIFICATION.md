# 이력·관심 공고·알림 명세

## 1. 회원 기능
- 검색 이력
- 열람 이력
- 관심 공고(북마크)
- 기업 맞춤 추천 이력
- 신규 공고 및 마감 임박 알림 설정

## 2. 비회원
- 지속 저장은 하지 않는다.
- 현재 브라우저 세션에서 검색 조건을 유지하는 정도는 허용한다.
- 로그인 유도는 저장이 필요한 시점에 맥락에 맞게 제시한다.

## 3. 알림
- 기본 알림 유형: 신규 공고, 마감 임박, 관심 공고 변경
- 사용자가 유형·빈도·채널을 선택하고 언제든 해제할 수 있어야 한다.
- 초기에는 앱 내 알림 구조를 우선 구현한다.
- 이메일 발송은 공급자 설정과 사용자 동의 후 활성화한다.
- 카카오 알림톡/SMS는 별도 비용과 승인·템플릿 요건을 확인한 후 후속 구현한다.

## 4. 중복·빈도 제어
- 동일 공고의 반복 알림 방지
- 마감 임박 알림의 발송 시점 설정
- 일일/주간 요약 옵션은 후속 확장 가능
- 발송 실패와 재시도 기록
