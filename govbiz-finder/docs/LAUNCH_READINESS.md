# 출시 전 점검 (2026-11-10)
측정: 공고 1,500건(본문 약 1.5KB) 벤치 DB, 프로덕션 빌드, 로컬 1대. 실서버·실데이터 수치는 **미검증**.

## 2. 출시 전 필수 — 결정·승인 필요
| # | 항목 | 이유 |
|---|---|---|
| 1 | 운영 서버(국내 IP)·도메인·HTTPS | 현재 PC 실행. 기업마당은 해외 IP 차단 |
| 2 | 유료화 방식(구독/건별/사내 라이선스)과 결제 수단 | 결제·구독 상태 저장은 DB·인증 변경 → 설계안 승인 후 구현 |
| 3 | 이용약관·환불 규정·개인정보처리방침 확정, 사업자 정보 표시 | 유료 서비스 법적 필수(전자상거래법). 초안만 있음(`PRIVACY_POLICY_DRAFT.md`) |
| 4 | 수집 데이터의 유료 서비스 내 이용 가능 여부 확인 | 기업마당 API 약관·출처표시(유료 재판매 해당 여부), 공공데이터포털은 이용허락범위 제한 없음 표기 |
| 5 | 이메일 발송(가입 확인·비밀번호 재설정·알림) | 현재 앱 내 알림만. 유료 서비스는 비밀번호 재설정 필수 |
| 6 | 오류·접속 모니터링, 백업 복구 리허설 | `/api/health`·백업 스크립트는 있으나 운영 환경 미검증 |
| 7 | DB 인덱스 추가(공고 상태·마감일·지역) | 공고 1만 건 이상에서 필요. 스키마 변경이라 승인 대상 |

## 3. 권장(출시 후 가능)
- K-Startup 실호출 검증·원천 확대, 사내(전용) 모드, 방문·전환 분석, 공고 5천 건 이상 시 판정 결과 캐시.

## 4. 알려진 한계
- 판정은 공고명·지원대상 등 구조화된 정보와 문구 추정 기반(본문 세부 조건은 원문 확인 필요).
- SQLite 단일 서버 구조: 동시 사용자 수백 명 수준까지 적합, 그 이상은 DB 이전 검토.
