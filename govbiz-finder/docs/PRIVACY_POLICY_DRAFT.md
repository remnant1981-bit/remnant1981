# 개인정보 처리방침 초안 (GovBiz Finder)

> **초안 — 법무 검토 전.** 서비스의 실제 데이터 처리 방식을 기준으로 작성했으며, `[제안]` 표시는 운영 주체가 정해야 하는 값이다. 운영 시작 전에 사업자명·연락처·보유기간 확정과 법률 검토가 필요하다(OPEN_ISSUES #6). 서비스 화면에는 확정본만 게시한다.

## 1. 수집하는 정보와 목적
| 구분 | 항목 | 필수 여부 | 목적 | 비고 |
|---|---|---|---|---|
| 비회원 | 없음(검색·열람은 정보 수집 없음) | - | - | 접속 로그는 서버 운영 로그에 한정, 개인정보·키는 로그에 남기지 않음 |
| 회원 계정 | 이메일, 비밀번호 | 필수 | 로그인·본인 데이터 접근 제어 | 비밀번호는 단방향 해시(bcrypt)로만 저장 |
| 기업 관계 확인 | 사업자등록번호 | 필수(회원이 기업 기능을 이용할 때) | 기업 데이터 접근 권한 확인, 국세청 사업자 상태조회 | 암호화 저장, 화면에는 마스킹 표시 |
| 기업정보(선택) | 기업명, 대표자명, 소재지, 업종, 설립일, 매출·종업원 구간, 연구소·벤처·수출 여부, 기술 키워드 | 선택 | 맞춤 적합성 분석 | 입력하지 않으면 분석에서 `확인 필요`로 처리, 불이익 없음 |
| 이용 기록(회원) | 관심 공고, 검색 조건, 열람한 공고, 알림 설정·알림 | 서비스 이용 중 자동 생성 | 이력 제공, 알림 | 기업 단위로 분리 저장 |

대표자명·주소·매출 등은 국세청 상태조회로 가져오지 않으며 이용자가 직접 입력한 값만 저장한다.

## 2. 외부 제공·위탁
- **국세청 사업자등록정보 API**: 이용자가 상태조회를 요청하면 사업자등록번호가 조회를 위해 국세청(공공데이터포털)에 전송된다. 응답 원문은 저장하지 않고 상태·과세유형 요약만 저장한다.
- 이메일 등 알림 발송 공급자: **현재 사용하지 않음**. 도입 시 위탁 사실과 공급자를 이 항목에 추가하고 별도 동의를 받는다.
- 그 외 제3자 제공·광고 목적 이용: 없음.

## 3. 보유 및 이용 기간 `[제안]`
| 항목 | 제안 기간 | 근거/비고 |
|---|---|---|
| 계정·기업정보 | 회원 탈퇴 또는 기업정보 삭제 요청 시까지 | 삭제 시 관련 이력까지 함께 삭제(구현됨) |
| 검색 이력 | 최근 100건만 보관, 이용자가 언제든 전체 삭제 가능 | 구현됨 |
| 열람 이력·알림 | `[제안]` 12개월 후 자동 삭제 | 자동 삭제 배치 **미구현** |
| 로그인 세션 | 7일 | 구현됨(로그아웃 시 즉시 무효화) |
| 관리자 감사 로그 | `[제안]` 3년 | 개인정보는 마스킹 저장 |
법령상 보존 의무가 있는 정보는 해당 기간 동안 별도 보관한다.

## 4. 이용자의 권리와 행사 방법
- 열람·수정: 기업정보 화면에서 직접 가능(구현됨).
- 삭제: "기업정보·이력 삭제"(구현됨). **계정 탈퇴 기능은 미구현** — 운영 전 구현 또는 문의 절차 명시 필요.
- 이력 삭제: 내 공고·알림 화면의 "이력 삭제"(구현됨).
- 알림 수신 거부: 알림 설정에서 유형별 해제(구현됨).
- 문의처: `[운영 주체 정보 입력]`

## 5. 안전성 확보 조치
- 사업자등록번호 AES-GCM 암호화 저장, 정확 일치 조회용 별도 HMAC 인덱스, 화면·로그 마스킹
- 비밀번호 해시 저장, 로그인 시도 제한·계정 잠금, 세션 쿠키(HttpOnly·SameSite, 운영은 Secure)
- 기업별 서버 측 접근통제, CSRF 방어, 관리자 권한 분리와 변경 감사 로그
- 사업자등록번호만으로는 기존 기업 정보에 접근할 수 없으며, 기업 관계 확인(관리자 검토) 후에만 기업 데이터 이용 가능
- 외부 공고 데이터는 비신뢰 입력으로 처리

## 6. 쿠키
세션 유지용 쿠키 1종(`gbf_session`, 로그인 시에만 설정)을 사용한다. 광고·분석 목적 쿠키는 사용하지 않는다.

## 7. 공고 데이터 출처 고지
공고 정보는 공식 출처(예: 기업마당)에서 수집하며, 각 공고에 출처와 최종 확인 시각, 공식 원문 링크를 표시한다. 제공 정보는 참고용이며 최종 신청 자격은 공식 원문과 담당기관 확인이 기준이다.

## 8. 운영 전 결정이 필요한 항목
- [ ] 운영 주체명·개인정보 보호책임자·문의처
- [ ] 보유기간 확정(열람 이력·알림 자동 삭제 구현 여부)
- [ ] 계정 탈퇴 절차(기능 구현 또는 수동 처리 절차)
- [ ] 이메일 등 알림 발송 도입 시 동의 문구·위탁 고지
- [ ] 법률 검토 및 시행일·개정 이력 관리
