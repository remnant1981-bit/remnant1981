# 개발 로그
## Phase 0 — 저장소·환경
- 저장소 `remnant1981`은 Flask/티스토리/쿠폰 앱 등 무관한 기존 프로젝트 → 기존 파일 무변경, `govbiz-finder/` 하위에 구축(사용자 승인). 기존 GitHub Pages 워크플로는 `coupon-wallet/**` 경로 한정이라 영향 없음.
- 환경: Node 22, npm 10. DB는 D1 호환 SQLite SQL + `node:sqlite`(로컬/테스트). 명세 간 충돌 없음.
- 위험: D1/Workers 이식성(DEPLOYMENT.md), 실 원천 미연동, 본인확인 공급자 미정.
## Phase 1~2 — 골격/DB
- Next.js 16 + TS + Tailwind 4, 반응형·접근성(skip link, label, aria-live, 포커스 링), 보안 헤더(CSP 등). 마이그레이션 `0001_init.sql`(명세 DATABASE.md 전 테이블 + 개정/출처/알림설정/rate_limits).
## Phase 3~4 — 수집/검색
- 어댑터 runner(원천 독립·지수 백오프·partial/failed 기록), 중복 4단계 판정(+출처 병합 보존), 변경 이력. 검색 URL 상태 유지, 전국 공고 누락 방지, LIKE 와일드카드 이스케이프.
## Phase 5~7 — 기업/인증/추천
- 상태조회 adapter(mock=테스트 데이터 표기). 사업자번호 AES-GCM 암호화+HMAC 인덱스+마스킹. 기업 관계 확인은 계정 생성과 분리, 승인 전 기업 데이터 전면 차단, 기업당 대표 1명.
- 적합성 MET/NOT_MET/UNKNOWN. **테스트로 발견·수정한 버그**: 업력 경계(365.25일 환산 오차 → 달력 기준 n주년 판정).
## Phase 8~10 — 내보내기/이력/관리자
- XLSX(헤더 고정·자동필터·날짜형식·수식주입 방지), CSV(BOM·이스케이프), PDF(Noto Sans KR 임베딩, 한글 확인), 인쇄 CSS. 알림 dedupe_key 중복 방지. 관리자 감사 로그(민감값 마스킹).
## Phase 11 — 검증 결과
- `npm run lint` 오류 0(경고 3, 의도적), `typecheck` 통과, `build` 통과, `vitest` 44개 통과(권한/보안 TEST_PLAN §3 전 항목 + 시나리오 §4 + 단위/통합).
- 프로덕션 서버 대상 Playwright 스모크: 검색→상세→가입→신청(pending 시 403 확인)→관리자 승인→프로필→상태조회(테스트 데이터 고지)→관심공고→XLSX/CSV/PDF 다운로드→모바일 가로 스크롤 없음→비회원 추천 체험 통과.

4. 이메일/카카오/SMS 미구현. 앱 내 알림은 `npm run collect` 등 배치 실행 시 생성(스케줄러 미설정).
5. (해결) 관리자 수정 공고는 `admin_locked`로 수집 덮어쓰기 방지(0002 마이그레이션, 테스트 포함). 잠금 해제 UI는 없음.

7. `npm audit` 중간 등급 10건(exceljs/ eslint 하위 의존성: uuid, minimatch) — 개발/내보내기 경로, 업스트림 수정 대기.
8. 서버 컴포넌트 렌더 중 추천 이력(company_matches) 저장 수행(부작용) — 후속 분리 권장.
