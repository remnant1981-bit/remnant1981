# 관리자·운영·SEO 명세

## 1. 관리자
- 관리자 계정 및 역할 분리
- 공고 등록·수정·비활성화
- 원천별 수집 활성/비활성
- 수집 실행 결과·오류 확인
- 중복 공고 검토
- 공고 데이터 수정 이력
- 관리자 주요 행위 감사 로그

관리자 화면은 일반 사용자에게 노출하지 않고 서버 측 권한을 확인한다.

## 2. 광고
- 초기에는 광고 없이 핵심 서비스의 사용성을 검증한다.
- 광고를 도입할 경우 공고 검색 결과와 명확히 구분하고, 광고임을 표시한다.
- 광고가 검색 순위나 적합도 평가에 영향을 주지 않도록 한다.

## 3. SEO
- 공개 공고 상세 페이지의 검색엔진 색인 허용 여부를 검토한다.
- 중복 URL canonical 처리
- 제목·설명 메타데이터
- sitemap.xml 및 robots.txt
- 기업별 비공개 페이지·이력·프로필은 검색엔진 색인 금지
- 원문 출처를 명확히 표시
