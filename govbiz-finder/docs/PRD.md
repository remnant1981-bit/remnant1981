# 제품 요구사항 정의서(PRD)

## 1. 제품 개요
서비스명(가칭): GovBiz Finder

한 줄 정의: 전국 중앙부처·공공기관·지자체·지역 유관기관의 기업지원사업을 통합 검색하고, 기업이 제공한 정보에 따라 관련 사업을 찾아주는 서비스.

핵심 메시지: **몰라서 놓치는 지원사업이 없도록.**

## 2. 해결할 문제
- 기업지원사업 정보가 기관별 홈페이지에 흩어져 있다.
- 정보 탐색 능력이나 네트워크 차이로 기업 간 정보 격차가 발생한다.
- 시·군·구 및 지역 테크노파크·산업진흥기관의 지역 한정 사업은 별도 탐색하지 않으면 놓치기 쉽다.
- 공고문마다 지원 대상·기간·제출서류 형식이 달라 비교와 관리가 어렵다.

## 3. 대상 사용자
- 중소기업 및 중견기업 실무자
- 대표자 및 경영지원 담당자
- 연구개발·기술사업화 담당자
- 창업기업 및 지역 소재 기업
- 지원사업 정보를 조사·관리하는 컨설턴트(향후)

## 4. 제품 원칙
1. 비회원도 기본 검색의 가치를 경험한다.
2. 기업정보 입력을 강제하지 않는다.
3. 사업자번호 조회와 기업 계정 인증을 분리한다.
4. 자격 미확인과 자격 미충족을 구분한다.
5. 공식 원문으로 연결하고 정보의 기준 시각을 표시한다.
6. 전국 공고와 지역 특화 공고를 함께 제공한다.
7. PDF뿐 아니라 실무 활용성이 높은 XLSX·CSV 내보내기를 지원한다.

## 5. 사용자 흐름
### 비회원
홈 → 검색어/분야/지역 선택 → 결과 필터링·정렬 → 공고 상세 → 공식 원문 이동 또는 파일 다운로드.

### 회원
회원가입 → 기업 관계 확인 → 기업 프로필 등록(선택 입력) → 맞춤 추천 → 관심 공고·검색/열람 이력 저장 → 알림 설정.

### 기업정보 조회
사업자번호 입력 → 국세청 사업자 상태조회 → 조회 가능한 상태정보 표시 → 나머지 정보는 직접 입력 또는 선택 생략 → 추천 결과 제공.

## 6. 기능 우선순위
### 필수(MVP)
- 반응형 웹
- 공개 공고 통합 목록 및 검색
- 분야·지역·기관·접수상태 필터
- 공고 상세 및 공식 원문 링크
- 데이터 출처·최종 확인 시각 표시
- 기본 공고 수집 프레임워크와 관리자 수동 등록
- 사업자 상태조회 API 연계(키가 없으면 모의 어댑터와 설정 안내)
- 기업정보 선택 입력
- 회원·기업별 접근통제
- 규칙 기반 적합성 표시
- XLSX·CSV 내보내기
- 기본 관리자 기능과 수집 로그
- 보안·권한 테스트

### 기본 구현(초기 출시 범위에 포함)
- PDF 보고서/인쇄
- 관심 공고
- 검색 이력 및 열람 이력(회원)
- 마감 임박 표시
- 신규 공고 알림의 기본 구조(이메일 등 실제 발송은 공급자 설정 후 활성화)
- 관리자 공고 등록·수정·비활성화

### 후속 확장
- 직원 초대·기업 내 역할 관리
- 카카오 알림톡/SMS
- Google Sheets API 직접 연동
- 고급 추천 및 AI 기반 공고문 구조화
- 더 많은 지자체·기관 커넥터
- 기업별 신청 진행 워크플로

## 7. 비기능 요구사항
- 모바일·태블릿·데스크톱 대응
- 검색 결과 페이지네이션
- API 오류 시 명확한 오류·재시도 상태
- 수집 작업과 사용자 검색 API 분리
- 기업별 데이터 격리
- 개인정보 최소 수집
- 비용과 외부 API 호출량 관리
- 접근성 기본 준수(키보드 탐색, 명확한 레이블, 대비)
- 시간대는 기본 Asia/Seoul, DB 저장은 UTC 권장
