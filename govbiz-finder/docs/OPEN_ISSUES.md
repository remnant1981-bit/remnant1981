# 외부 확인 및 결정이 필요한 항목

Claude Code는 아래 항목을 임의로 사실로 가정하지 말고, 구현 전 공식 문서와 현재 환경을 확인한다. 확인 불가 시 mock/adapter와 설정 안내를 만들고 실제 연동 미완료로 표시한다.

1. 각 공고 원천의 최신 API, 인증 방식, 쿼터, 이용약관, 재배포 허용 범위
2. 국세청 사업자등록정보 상태조회·진위확인 API의 현재 필드, 요청값, 응답값, 승인 및 호출 제한
3. Cloudflare Pages/Workers/D1/R2의 현재 무료 한도·유료 전환 조건
4. 기업 관계 확인에 사용할 본인확인/사업자 증빙 방식 및 공급자 비용
5. 이메일 발송 공급자 및 발송 도메인 설정
6. 실제 운영 개인정보 처리방침·보유기간·동의 문구
7. 지원사업 공고 데이터의 저장·요약·재배포 범위

초기 MVP에서 외부 서비스 계약이나 유료 가입이 필요한 기능은 연동 인터페이스까지만 구현하고, 사용자가 승인하기 전에는 실제 호출하지 않는다.
