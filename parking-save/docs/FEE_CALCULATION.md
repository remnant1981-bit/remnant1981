# 주차요금 계산 엔진

## 입력
- 주차장 ID
- 시작 일시
- 종료 일시
- 적용 지역의 공휴일 판정 데이터(확보 시)
- 해당 시설의 검증된 요금/운영 규칙

## 계산 원칙
1. 시작~종료 구간을 날짜 및 요일/시간대 경계로 분할한다.
2. 각 구간에 해당하는 운영·무료·유료 규칙을 적용한다.
3. 기본요금, 추가요금 단위, 일일 최대요금, 시간대별 요금 등을 원천 규칙에 맞게 계산한다.
4. 날짜가 바뀌는 경우 일일 최대요금 초기화 여부를 시설별 규칙에 따라 적용한다.
5. 규칙이 불완전하거나 서로 충돌하면 임의 계산하지 않고 `정확한 요금 계산 불가`를 반환한다.
6. 계산 결과에는 적용된 규칙과 데이터 기준일을 함께 제공한다.

## 중요 예외
- 무료 개방 시간이 주차 구간 일부에만 적용되는 경우 해당 구간만 무료 처리한다.
- 주말/공휴일 무료 여부는 시설별 근거가 있을 때만 적용한다.
- 운영시간 외 출차/입차 제한은 요금과 별도로 표시한다.
- 공휴일 규칙이 확인되지 않으면 평일/주말 규칙을 임의 대입하지 않는다.
- 요금 데이터 없음은 0원으로 계산하지 않는다.

## 테스트
분 단위 경계, 추가요금 올림/내림 규칙, 자정 통과, 주말 전환, 공휴일, 무료시간 전환, 일일 최대요금, 운영 종료, 규칙 누락/충돌을 테스트한다.
