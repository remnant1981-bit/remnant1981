# 개발 계획 및 마일스톤

## Phase 0 — 저장소/환경 파악
- 기존 코드와 패키지 매니저 확인
- 실행·테스트·배포 방법 확인
- 문서와 기존 구현 간 충돌 기록

## Phase 1 — 데이터 모델/샘플 원천
- 원천 후보 조사 및 실제 샘플 호출
- 공영 여부·요금·운영시간 필드 커버리지 분석
- 통합 스키마와 정규화 규칙 구현
- 원천 응답 보존 및 수집 로그

## Phase 2 — 검색 MVP
- 위치/목적지 기반 검색
- 지도/목록 UI
- 거리 계산 및 필터/정렬
- 정보 없음 상태 처리

## Phase 3 — 요금 엔진
- 요일·시간대·공휴일 규칙 모델링
- 시작/종료 시각 기반 계산
- 계산 불가 사유 및 적용 규칙 노출
- 단위 테스트

## Phase 4 — 추천 및 지도 연동
- 무료 우선/요금순/거리순
- 네이버 지도 앱 연동 검증 및 구현
- 미설치/호출 실패 대체 동작

## Phase 5 — 실시간 정보/운영
- 제공 시설 대상 잔여면수 연동
- 데이터 신선도 검증
- 관리자 데이터 갱신/품질 모니터링

## 출시 게이트
- 요금 계산 정확성 테스트 통과
- 미확인 정보를 무료/실시간 상태로 오표시하지 않음
- 출처·기준일 표시
- 위치 권한과 API 키 보안 검증
