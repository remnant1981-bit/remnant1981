# 추천 로직

## 목표
무료·저렴함, 목적지와의 거리, 운영 가능 여부, 실시간 주차 가능 정보를 함께 고려해 비교 가능한 결과를 제공한다.

## 기본 원칙
- 요금 계산이 가능한 시설은 입력한 주차 시간에 대한 예상 금액을 사용한다.
- 무료 시설은 우선 노출할 수 있으나 거리와 운영 상태를 숨기지 않는다.
- 거리만 확인 가능하고 요금이 불명확한 시설은 가격 기준 순위에 임의 포함하지 않는다.
- 실시간 잔여면수는 최신성 기준을 통과한 데이터만 사용한다.
- 잔여면수 정보가 없다는 이유로 낮은 점수를 부여하지 않는다.

## 초기 정렬 프리셋
1. 무료 우선
2. 예상 요금 낮은 순
3. 거리 가까운 순
4. 실시간 여유 순(유효 데이터 존재 시)

## 고도화
MVP에서는 설명 가능한 규칙 기반 정렬을 우선한다. 사용자 행동 데이터가 충분히 축적된 뒤 가중치 기반 추천을 검토한다. 추천 사유를 사용자에게 설명할 수 있어야 한다.
