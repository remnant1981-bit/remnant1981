# 네이버 지도 연동

## 목표 흐름
파킹세이브에서 주차장을 선택하면 네이버 지도 앱 또는 지원되는 지도 호출 방식으로 목적지 주차장까지 이동 안내를 연다. 주차 후 목적지까지 도보 경로 안내도 연결하는 것을 목표로 한다.

## 구현 전 검증
- 네이버 지도 공식 앱 연동/URL Scheme 문서 확인
- Android/iOS별 호출 방식과 설치 여부 처리 확인
- 목적지 좌표·명칭 인코딩 규칙 확인
- 자동차 길찾기 및 도보 길찾기 지원 여부 확인
- 앱 미설치 시 웹 지도 또는 스토어/브라우저 대체 동작 확인
- 관련 API·브랜드·호출 정책 및 사용 조건 확인

## 원칙
- 자체 내비게이션은 MVP 범위에서 제외한다.
- 딥링크 형식은 공식 문서 검증 후 구현한다. 검증 전 임의 URL을 확정하지 않는다.
- 지도 앱 호출 실패 시 주소/좌표 복사 등 대체 수단을 제공한다.
