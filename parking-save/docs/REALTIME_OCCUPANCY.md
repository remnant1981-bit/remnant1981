# 실시간 잔여면수 및 혼잡도

## 표시 기준
- 전체면수와 잔여면수가 모두 유효하고 관측시각이 신선도 기준을 통과한 경우 잔여면수 표시
- 잔여 비율 = 잔여면수 / 전체면수 × 100
- 혼잡도 구간은 초기 운영값으로 여유/보통/혼잡 등 단순 구분을 둘 수 있으나, 임계값은 설정값으로 관리하고 실제 데이터 특성 검토 후 확정
- 실시간 정보가 없거나 오래된 경우 `실시간 확인 불가` 표시

## 금지 사항
- 과거 평균이나 주변 교통량만으로 실시간 잔여면수를 만들어내지 않는다.
- 제공기관의 갱신 시각이 없으면 현재 정보인 것처럼 표시하지 않는다.
- 총면수 또는 잔여면수의 의미가 원천에서 불명확하면 혼잡도 산출에 사용하지 않는다.

## 후속 기능
요일·시간대별 과거 점유 패턴은 충분한 관측 데이터가 축적된 경우에만 별도 참고 정보로 제공한다. 실시간 상태와 예측/통계 정보는 UI에서 명확히 구분한다.
