# OPEN ISSUES — 미확정 및 검증 필요 항목

다음 항목은 개발자가 임의로 확정하지 말고 조사 결과와 근거를 기록한 뒤 결정한다.

1. **공공데이터 원천별 실제 커버리지:** 전국 주차장 표준데이터의 공영 여부/노상·노외/좌표/요금/운영시간 필드 품질.
2. **한국교통안전공단 API:** 실제 서비스명, 엔드포인트, 인증, 호출 제한, 실시간 잔여면수 제공 시설 범위 및 갱신 주기.
3. **지자체 API:** 지역별 제공 조건, 데이터 라이선스, 표준화 난이도.
4. **공휴일 판정:** 공휴일 데이터 원천과 임시공휴일 반영 방식.
5. **요금 규칙 예외:** 일일 최대요금의 날짜 경계, 회차/정기권, 입출차 제한, 공휴일 별도 규정.
6. **검색 반경 기본값:** 초기 1km 제안값의 적절성.
7. **실시간 신선도 기준:** 원천별 갱신주기를 확인한 뒤 설정.
8. **혼잡도 임계값:** 데이터 분포 검토 후 여유/보통/혼잡 구간 설정.
9. **네이버 지도 연동:** 공식 앱 연동 URL/SDK 정책, Android/iOS 동작 및 웹 대체 경로.
10. **배포/운영 인프라:** 호스팅, DB, 스케줄러, 모니터링 비용 및 지역.
11. **서비스 법적 고지:** 공공데이터 출처표시 및 이용조건, 위치정보 처리 관련 요건.

- 항목: #4 공휴일 판정 (D1 포함) — **원천 조사 완료, 실응답 검증은 키 필요**
- 조사일: 2026-11-07
- 확인한 공식 문서/샘플:
  - 공공데이터포털 한국천문연구원_특일 정보 https://www.data.go.kr/data/15012690/openapi.do (기본정보·이용조건·기념일 오퍼레이션의 요청/응답 표·오류코드)
  - 국가법령정보센터 「관공서의 공휴일에 관한 규정」(시행 2026.5.11) https://www.law.go.kr/LSW/lsInfoP.do?lsiSeq=285779
- 확인 결과:
  - 법적 정의: 제2조 공휴일 = **일요일** + 국경일 + 신정·설·부처님오신날·노동절·어린이날·현충일·추석·성탄절 + 임기만료 선거일 + 정부 수시 지정일(임시공휴일, 제4조: 국무회의 심의). 제3조 대체공휴일(토·일·다른 공휴일과 겹칠 때 다음 첫 비공휴일).
  - 특일 정보 API: 무료, 이용허락범위 제한 없음, 업데이트 주기 "실시간", 개발계정 10,000건(운영계정은 활용사례 등록 시 증량), 서비스 URL `https://apis.data.go.kr/B090041/openapi/service/SpcdeInfoService`. 요청 `ServiceKey, pageNo, numOfRows, solYear(필수), solMonth(선택)`, 응답 `resultCode, totalCount, locdate(YYYYMMDD), seq, dateKind, isHoliday(Y/N), dateName`. 포맷은 공식 페이지상 XML.
  - **미확인**: 공식 페이지에는 기념일(`getAnniversaryInfo`) 탭만 표시됨. 공휴일 오퍼레이션 `getRestDeInfo`와 `_type=json`은 2차 자료(GitHub 이슈, 블로그) 기준. 미래 연도 공표 시점, 임시공휴일·선거일·대체공휴일 반영 속도(블로그 사례 1~2일, 비공식), 일요일 포함 여부, 지방공휴일(예: 제주 4·3) 미포함 여부.
- 영향 범위: `src/collector/holidays.ts`, `loadHolidays`(요금·운영 판정), `holidays`/`holiday_coverage` 테이블(0003), 요일별 규칙 시설의 요금 계산 가능 여부.
- 결정(잠정):
  1. 1차 원천은 특일 정보 API. 매일 1회 수집 권장(월 24회 호출 ≪ 일 10,000건).
  2. **커버리지 명시**: 당해·다음 해를 월별 수집하되 12개월 전부 성공 + canary(1/1·12/25)가 있는 연도만 완전한 연도로 인정하고, 연속 구간만 `holiday_coverage`로 선언. 미공표 연도는 '공휴일 없음'이 아니라 '판정 불가'.
  3. **만료**: 마지막 성공 수집이 7일을 넘으면 커버리지 무효(임시공휴일 지정 누락 위험) → 요일별 규칙 시설은 요금 계산 불가. 수집 실패 시 기존 데이터는 유지(만료까지만 유효).
  4. 같은 날 겹침(seq), 원천 분류코드 보존, 취소된 공휴일은 재수집으로 제거.
  5. 키 검증 전 운영 사용 금지: 첫 실행 결과(연도별 건수·명칭)를 법령·공식 달력과 육안 대조.
- **사용자 결정 필요**: 주차장 원천의 "공휴일" 운영·요금 규칙을 일요일에도 적용할지. 법적 정의는 일요일 포함이며 표준데이터에 `평일+토요일+공휴일`로 7일 운영을 표기하는 사례가 있어 포함 가능성이 높으나, 원천 정의가 문서화되어 있지 않아 현재는 **일요일 규칙을 만들지 않고 '운영 확인 불가'로 둠**. 적용 시 원천별 정책 옵션(`sundayAsHoliday`)으로 구현 권장.
- 한계: 지방공휴일·지자체 임시 무료개방일은 이 원천에 없음(주차장별 특기사항에 의존).

- 항목: #9 네이버 지도 연동 (**문서 검증 완료, 실기기 동작·이용 약관은 미검증**)
- 조사일: 2026-11-07
- 확인한 공식 문서/샘플: Ncloud Maps 문서 "URL Scheme for integration of Maps app" https://guide.ncloud-docs.com/docs/en/application-maps-url-scheme-vpc (한국어판 https://guide-gov.ncloud-docs.com/docs/naveropenapiv3-maps-url-scheme-url-scheme)
- 확인 결과:
  - 형식 `nmap://<action>?<params>&appname=<식별자>`. **appname 필수**(Android: applicationId, iOS: bundle ID, 모바일 웹: 웹 페이지 URL).
  - 사용 액션: `route/car`(자동차), `route/walk`(도보), `place`(마커: lat·lng·name 필수), `navigation`, `search`. 경로 공통 파라미터 `slat/slng/sname`(선택, 생략 시 현재 위치), `dlat/dlng`(필수), `dname`(선택, URL 인코딩). 좌표 범위 위도 31.43~44.35, 경도 122.37~132.00.
  - **앱 설치 필수**. 미설치 처리는 호출 측 구현: Android 모바일 웹은 Intent URL(`intent://…#Intent;scheme=nmap;…;package=com.nhn.android.nmap;end`)로 Play 스토어 자동 이동, iOS는 앱스토어(id311867728)로 분기(문서의 JS 타이머 예제 본문은 스크랩에서 비어 있어 미확인).
  - 도보 길찾기 지원, 자전거·대중교통도 있음.
- 영향 범위: `src/domain/map-link.ts`, `src/components/MapLinks.tsx`, 상세 화면.
- 결정:
  1. 자체 내비게이션 없이 `route/car`(현재 위치→주차장), `route/walk`(주차장→검색한 목적지), `place` 링크만 제공. 도보는 목적지 검색일 때만(현재 위치 검색은 목적지 없음).
  2. Android: Intent URL 앵커. iOS: 클릭 시 scheme 호출 후 1.8초 내 화면 전환이 없으면 앱스토어·복사 대체 안내. 그 외(데스크톱): 버튼 비활성 + 주소·좌표 복사.
  3. 좌표 범위 밖·appname 없음이면 링크 미생성(복사만).
  4. appname은 환경변수 `SITE_URL`(운영 도메인) 사용.
- 미검증/후속: Android·iOS 실기기에서 앱 호출·미설치 분기 확인, iOS 대체 동작 실측, 웹 지도 대체 URL(공식 문서 미확인이라 미구현), URL Scheme 이용 약관·브랜드 표기 정책 확인(릴리스 체크리스트).
