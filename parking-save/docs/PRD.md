# PRD — 제품 요구사항 정의

## 1. 제품 개요
- 서비스명: 파킹세이브(ParkingSave)
- 슬로건: 주차하기 전에, 주차비부터 아끼자!
- 목표: 사용자가 목적지에 도착하기 전에 공영주차장의 위치·요금·운영시간·주차 가능 정보를 비교해 합리적인 선택을 하도록 지원한다.

## 2. 대상 사용자와 문제
운전자는 목적지 주변의 공영주차장, 무료 개방 시간, 요일별 요금 차이, 예상 주차비 및 잔여면수를 여러 출처에서 각각 확인해야 한다. 파킹세이브는 이를 하나의 검색 흐름으로 통합한다.

## 3. 범위
### 포함
- 전국 공영주차장 검색(노상·노외)
- 무료 개방 주차장 및 요일·시간대별 요금 규칙
- 현재 위치/목적지 기준 검색
- 주차 시작·종료 시각 입력 및 예상 요금 계산
- 거리·요금·잔여면수 비교 및 추천 정렬
- 주차면수 및 실시간 잔여면수(제공되는 시설만)
- 네이버 지도 앱 연동을 통한 자동차/도보 이동 흐름
- 데이터 출처, 기준일, 갱신 상태 표시

### 제외(MVP)
- 민영주차장
- 자체 내비게이션
- 데이터 근거가 없는 혼잡도 추정
- 예약·결제·주차권 구매
- 사용자 제보를 검증 없이 공식 데이터로 반영

## 4. 핵심 사용자 흐름
1. 사용자가 현재 위치를 사용하거나 목적지를 검색한다.
2. 주차 시작 일시와 종료 일시를 입력한다.
3. 주변 공영주차장 결과를 지도/목록으로 확인한다.
4. 무료 우선, 예상 요금, 거리, 실시간 잔여면수 기준으로 정렬한다.
5. 주차장 상세에서 요금 규칙·운영시간·면수·데이터 기준일을 확인한다.
6. 선택한 주차장을 네이버 지도 앱으로 열어 이동한다.
7. 주차 후 목적지까지 도보 이동은 지도 앱에서 안내한다.

## 5. 주요 성공 지표
- 검색 성공률 및 검색 응답시간
- 요금 계산 가능 시설 비율
- 위치·요금·운영시간 데이터 최신성
- 실시간 잔여면수 제공 시설 비율
- 목적지 주변 결과에서 상세 보기/지도 실행 전환율
- 요금 계산 오류율

## 6. 비기능 요구사항
- 모바일 우선 반응형 UI
- 개인정보 최소 수집 및 위치 권한 선택 동의
- 외부 API 장애 시 캐시 데이터와 상태 안내
- 데이터 출처와 갱신시각 추적
- 서버 비밀키 보호 및 호출량 제한
