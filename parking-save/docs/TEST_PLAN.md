# 테스트 계획

## 단위 테스트
- 요금 기본/추가 단위 계산
- 평일/주말/공휴일 경계
- 무료 시간대와 유료 시간대 혼합
- 자정 및 날짜 변경
- 일일 최대요금 적용
- 운영시간 외 주차
- 규칙 누락/충돌 시 계산 불가 처리
- 거리 계산 및 정렬 안정성
- 잔여 비율 및 혼잡 구간 설정

## 통합 테스트
- 원천 데이터 수집 → 정규화 → DB 저장
- 중복 후보 탐지
- 검색 API의 위치/시간 조건
- 원천 장애 시 캐시/부분 결과
- 실시간 데이터의 관측시각/신선도 검증
- 지도 딥링크 파라미터 및 대체 흐름

## UI 테스트
- 위치 권한 허용/거부
- 목적지 직접 검색
- 시작/종료 시간 입력
- 무료/요금순/거리순 정렬
- 정보 없음/실시간 확인 불가 표시
- 모바일 화면 및 접근성

## 핵심 회귀 기준
요금 정보가 없을 때 0원으로 노출되지 않아야 한다. 실시간 데이터가 없을 때 혼잡도를 추정해 표시하지 않아야 한다.
