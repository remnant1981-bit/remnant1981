# 보안 및 개인정보

## 위치정보
- 현재 위치는 사용자 동의 후 사용한다.
- 가능한 경우 위치를 서버에 장기 저장하지 않고 검색 요청에만 사용한다.
- 목적지 검색 기록 저장은 기본 비활성화 또는 명시적 동의 기반으로 설계한다.
- 위치 권한 거부 시 주소/목적지 직접 입력으로 이용 가능해야 한다.

## 보안
- API 키·DB 비밀번호는 환경변수/비밀관리 시스템으로 관리한다.
- 관리자 수집 API는 인증·인가 및 감사로그를 적용한다.
- 입력값 검증, 요청 제한, 오류 메시지 내 민감정보 제거
- HTTPS 적용 및 의존성 취약점 점검

## 데이터
- 주차장 공공정보와 사용자 위치정보를 구분한다.
- 외부 데이터의 이용허락·출처표시·재배포 조건을 준수한다.
- 로그 보존기간과 사용자 데이터 삭제 정책을 문서화한다.
