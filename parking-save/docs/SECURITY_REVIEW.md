# 출시 전 자체 보안 점검 (2026-11-13)

범위: `parking-save` 앱 코드·배포 설정(`deploy/naver`)·의존성. 방법: 코드 전수 확인(경로별 요청 제한·입력 검증·SQL 조립·출력 이스케이프·비밀값 처리), 실데이터 빌드에서 측정, 회귀 테스트 추가.
**전문 보안 진단(모의 해킹)을 대체하지 않음** — 공개 출시 전 외부 점검 권장.

## 1. 결과 요약

| # | 항목 | 판정 | 조치 |
|---|---|---|---|
| 1 | 공유 이미지(`/lots/:id/opengraph-image`) 요청 제한·캐시 없음 — 1장 렌더에 CPU 60~110ms, 1.6만 개 ID를 돌며 요청하면 서버(1 vCPU)를 묶을 수 있음 | **수정** | 클라이언트당 분당 120회 제한 + 시설별 PNG 1시간 메모리 캐시(최대 300장) |
| 2 | 신고 API: `Origin: null`·잘못된 Origin이면 URL 해석 예외로 500 | **수정** | 같은 사이트가 아니면 403. 회귀 테스트(수정 전 실패 확인) |
| 3 | 신고 API: 본문 크기 제한이 nginx(64KB)에만 있음 | **수정** | 앱에서 8KB 초과 413(Content-Length 없는 전송도 실제 크기로 확인) |
| 4 | 요청 제한기 메모리: 많은 주소에서 동시에 몰리면 키가 끝없이 늘 수 있음 | **수정** | 키 최대 5만 개, 넘치면 오래된 키부터 제거 |
| 5 | 지역 목록(`/area`)·언어 전환(`/lang`) 요청 제한 없음 | **수정** | 지역 목록 분당 120회, 언어 전환 분당 30회 |
| 6 | HSTS 헤더 없음 | **수정** | 운영에서 `Strict-Transport-Security: max-age=31536000`(HTTPS일 때만 유효). 하위 도메인·preload는 도메인 확정 후 결정 |
| 7 | CSP `script-src 'unsafe-inline'` | 유지(알려진 한계) | Next.js 하이드레이션 인라인 스크립트 때문. 외부 스크립트·연결은 막혀 있음. nonce 방식은 후속 |
| 8 | 개발 의존성 취약점(moderate 8건, `minimatch` ← eslint 계열) | 유지 | 개발 도구 전용, 운영 이미지·런타임 미포함. **운영 의존성 취약점 0건**(`npm audit --omit=dev`) |

## 2. 확인했고 문제 없던 항목

| 영역 | 확인 내용 |
|---|---|
| SQL 주입 | 모든 쿼리가 자리표시자(`?`) 사용. 문자열 보간은 상수(열 이름·`?` 목록·고정 조건)뿐. 목적지 검색 `LIKE`는 `%`·`_`·`\` 이스케이프 |
| XSS | React 기본 이스케이프. `dangerouslySetInnerHTML`은 JSON-LD 1곳(`<`를 `<`로 치환). 지도 팝업은 `textContent`만 사용. 데모는 `esc()` |
| 오픈 리다이렉트 | `/lang`의 `next`는 같은 사이트 경로만(`//`·`/\`·줄바꿈·2,000자 초과 거부), Location은 상대 경로 |
| 관리자 | nginx가 `/admin`·`/api/admin` 외부 차단(SSH 터널 전용) + Bearer 토큰(32자 이상, 상수 시간 비교) + 분당 30회 + 실패·처리 감사로그(클라이언트는 솔트 해시) |
| 경로 매개변수 | 시설 ID `^\d{1,9}$`, 지역은 알려진 시·도 + 시·군·구 형식만 |
| 요청 제한 우회 | `X-Forwarded-For`는 끝에서 N번째(신뢰 프록시 수) 값 사용 — 클라이언트가 넣은 앞쪽 값 무시 |
| 개인정보 | 좌표는 URL·메모리에만, 서버 저장·접속 로그(nginx 쿼리 제외 형식)·앱 로그(가림 처리) 없음. 즐겨찾기·최근 검색·타이머는 기기 저장. 신고는 이름·연락처 미수집 |
| 비밀값 | 환경변수 전용(`/etc/parking-save/env` 권한 600), 저장소·로그·오류 응답 미포함. 로그에서 `serviceKey=`·Bearer 토큰 가림 |
| 쿠키 | 언어 쿠키만 사용(`HttpOnly`, `SameSite=Lax`, 운영 `Secure`), 위치·개인정보 없음 |
| 서비스 워커 | 화면 이동만 처리, 검색 결과·API 응답 캐시 안 함. 알림 클릭 이동은 같은 사이트 경로만 |
| 외부 요청(SSRF) | 이용자 입력으로 서버가 외부 주소를 호출하는 경로 없음(수집 대상 주소는 코드 고정) |
| 오류 응답 | 내부 오류 내용은 응답에 포함하지 않음(`INTERNAL_ERROR` 고정 문구), 서버 로그에만 |

## 3. 남은 권장 사항 (출시 전·후)

1. 외부 전문 점검(모의 해킹) 1회 — 특히 관리자 경로 차단이 nginx 설정에 달려 있으므로 실제 서버에서 `curl https://<도메인>/admin` → 404 확인.
2. 서버 SSH: 비밀번호 로그인 끄기, 키 인증만(네이버클라우드 콘솔 ACG에서 22번 포트 접속 IP 제한).
3. 관리자 토큰은 노출 의심 시 `/etc/parking-save/env`에서 교체 후 `parking-update`.
4. CSP nonce 적용(후속), 요청 제한을 서버 여러 대로 늘릴 때는 공유 저장소 방식으로 교체.
5. 개발 의존성 취약점은 eslint 계열 업데이트 시 함께 해소.
