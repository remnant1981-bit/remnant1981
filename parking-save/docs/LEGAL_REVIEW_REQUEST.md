# 법률 검토 요청서 — 파킹세이브

작성 2026-11-14. 검토자(변호사·개인정보 전문가)에게 그대로 보낼 수 있게 서비스 사실관계와 질문을 정리함. 약관·처리방침 초안은 서비스의 `/terms`, `/privacy` 화면(저장소 `src/app/terms`, `src/app/privacy`)에 있음.

## 1. 서비스 개요 (사실관계)

| 항목 | 내용 |
|---|---|
| 성격 | 공영주차장 정보 비교 웹 서비스(무료). 예약·결제·주차장 운영 없음 |
| 운영 형태 | 운영 주체 **미정**(개인 또는 법인 — 검토 결과에 따라 결정) |
| 회원 | 없음. 이름·연락처·이메일 수집 없음 |
| 데이터 원천 | 공공데이터포털 전국주차장정보표준데이터, 한국천문연구원 특일 정보, 서울 열린데이터광장(실시간 잔여면수, 선택) |
| 서버 | 국내 클라우드(네이버클라우드) 1대, 서울 리전 예정 |
| 광고·유료 기능 | 현재 없음 |

### 위치정보 처리 흐름
1. 이용자가 "현재 위치 사용"을 누르고 **브라우저 위치 권한을 허용**하면, 기기에서 좌표를 소수 넷째 자리(약 11m)로 줄여 검색 요청 주소(쿼리 문자열)에 담아 서버로 보냄.
2. 서버는 좌표로 반경 안 주차장을 찾아 응답. **DB·파일에 저장하지 않음**. 같은 조건 재검색을 위해 결과를 **메모리에 최대 30초** 보관(좌표 포함), 이후 소멸.
3. 웹 서버 접속 로그는 쿼리 문자열을 **빼고** 기록(좌표 미기록). 앱 오류 로그도 좌표·검색어를 가림.
4. 요청 제한을 위해 **IP 주소를 메모리에서 최대 1시간** 사용(저장 안 함).
5. 결과 공유 링크에는 좌표를 소수 셋째 자리(약 100m)로 줄여 담음 — 이용자가 직접 공유할 때만.
6. 지도 보기를 열면 이용자 브라우저가 지도 이미지 서버(OpenStreetMap 또는 브이월드)에 직접 접속 → 그 서버에 IP·보고 있는 지도 영역이 전달됨.
7. 네이버 지도 앱 길찾기를 누르면 주차장 좌표·이름이 앱으로 전달됨(이용자 위치는 앱이 직접 사용).
8. 즐겨찾기·최근 검색·주차 타이머·알림 설정은 **이용자 기기에만** 저장.

### 서버에 저장되는 정보
- 정보 오류 신고: 유형·내용(자유 입력 500자)·시각·IP를 복원할 수 없게 변환한 값(앞 16자리, 도배 방지)
- 웹 서버 로그: 시각·IP·경로(검색 조건 제외)·응답 코드, 현재 14일 순환
- 관리자 처리 기록: 운영자 이름·처리 내역, 관리자 접근 기록(IP 변환값)
- 쿠키: 화면 언어 1개(`ps-lang`, 1년)

## 2. 질문

### A. 위치정보법
1. 위 흐름에서 **위치기반서비스사업 신고**(위치정보의 보호 및 이용 등에 관한 법률)가 필요한가? 좌표를 저장하지 않고 요청 처리에만 쓰며 30초 메모리 캐시가 있음.
2. 신고가 필요하다면 개인/법인 중 어느 형태가 현실적인지, 신고 전 서비스 공개(시험 운영)가 가능한지.
3. 위치 이용 **동의**를 브라우저 권한 창 + 처리방침 고지로 갈음할 수 있는지, 별도 동의 화면이 필요한지.
4. 위치정보 이용·제공 사실 확인자료 보관 의무가 적용되는지(저장하지 않는 구조에서).
5. 만 14세 미만 이용자의 위치 이용 시 법정대리인 동의가 필요한지, 연령 확인 없이 운영 가능한지.

### B. 개인정보보호법
6. IP 주소의 메모리 사용(1시간)·로그 보관(14일)·신고의 IP 변환값 저장이 개인정보 처리에 해당하는지, 처리방침에 적을 보관 기간 권장값.
7. 신고 자유 입력란에 이용자가 개인정보를 적는 경우의 처리(현재 "개인정보를 적지 마세요" 안내만 있음).
8. 지도 이미지 서버(OpenStreetMap — 해외)로의 IP 전달이 **국외 이전·제3자 제공** 고지 대상인지.
9. 개인정보 보호책임자 지정·처리방침 필수 항목 중 빠진 것.

### C. 약관·책임
10. 요금·운영시간이 **예상치**이고 현장과 다를 수 있다는 고지(약관 2조·화면 곳곳)로 손해 책임을 제한할 수 있는 범위.
11. 관리자 보정 값, 목적지 대략 위치, 혼잡 경향(과거 평균), 주차 타이머 알림에 대한 면책 문구가 충분한지.
12. 준거법·관할, 서비스 변경·중단 고지 방법.

### D. 데이터 이용
13. 공공데이터포털·한국천문연구원·서울 열린데이터광장 데이터의 이용허락 범위(출처 표시 방식, 가공·재배포 허용 여부). 현재 각 시설 화면에 출처·기준일 표시.
14. OpenStreetMap 타일 이용 정책(대량 사용 금지), 브이월드 이용 약관상 유의점.
15. 정적 데모 페이지(전국 시설 데이터를 페이지에 담아 공유)의 공개 배포가 데이터 이용허락에 맞는지.

## 3. 검토 후 받아야 할 것
- 신고 필요 여부와 절차, 동의 화면 필요 여부
- 약관·처리방침 확정 문안(운영 주체·연락처·보관 기간·시행일 포함)
- 필요 시 서비스 구조 변경 권고(예: 좌표 캐시 제거, 동의 화면 추가)
