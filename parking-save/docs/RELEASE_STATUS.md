## 3. 성능 (2026-11-12 측정)

운영 서버(네이버클라우드 Micro 1vCPU·1GB)와 같은 제약으로 측정: Docker 컨테이너 `--cpus 1 --memory 700m`, 실데이터 15,828곳, 요청마다 다른 클라이언트(요청 제한 영향 배제).

| 대상 | 동시 요청 | 처리량 | 응답 p50 / p95 / p99 |
|---|---|---|---|
| 검색 API, 반경 1km | 1 | 142건/초 | 5 / 17 / 27ms |
| | 10 | 146건/초 | 57 / 150 / 202ms |
| | 50 | 200건/초 | 225 / 383 / 569ms |
| 검색 API, 반경 3km | 25 | 91건/초 | 247 / 528 / 699ms |
| 검색 화면(HTML), 반경 1km | 10 | 32건/초 | 294 / 424 / 1,131ms |
| | 25 | 36건/초 | 685 / 914 / 979ms |

- 메모리 최대 191MB/700MB, 재시작·OOM 없음. 오류 0건.
- 해석: 검색 화면 기준 초당 약 35건(분당 약 2,000건)까지 1초 안팎 응답 → 초기 서비스에 충분. 화면 렌더링이 API보다 약 5배 무거워 트래픽 증가 시 첫 병목. 서버 1대 구성이라 요청 제한·SQLite도 1대 전제.

## 4. 이번 출시 범위에 들어간 기능

- 검색(현재 위치·목적지*·주차장 이름), 시작·종료 시각 기준 예상 요금, 정렬·필터, 동일 시설 묶음, 더 싼 시간대 제안
- 목록/지도 전환(핀 묶기), 상세(요금 규칙·운영시간·날짜별 요금 내역·이용 시간별 요금 그래프), 네이버 지도 앱 연결
- 즐겨찾기·최근 검색(동의 시)·주차 타이머 — 기기에만 저장
- 결과 공유(위치 약 100m 단위 축소), 홈 화면 설치(PWA), 다크 모드, 정보 오류 신고(관리자 검토)
- 요금 이상치 경고(원천 입력 오류 의심 15곳), 감면·할인 대상 안내(금액 미반영), 가성비 정렬(요금+거리), 주차장 나란히 비교(최대 3곳)
- 운영: 수집 3종(표준데이터·공휴일·서울 실시간), 품질 리포트, 관리자 화면(신고·중복 후보·수집 상태·품질), 자동 백업, 헬스체크

\* 목적지 주소 검색은 지오코딩 제공자 결정 전까지 운영에서 사용할 수 없음(현재 위치·주차장 이름 검색으로 대체).
