## 출시 전 필수 결정/입력
1. **공공데이터포털 인증키** 발급·설정 → 표준데이터(`npm run sync:standard`)·공휴일(`npm run sync:holidays`) **첫 실호출 검증**(어댑터는 구현 완료, 응답 형태·값 분포 확인 필요). 서울 열린데이터광장 키(`SEOUL_OPENAPI_KEY`)도 별도 발급
2. ~~일요일 규칙~~ 결정됨(표준데이터 한정 적용·추정 표시) — 실데이터 확인 후 재검토
3. **실시간 잔여면수**: 서울은 구현 완료(키 필요: `SEOUL_OPENAPI_KEY`), 연결 후보 **관리자 검토 운영 절차** 필요. 서울 외 지역은 한국교통안전공단 API 키 발급 후 기술문서 확인
4. **운영 인프라**(호스팅·DB·스케줄러·알림 채널, OPEN_ISSUES #10) — 요청 제한·알림 전달 방식에 영향
5. **법적 고지**: 공공데이터 출처표시·이용조건, 위치정보 처리방침(OPEN_ISSUES #11), 지도 앱 URL Scheme 이용 약관
6. 임시 임계값 확정: 검색 반경(#6), 실시간 신선도(#7), 혼잡 구간(#8), 거리 유의점 700m, 품질 알림 임계값
