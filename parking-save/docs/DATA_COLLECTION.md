# 데이터 수집 및 정합성

## 우선 조사할 원천
1. 공공데이터포털의 전국 주차장 정보 표준데이터
2. 한국교통안전공단 주차정보 관련 API
3. 지자체·공공기관이 제공하는 주차장 상세/실시간 정보

위 항목은 조사 후보이며, 실제 제공 필드·공영 여부·전국 커버리지·호출 제한·갱신 주기·이용 조건을 API별로 검증해야 한다.

## 수집 단계
1. 원천 목록과 이용 조건 기록
2. 인증 및 샘플 호출 검증
3. 원천 응답 원본 보존
4. 필드 매핑 및 표준화
5. 좌표·주소·시설 유형 검증
6. 중복 후보 탐지
7. DB 반영 및 변경 이력 기록
8. 실패/지연/데이터 공백 모니터링

## 품질 규칙
- 공영 여부가 확인되지 않은 시설은 공영으로 단정하지 않는다.
- 요금 미기재는 무료가 아니다.
- 운영시간 미기재는 24시간 운영이 아니다.
- 실시간 잔여면수 미제공은 만차 또는 여유로 간주하지 않는다.
- 오래된 데이터는 마지막 수집일과 함께 표시하고 신선도 상태를 분류한다.
- 시설별 원천 및 기준일을 추적할 수 있어야 한다.

## 초기 운영 전략
전국 검색 가능한 기본 레코드를 확보하되, 요금·운영시간·실시간 정보의 상세도는 지역별로 다를 수 있다. 데이터가 확보된 항목만 정확히 노출하고 미확보 항목은 `정보 없음`으로 표시한다.
