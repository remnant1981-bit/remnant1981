# 검색 및 필터 명세

## 검색 입력
- 검색 기준: 현재 위치 또는 목적지
- 반경: 기본값 제안은 1km, 사용자 변경 가능하도록 설계(최종 UX 값은 구현 전 검토)
- 주차 시작 일시
- 주차 종료 일시
- 선택 필터: 무료만, 노상/노외, 실시간 잔여면수 확인 가능

## 결과 항목
- 주차장명 및 주소
- 목적지/현재 위치로부터 거리
- 예상 총 주차요금 또는 `요금 정보 없음`
- 무료 적용 여부 및 적용 시간대
- 운영 상태(운영/운영 외/확인 불가)
- 전체 주차면수
- 실시간 잔여면수 및 관측 시각(제공 시)
- 출처 및 데이터 기준일

## 정렬
- 무료 우선
- 예상 요금 낮은 순
- 거리 가까운 순
- 실시간 잔여면수 많은 순(유효 데이터가 있는 시설만)

정렬은 사용자가 선택할 수 있게 한다. 무료 우선 정렬에서도 거리·운영 여부를 함께 보여주며, 지나치게 먼 시설을 무조건 최적 추천으로 단정하지 않는다.
