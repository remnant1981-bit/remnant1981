# 화면 및 사용자 경험 명세

## 1. 홈/검색
- 목적지 검색 입력
- 현재 위치 사용 버튼(권한 요청은 사용자 동의 후)
- 주차 시작/종료 일시 입력
- 빠른 주차 시간 선택 및 직접 입력
- 검색 실행

## 2. 검색 결과
- 지도/목록 전환
- 무료 우선/요금순/거리순 정렬
- 노상·노외 필터
- 주차장 카드에 이름, 거리, 예상요금, 운영상태, 총면수/잔여면수, 정보 기준일 표시
- 요금/실시간 정보가 없으면 명시적 상태 라벨 표시

## 3. 상세
- 주소 및 위치
- 시설 유형 및 운영기관
- 요금 규칙 상세와 예상요금 산출 근거
- 운영시간/무료 개방 시간
- 전체면수/실시간 잔여면수/관측시각
- 데이터 출처와 마지막 갱신일
- 네이버 지도 열기

## 4. 상태 화면
- 로딩
- 검색 결과 없음
- 위치 권한 거부
- 위치 조회 실패
- 데이터 일부 누락
- 외부 API 장애
- 데이터 갱신 지연

## UX 원칙
정확하지 않은 수치를 확정적으로 보이지 않는다. 정보 없음과 0, 무료와 요금 미확인, 실시간 만차와 실시간 미제공을 구분한다.
