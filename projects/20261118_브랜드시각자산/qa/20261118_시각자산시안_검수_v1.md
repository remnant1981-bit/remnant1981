## 판정 근거

- 상 0건, 중 3건 → **조건부 통과**
- 중 3건 수정 후 조이 확인으로 종결 가능. 지적 1(Canva 초안 미충족)은 수정이 아니라 대표 판단 사항이므로 시안 선택 보고 시 함께 고지 필요

## 미검증 항목

- SVG 렌더링 결과(시각 확인): 검수 환경에 SVG 렌더러(rsvg-convert, cairosvg 등)와 해당 서체가 없어 실제 표시 모양, 글자 겹침·잘림 여부는 확인하지 못함. 좌표 계산상 B의 `Hooni`(190~430)와 옐로 띠(432~628)는 겹치지 않음
- Canva 무료 서체 제공 여부(시안서 7-3): Canva 도구 미부여로 확인하지 못함
- Google Fonts 배포본 Noto Sans KR·Noto Serif KR의 개별 라이선스 페이지: 상위 저장소(noto-cjk) 원문만 확인함. 같은 OFL 1.1로 배포되는 것으로 알려져 있으나 이번에 페이지를 열어 보지는 않음
- OFL FAQ(로고 사용 관련 해설): 조회 횟수 제한(6회)으로 열지 않음. 로고 사용 가능 판단은 라이선스 본문의 "document created using the Font Software" 조항에 근거함
- 흑백 인쇄 실물 확인: 휘도 대비로 계산상 판단만 함(A 앰버/크림 4.57:1 → 흑백에서도 구분 가능)
- 유사 상표·로고 조회: 브리프 범위 제외, 대표 판단 사항
