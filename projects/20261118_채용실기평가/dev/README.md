# ops_status.py — 업무 현황 요약

`ops/work-log.md` 의 `## 기록` 표를 읽어 마크다운으로 요약한다.

- 상태별 건수
- 미완료 항목 (상태가 `완료`가 아닌 건)
- 검수 미완료 건 (검수 = `미완료` 또는 빈 값)
- 검수 값 확인 필요 (비표준 값, 예: `조이 1차 검토(...)`). `완료`, `해당없음*`, `—` 는 정상으로 간주

## 요구사항
Python 3.10+, 표준 라이브러리만 사용. 외부 네트워크·서비스 없음.

## 실행
```
cd projects/20261118_채용실기평가/dev
python3 ops_status.py                    # stdout 출력 (기본)
python3 ops_status.py --output out.md    # stdout 출력 + 파일 저장
python3 ops_status.py --input <경로>     # 다른 work-log 지정 (기본 ops/work-log.md)
```
종료 코드: 0 정상 / 1 `## 기록` 표 없음·필수 열(번호·상태·검수) 누락 / 2 파일 입출력 오류.

## 동작 및 경계 처리
- 입력 파일은 읽기만 함. `--output` 이 입력과 같은 경로면 거부함.
- `## 기록` 섹션의 첫 표만 대상 (`## 양식` 표의 예시는 무시). 열은 헤더 이름으로 매핑함.
- 셀 안 `\|` 는 `|` 로 복원, 출력 시 다시 이스케이프함. 빈 셀은 유지하고, 검수 빈 값은 `(빈 값)`으로 표시함.
- 열 수가 헤더와 다른 행은 stderr 경고 후 건너뜀. 정의 외 상태값도 누락 없이 집계함.
- 한계: 백틱 코드 안의 이스케이프 없는 `|` 는 구분자로 취급함 (GFM과 동일).
