## 검수 방법

- DOCX를 작업용 임시 위치(세션 scratchpad)에 복사한 뒤 pandoc으로 본문 추출, LibreOffice로 PDF 변환해 페이지 수 확인, XML 직접 열람으로 메모·변경 추적·메타데이터 확인
- 원본은 검수 전후 SHA-256 해시를 비교해 변경 없음 확인
- 웹 교차확인: 해당 없음 (외부 사실·수치·고유명사 인용 없음)
