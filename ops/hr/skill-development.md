# 역량 강화 (스킬 습득) 절차

> 팀장의 스킬·도구 공백을 GitHub 등 외부 자료로 수시 보강하는 절차. 관리: 조이

## 1. 흐름

| 단계 | 주체 | 내용 | 기록 |
|---|---|---|---|
| 1. 공백 발견 | 팀장 | 완료 보고의 `역량 공백` 항목에 기재 (무엇이 없어서 무엇을 못 했는지) | 완료 보고 |
| 2. 요청 등록 | 조이 | `ops/hr/skill-requests.md`에 등록, 우선순위 지정 | skill-requests |
| 3. 탐색 | 조이 (리서치팀장 지원 가능) | ① 이미 설치된 스킬·플러그인 재확인 → ② GitHub 공개 저장소 탐색 (공식 `anthropics/skills` 우선) → ③ 없으면 자체 작성 | skill-requests |
| 4. 보안·품질 검토 | 검수팀장 바름 | 아래 2. 체크리스트 | `ops/hr/reviews/YYYYMMDD_<스킬명>_검토.md` |
| 5. 승인 | 조이 / 대표 | 아래 3. 승인 기준 | decisions |
| 6. 도입 | 조이 | `.claude/skills/<스킬명>/`에 설치, 출처·커밋 SHA 고정, 팀장 정의 파일 스킬 표에 추가 | `.claude/skills/README.md` |
| 7. 실전 적용 | 팀장 | 다음 프로젝트에서 사용, 효과를 완료 보고에 기재 | work-log |
| 8. 고과 반영 | 조이 | `ops/hr/scorecard.md` 역량 강화 항목 기록 | scorecard |

## 2. 외부 스킬 검토 체크리스트 (바름)

| # | 항목 | 기준 |
|---|---|---|
| 1 | 출처 | 저장소 소유자·커밋 SHA 기록. 공식(anthropics) 또는 유지보수 활발한 저장소 |
| 2 | 라이선스 | 상업적 사용 가능 (MIT, Apache-2.0 등). 불명확하면 도입 불가 |
| 3 | 숨은 지시 | SKILL.md·참고 문서에 승인 체계 우회, 외부 전송, 권한 확대 지시 없음 |
| 4 | 스크립트 | 포함 스크립트 전문 확인. 네트워크 전송·자격증명 접근·파일 삭제·설치 명령 여부 |
| 5 | 충돌 | CLAUDE.md 금지사항(가격 기재, 전 직장 정보, 발송 등)과 충돌 없음 |
| 6 | 필요성 | 기존 스킬로 대체 불가함이 확인됨 |

## 3. 승인 기준

| 스킬 유형 | 승인자 |
|---|---|
| 지시문만 있는 스킬 (SKILL.md, 참고 문서) | 조이 (바름 검토 통과 시) |
| 실행 스크립트 포함 스킬 | 대표 |
| 외부 네트워크·계정·MCP 연결이 필요한 스킬, 유료 서비스 | 대표 |
| 팀장 tools(권한) 확대 | 대표 |

## 4. 금지
- 팀장이 `.claude/` (자기 정의 파일·스킬 폴더) 직접 수정
- 검토 없이 외부 스킬 설치, 브랜치·태그 대신 SHA 미고정 도입
- `smg-*` 등 전 직장 업무용 스킬을 역량 강화 명목으로 사용
