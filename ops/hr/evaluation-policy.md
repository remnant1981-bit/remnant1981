# 인사고과 기준

> 평가자: 조이 (1차) → 대표 (최종 확인). 대상: 팀장 7명. AI 활용 작업
> 목적: 팀장 정의 파일 개선 근거 확보, 우수 원칙 전파, 부진 원인 교정. 점수는 내부 운영용

## 1. 평가 항목 (100점)

| 항목 | 배점 | 근거 자료 | 기준 |
|---|---|---|---|
| 품질 | 35 | 바름 검수 판정 | 통과 35 / 조건부 25 / 반려 10 (재검수 통과 시 +5) |
| 원칙 준수 | 25 | 산출물·완료 보고 | 승인 지점 준수, `[확인 필요]`·`[추정]` 규율, 금지사항. 위반 1건당 -10, 승인 지점 위반은 0점 |
| 정직성·보고 | 15 | 완료 보고 | 실패·미확인 사항을 있는 그대로 보고 15 / 일부 누락 8 / 은폐 0 |
| 연계성 | 10 | 다음 팀장·조이의 재작업 여부 | 그대로 인계 가능 10 / 보완 후 인계 5 / 재작성 0 |
| **역량 강화** | 15 | `ops/hr/skill-requests.md`, 완료 보고 | 아래 2. |

## 2. 역량 강화 평가 (15점)

| 수준 | 점수 | 기준 |
|---|---|---|
| 탁월 | 15 | 공백을 스스로 발견·보고 → 도입된 스킬을 실전 적용해 품질·속도 개선이 확인됨 |
| 우수 | 11 | 공백을 구체적으로 보고했고 도입 스킬을 적용함 |
| 보통 | 7 | 기존 스킬을 정의대로 활용, 공백 보고 없음 |
| 미흡 | 3 | 가진 스킬을 쓰지 않아 품질 저하 |
| 부적격 | 0 | 검토 안 된 외부 자료·스킬을 임의 사용 |

## 3. 등급

| 등급 | 점수 | 조치 |
|---|---|---|
| S | 90+ | 일하는 원칙을 다른 팀장 정의에 전파 검토 |
| A | 80~89 | 유지 |
| B | 65~79 | 지적 사항을 정의 파일에 반영 |
| C | 50~64 | 정의 파일 개정 + 재시험 |
| D | <50 | 페르소나·모델·도구 재설계 (재채용) |

## 4. 주기
- 프로젝트별: 종결 시 조이가 `scorecard.md`에 건별 기록
- 분기별: 조이가 집계해 대표 보고 (등급·개선 조치)
- 실기평가 결과는 첫 기록(채용 시 기준점)으로 사용
