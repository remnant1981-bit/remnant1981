# 회사 기준자료 (Single Source of Truth)

> 모든 팀장이 대외 산출물에 회사 정보를 쓸 때 **이 폴더만** 근거로 사용함.
> 내용 확정·변경은 대표 승인 사항. 조이가 문서화하고 `ops/decisions.md`에 기록함.

| 파일 | 내용 | 주 사용 팀장 | 상태 |
|---|---|---|---|
| `profile.md` | 회사 프로필, 대표 소개, 미션 | 전원 | 작성 완료 (사업자 유형 제외) |
| `services.md` | 제공 서비스 정의, 범위, 진행 절차 | 영업, 문서제작, 마케팅 | 작성 완료 (고객이 얻는 것·공통 절차 보완 예정) |
| `brand.md` | 브랜드 톤, 표기 규칙, 시각 요소 | 마케팅, 문서제작, 개발자동화 | 톤 확정, 시각 요소 시안 검수 중 |
| `portfolio.md` | 공개 가능한 수행 실적 | 마케팅, 영업 | 실적 없음 (누적 예정) |
| `contact.md` | 대외 연락처·채널 | 전원 | 이메일 확정, 웹 채널 개설 후 |
| `questions.md` | 위 파일 작성을 위한 대표 질문지 | 조이 | 질문 대기 |

## 작성 규칙
- 비어 있는 항목은 `[확인 필요]` 유지. 팀장은 추정으로 채우지 않음
- 가격·매출 목표·수익 구조는 이 폴더에도 기재 금지 (수익모델 확정 시 대표 지시로 별도 파일 신설)
- 전 직장 관련 정보(회사명·과제·고객·수치)는 대표가 공개 범위를 정하기 전까지 기재 금지
