# 브랜드 가이드

| 항목 | 내용 |
|---|---|
| 브랜드 톤 | **투명한 기록형 기본 + 친근한 어휘 일부** (Q7, 대표 확정). 형용사: 담백한 · 꼼꼼한 · 솔직한 (+ 쉬운 말 선택) |
| 고객 대상 문체 | 합니다체(평이), 짧은 단문 중심. 어려운 용어는 풀어 씀. 할 수 있는 것과 할 수 없는 것을 분명히 구분. 1인칭: 문서·제안서·홈페이지 = "Hooninote는", 블로그 = "저는" (대표 박장훈 1인칭) |
| 금지 표현 | 근거 없는 최상급("최고", "유일"), 가격·할인 언급, 애매한 약속("최대한 잘", "알아서 해드립니다"), 광고성 감탄·과한 수식어, 압박 문구("지금 놓치면 후회", "마감 임박"), 반말·유행어, 느낌표·이모지 남발, 확인되지 않은 일정·결과·진행 방식의 단정 |
| 채널별 조정 | 제안서·납품 문서: 합니다체 단문 그대로 / 블로그: 합니다체 + 쉬운 설명 / SNS: 게시물당 이모지 1개 이내, 문서·제안서·메일은 이모지 사용 안 함 |
