# 브랜드 가이드

| 항목 | 내용 |
|---|---|
| 브랜드 톤 | **투명한 기록형 기본 + 친근한 어휘 일부** (Q7, 대표 확정). 형용사: 담백한 · 꼼꼼한 · 솔직한 (+ 쉬운 말 선택) |
| 고객 대상 문체 | 합니다체(평이), 짧은 단문 중심. 어려운 용어는 풀어 씀. 할 수 있는 것과 할 수 없는 것을 분명히 구분. 1인칭: 문서·제안서·홈페이지 = "Hooninote는", 블로그 = "저는" (대표 박장훈 1인칭) |
| 금지 표현 | 근거 없는 최상급("최고", "유일"), 가격·할인 언급, 애매한 약속("최대한 잘", "알아서 해드립니다"), 광고성 감탄·과한 수식어, 압박 문구("지금 놓치면 후회", "마감 임박"), 반말·유행어, 느낌표·이모지 남발, 확인되지 않은 일정·결과·진행 방식의 단정 |
| 채널별 조정 | 제안서·납품 문서: 합니다체 단문 그대로 / 블로그: 합니다체 + 쉬운 설명 / SNS: 게시물당 이모지 1개 이내, 문서·제안서·메일은 이모지 사용 안 함 |
| 근거 자료 | `projects/20261118_채용실기평가/marketing/20261118_브랜드톤제안_v2.md` (나래 제안, 바름 검수 통과) |
| 로고 | **A안 잉크 노트** (조이 선정, 대표 위임): 워드마크 `Hooninote`(Inter 세미볼드, 잉크 네이비) + 하단 짧은 앰버 밑줄 1개. 심볼 없음. SNS 프로필: 네이비 정사각 배경 + 흰색 `H` + 밝은 앰버 짧은 선. 스케치: `projects/20261118_브랜드시각자산/marketing/20261118_로고스케치_A_v1.svg` [확인 필요: 최종 벡터 원본 제작·유사 상표 조회] |
| 대표 색상 | 잉크 네이비 `#1F2A44` (로고·제목·본문) / 종이 크림 `#F7F4EC` (배경) / 앰버 `#B45309` (밝은 배경 위 밑줄·구분선·큰 글자) / 밝은 앰버 `#F59E0B` (네이비 등 어두운 배경 위 선·강조 전용) / 흰색 `#FFFFFF` (인쇄 배경) |
| 색 사용 규칙 (WCAG 검증) | 네이비/크림 12.97:1, 네이비/흰색 14.3:1 → 본문 가능. 앰버/크림 4.57:1 → 선·큰 글자만, 작은 글자 금지. 앰버 `#B45309`는 네이비 배경 위 사용 금지(2.84:1) → 밝은 앰버 `#F59E0B`(6.64:1) 사용 |
| 서체 | 국문 Pretendard (제목·본문), 영문 Inter (로고·영문). 모두 SIL OFL 1.1 — 상업 사용·문서 임베딩 가능 (바름 원문 확인 2026-11-18). 웹폰트 재배포 시 라이선스 사본 동봉. HWPX 문서에서 서체 미설치 환경 대비 [확인 필요: 대체 서체 지정] |
| Canva 브랜드킷 | 미생성 (Canva 크레딧 한도 초과로 보류). 크레딧 회복 후 나래가 A안 기준 생성 — 브랜드킷 생성은 대표 승인 |
